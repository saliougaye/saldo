# Code of conduct

This project uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The text at that address applies to every space of the project: the repository, issues,
pull requests and discussions.

## In short

- Be kind and patient. Assume good intent.
- Disagree with the idea, not with the person.
- Do not harass, insult or discriminate.
- Do not publish another person's private information.

## Report a problem

Report behaviour that breaks this code to the maintainer through
[GitHub private vulnerability reporting](https://github.com/saliougaye/saldo/security/advisories/new), or
open an issue titled «Conduct report» with no names and no details. The maintainer will answer and will
arrange a private channel.

The maintainer can remove comments, lock threads and block accounts that break this code.
