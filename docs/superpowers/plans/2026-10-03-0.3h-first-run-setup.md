# 0.3h — First-run setup wizard (`/setup`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fresh instance (no account yet) greets its self-hoster at `/setup` with a four-step wizard — Benvenuto → Il tuo server → Il tuo account → Pronto — that ends with an admin account, the instance name and the registration mode saved, and nothing left to do on the command line.

**Architecture:** The gate is one fact, «the instance has no user row»: `/`, `/login` and `/register` send to `/setup` while it holds, `/setup` sends to `/` once it does not. The registration policy learns the same fact: on a fresh instance the first account is allowed under every mode and needs no invite (this is what retires the CLI's first invite; `first-user` and the CLI stay). The wizard is a client flow in the auth pages' shell (`auth.module.css`, `Steps`, `Brand`, `OptionList`, `TextField`, `Button`, `Alert`), on three server pieces: `setupState` (what to show, and whether `/setup` is still needed), `saveSetupServer` (name and mode, written only where the environment does not set them, allowed only while no user exists) and the existing passkey registration (`authClient.passkey.addPasskey`, `claimRoleForNewUser` makes the first account the admin). The last step mints the optional first invite with the existing `mintInvite` behind a Server Action that requires the admin session the ceremony just created.

**Tech Stack:** Next.js 16 app router (Server Components, Server Actions, `redirect`), Better Auth passkey plugin, drizzle + PGlite tests (vitest), CSS Modules on `@saldo/ui` tokens, `@saldo/i18n` (seven locales, parity test).

**Mockup:** `docs/superpowers/mockups/2026-10-01-first-run-setup-variants.html`, variant **A · Wizard** (moved here from `.variants/`). Spec: §17.1.4, §17.1.8, roadmap 0.3h row and the decision «First-run setup is a wizard, without an SMTP step (2026-10-01)».

## Decisions (recorded here, as the roadmap asks)

1. **The gate is the user count, not a flag.** No `setup_done` row: an instance with one account is set up, an instance with none is not. It survives a wiped `server_settings`, needs no migration, and is the same fact `first-user` already keys on.
2. **The first account is allowed under every mode and needs no code.** Today `REGISTRATION=invite` (the documented recommendation) refuses the very first account unless the CLI minted a code, and `closed` refuses it outright. The wizard replaces that CLI step, so `registrationAllowed` answers `true` and `registrationRequiresInvite` answers `false` while no user exists, whatever the mode. The window this opens is the one `first-user` always had: a fresh instance accepts whoever arrives first, and closes the moment an account exists. Two ceremonies finishing in the same seconds on a fresh instance both create accounts; `claimRoleForNewUser`'s lock makes exactly one of them the admin. Documented in `docs/self-hosting.md`.
3. **Step 2 writes before the account exists.** `saveSetupServer` has no session to check; its guard is «no user exists», decided on the server at call time. After the account exists the panel at `/admin/settings` is the way, and the action answers `alreadySetUp`.
4. **Step 2 offers `invite` (consigliata), `open`, `closed`** — not `first-user`, which the wizard supersedes. A locked value of `first-user` from the environment is still shown, read-only, with its existing label.
5. **No SMTP step.** The last step shows the email status (`configurata dall'ambiente` under `SMTP_HOST`, `configurata` when a stored configuration reads, `non configurata` with a link to `/admin/settings?edit=smtp`) and nothing else about mail.
6. **The first invite is optional and uses the admin session.** Step 4 runs after the ceremony signed the browser in as the new admin, so `mintFirstInviteAction` is `requireWebAdmin()` + `mintInvite` with `ttlDays: 7`. The code is shown once, with the link and a copy button; no QR (the mockup has none; `/admin/invites` has it for later).
7. **`/setup` is a page, not a layout rule.** No middleware exists in `apps/web` and none is added: each of the three public pages gets one `if (await pageSetupNeeded()) redirect('/setup')` line, which is how every other redirect in the app is done.
8. **«Database connesso» is honest, not a probe.** The page's own `userCount` query is the connection check: if it throws, Next shows its error page and the wizard is not rendered. The row therefore always reads «connesso» when seen.
9. **«Vai a Saldo» goes to `/home`.** A new account has no `settings` row, so `readPage` sends it on to `/onboarding`, exactly as `/register` does today. Nothing new.
10. **`/auth/mobile` follows the same policy.** The phone's browser page asks the async `registrationRequiresInvite`, so a phone on a fresh instance creates the first account without a code too. It is not redirected to `/setup`: the phone cannot usefully run the wizard, and the account it creates becomes the admin the same way.
11. **Version stays `APP_VERSION`.** The welcome step shows what `AuthFooter` shows.

```ts
import { sql } from 'drizzle-orm';
import { user } from '../db/schema';
import type { ServerDatabase } from '../db/types';
import type { RegistrationMode } from '../env';

/** How many accounts the instance has. Zero is the one number that matters: it is what `/setup` keys on (0.3h). */
export async function userCount(db: ServerDatabase): Promise<number> {
  const [row] = await db.select({ count: sql<number>`count(*)::int` }).from(user);
  return row?.count ?? 0;
}

/**
 * §9.2 `REGISTRATION`: `open` always, `invite` always (under that mode it is the **code** that
 * decides, not the instance), and `closed` and `first-user` only while the instance has no user.
 *
 * **A fresh instance lets its first account in under every mode** (0.3h). The first-run wizard at
 * `/setup` replaced the CLI's first invite, so an instance that starts with `REGISTRATION=invite`
 * — the documented recommendation — has to accept the account the wizard creates. The window is
 * the one `first-user` always had: it closes the moment an account exists.
 *
 * What this answers is "should the client offer to create an account", which is why `invite` is
 * `true`: somebody holding a code must be able to reach the form. Whether the code is any good is
 * settled later, in `resolveUser`.
 *
 * Better Auth has no notion of a closed instance, so this is checked in the passkey plugin's
 * `resolveUser` hook: the last moment before a user row would be created.
 */
export async function registrationAllowed(
  db: ServerDatabase,
  mode: RegistrationMode,
): Promise<boolean> {
  if (mode === 'open' || mode === 'invite') return true;
  return (await userCount(db)) === 0;
}

/**
 * Under `invite` every account needs a code **except the first** (0.3h): the first account is the
 * one the wizard creates, and it becomes the admin who mints every later code. Once it exists the
 * door is the code, with no window during which it stands open.
 */
export async function registrationRequiresInvite(
  db: ServerDatabase,
  mode: RegistrationMode,
): Promise<boolean> {
  return mode === 'invite' && (await userCount(db)) > 0;
}
```

```ts
import { userCount } from '../auth/policy';
import type { ServerDatabase } from '../db/types';
import { env, type RegistrationMode } from '../env';
import type { SettingSource } from '../settings/resolve';
import {
  readServerSettings,
  type SettingsSource,
  smtpView,
} from '../settings/serverSettings';

/** A setting as the wizard shows it: the value, where it came from, and whether the person may change it. */
export interface SetupSetting<T> {
  value: T;
  source: SettingSource;
  locked: boolean;
}

/** `env`: `SMTP_HOST` is set. `configured`: a stored configuration that still reads. `none`: nothing, or a password that no longer decrypts. */
export type SetupMailStatus = 'env' | 'configured' | 'none';

export interface SetupState {
  /** True while the instance has no account: the only condition under which `/setup` renders. */
  needed: boolean;
  instanceName: SetupSetting<string>;
  registration: SetupSetting<RegistrationMode>;
  /** The variables that lock step 2, in the order the note names them; empty when nothing is locked. */
  lockedVariables: string[];
  mail: SetupMailStatus;
}

/** 0.3h, decision 1: the gate is the user count. `/`, `/login` and `/register` send to `/setup` while this holds. */
export async function setupNeeded(db: ServerDatabase): Promise<boolean> {
  return (await userCount(db)) === 0;
}

/**
 * Everything `/setup` renders, in one read: the count, the three settings with their sources and
 * the mail status for the last step. Like the settings readers it takes the environment part last,
 * so a test states «the environment locks it» without touching `process.env`.
 */
export async function setupState(
  db: ServerDatabase,
  source: SettingsSource = env(),
): Promise<SetupState> {
  const [needed, settings, smtp] = await Promise.all([
    setupNeeded(db),
    readServerSettings(db, source),
    smtpView(db, source),
  ]);
  const lockedVariables: string[] = [];
  if (settings.instanceName.source === 'env') lockedVariables.push('INSTANCE_NAME');
  if (settings.registration.source === 'env') lockedVariables.push('REGISTRATION');
  return {
    needed,
    instanceName: {
      value: settings.instanceName.value,
      source: settings.instanceName.source,
      locked: settings.instanceName.source === 'env',
    },
    registration: {
      value: settings.registration.value,
      source: settings.registration.source,
      locked: settings.registration.source === 'env',
    },
    lockedVariables,
    mail: mailStatus(smtp),
  };
}

function mailStatus(smtp: Awaited<ReturnType<typeof smtpView>>): SetupMailStatus {
  if (smtp.value === null) return 'none';
  if (smtp.source === 'env') return 'env';
  return smtp.value.passwordReadable ? 'configured' : 'none';
}
```

```ts
import { z } from 'zod';
import type { ServerDatabase } from '../db/types';
import { env } from '../env';
import { log } from '../log';
import { resolveSettings } from '../settings/resolve';
import type { SettingsSource } from '../settings/serverSettings';
import { saveInstanceName, saveRegistration } from '../settings/write';
import { setupNeeded } from './state';

/** The modes step 2 offers. `first-user` is what the wizard supersedes, so it is not one of them (decision 4). */
export const SETUP_MODES = ['invite', 'open', 'closed'] as const;
export type SetupMode = (typeof SETUP_MODES)[number];

const setupInputSchema = z.object({
  /** Trimmed by `saveInstanceName`; empty deletes the row. The 60 is `instanceNameRowSchema`'s. */
  name: z.string().max(60),
  mode: z.enum(SETUP_MODES),
});

export type SetupWriteResult = { ok: true } | { ok: false; error: 'alreadySetUp' | 'invalid' };

/**
 * Step 2 of `/setup` (0.3h, decision 3). There is no session yet, so the guard is the instance's
 * own state: while no account exists, whoever is on the page is the person setting it up. A value
 * the environment sets is **skipped, not refused** — the step showed it locked, and the person is
 * saving the rest. Written by nobody (`updated_by` null), like the CLI's writes.
 */
export async function saveSetupServer(
  db: ServerDatabase,
  raw: unknown,
  now: Date,
  source: SettingsSource = env(),
): Promise<SetupWriteResult> {
  if (!(await setupNeeded(db))) return { ok: false, error: 'alreadySetUp' };
  const parsed = setupInputSchema.safeParse(raw);
  if (!parsed.success) return { ok: false, error: 'invalid' };
  const resolved = resolveSettings(source, []);
  if (resolved.instanceName.source !== 'env') {
    const named = await saveInstanceName(db, null, parsed.data.name, now, source);
    if (!named.ok) return { ok: false, error: 'invalid' };
  }
  if (resolved.registration.source !== 'env') {
    const moded = await saveRegistration(db, null, parsed.data.mode, now, source);
    if (!moded.ok) return { ok: false, error: 'invalid' };
  }
  log('setup', 'the server step of the first-run wizard was saved', {
    nameLocked: resolved.instanceName.source === 'env',
    modeLocked: resolved.registration.source === 'env',
  });
  return { ok: true };
}
```

```ts
import type { RegistrationMode } from '../../server/env';
import type { SetupMailStatus } from '../../server/setup/state';
import { SETUP_MODES, type SetupMode } from '../../server/setup/write';

/** The sub-path of `/admin/settings` the last step links to when mail is not configured. */
export const SMTP_SETTINGS_PATH = '/admin/settings?edit=smtp';

/** The invite's lifetime, in days: the panel's default, and all the wizard offers. */
export const FIRST_INVITE_TTL_DAYS = 7;

export interface SetupModeChoice {
  value: RegistrationMode;
  labelKey: string;
  noteKey: string;
  recommended: boolean;
}

const LABEL_KEY: Record<RegistrationMode, string> = {
  open: 'admin.settings.registration.open',
  'first-user': 'admin.settings.registration.firstUser',
  invite: 'admin.settings.registration.invite',
  closed: 'admin.settings.registration.closed',
};

/** The notes are the panel's, except `closed`: here it is «solo il tuo», because the wizard is about to create it. */
const NOTE_KEY: Record<RegistrationMode, string> = {
  open: 'admin.settings.registration.openNote',
  'first-user': 'admin.settings.registration.firstUserNote',
  invite: 'admin.settings.registration.inviteNote',
  closed: 'setup.closedNote',
};

function choice(value: RegistrationMode): SetupModeChoice {
  return {
    value,
    labelKey: LABEL_KEY[value],
    noteKey: NOTE_KEY[value],
    recommended: value === 'invite',
  };
}

/**
 * Step 2's list (decision 4): `invite`, `open`, `closed`, in that order. `first-user` is what the
 * wizard supersedes, so it appears only when the environment locks the value to it — then the list
 * is that one row, read-only, rather than three rows none of which is selected.
 */
export function setupModeChoices(value: RegistrationMode, locked: boolean): SetupModeChoice[] {
  if (locked && !isSetupMode(value)) return [choice(value)];
  return SETUP_MODES.map(choice);
}

export function isSetupMode(value: RegistrationMode): value is SetupMode {
  return (SETUP_MODES as readonly string[]).includes(value);
}

/** The line under the locked fields; `null` when nothing is locked. */
export function lockedNoteKey(variables: readonly string[]): 'setup.lockedOne' | 'setup.lockedMany' | null {
  if (variables.length === 0) return null;
  return variables.length === 1 ? 'setup.lockedOne' : 'setup.lockedMany';
}

export function emailStatusKey(
  mail: SetupMailStatus,
): 'setup.emailEnv' | 'setup.emailConfigured' | 'setup.emailMissing' {
  switch (mail) {
    case 'env':
      return 'setup.emailEnv';
    case 'configured':
      return 'setup.emailConfigured';
    case 'none':
      return 'setup.emailMissing';
  }
}
```

```tsx
'use client';

import { interpolate } from '@saldo/i18n/translate';
import { useRouter } from 'next/navigation';
import { useEffect, useRef, useState, useTransition } from 'react';
import { authClient } from '../../src/client/authClient';
import { log } from '../../src/client/log';
import { describeAuthError, fieldForErrorCode } from '../../src/features/auth/authErrors';
import { rememberPasskey } from '../../src/features/auth/lastPasskey';
import { registrationContextJson } from '../../src/features/auth/registrationBody';
import type { RegistrationMode } from '../../src/server/env';
import type { InstanceInfo } from '../../src/server/instance';
import type { SetupMailStatus } from '../../src/server/setup/state';
import { Alert } from '../../src/ui/Alert';
import { AuthFooter, Brand } from '../../src/ui/Brand';
import { Button } from '../../src/ui/Button';
import { Icon } from '../../src/ui/Icon';
import { type ListOption, OptionList } from '../../src/ui/OptionList';
import { Steps, stepsBackClass } from '../../src/ui/Steps';
import { TextField } from '../../src/ui/TextField';
import authStyles from '../(auth)/auth.module.css';
import { type FirstInviteResult, mintFirstInviteAction, saveSetupServerAction } from './actions';
import styles from './setup.module.css';

type Step = 0 | 1 | 2 | 3;

const MAX_NAME_LENGTH = 60;
const COPIED_MS = 2000;

interface Props {
  locale: string;
  instance: InstanceInfo;
  initialName: string;
  nameLocked: boolean;
  initialMode: RegistrationMode;
  modeLocked: boolean;
  modeChoices: readonly ListOption<RegistrationMode>[];
  /** «Impostati da REGISTRATION, INSTANCE_NAME», or null when nothing is locked. */
  lockedNote: string | null;
  mail: SetupMailStatus;
  smtpSettingsHref: string;
  strings: Record<string, string>;
  /** «Passo 1 di 2», «Passo 2 di 2». */
  stepLabels: string[];
}

interface Refusal {
  step: Step;
  field: 'name' | 'email' | 'displayName' | null;
  title: string;
  body: string;
}

type Minted = Extract<FirstInviteResult, { ok: true }>;

export function SetupFlow(props: Props) {
  const {
    locale,
    instance,
    initialName,
    nameLocked,
    initialMode,
    modeLocked,
    modeChoices,
    lockedNote,
    mail,
    smtpSettingsHref,
    strings,
    stepLabels,
  } = props;
  const router = useRouter();
  const [step, setStep] = useState<Step>(0);
  const [name, setName] = useState(initialName);
  const [mode, setMode] = useState<RegistrationMode>(initialMode);
  const [displayName, setDisplayName] = useState('');
  const [email, setEmail] = useState('');
  const [busy, setBusy] = useState(false);
  const [refusal, setRefusal] = useState<Refusal | null>(null);
  const [inviteLabel, setInviteLabel] = useState('');
  const [minted, setMinted] = useState<Minted | null>(null);
  const [copied, setCopied] = useState(false);
  const [pending, startTransition] = useTransition();
  const timer = useRef<ReturnType<typeof setTimeout>>(undefined);

  useEffect(() => () => clearTimeout(timer.current), []);

  // See RegisterFlow: `strings` is a Record, so fixed labels are read back as plain strings here.
  const label = (key: string): string => strings[key] ?? '';

  // The instance name the person is typing, or the resolved one when it is locked or empty.
  const shownInstanceName = nameLocked || name.trim() === '' ? instance.name : name.trim();
  const modeLabel = modeChoices.find((choice) => choice.value === mode)?.label ?? mode;

  const headingRef = useRef<HTMLHeadingElement | null>(null);
  const moved = useRef(false);
  // biome-ignore lint/correctness/useExhaustiveDependencies: the step is the trigger, not a read.
  useEffect(() => {
    if (!moved.current) {
      moved.current = true;
      return;
    }
    headingRef.current?.focus();
    window.scrollTo({ top: 0 });
  }, [step]);

  const shown = refusal !== null && refusal.step === step ? refusal : null;

  const go = (next: Step) => {
    setRefusal(null);
    setStep(next);
  };

  /** Step 2 → 3: save the server step, then move on. A locked value is skipped by the server. */
  const submitServer = () => {
    if (pending) return;
    if (!nameLocked && name.trim().length > MAX_NAME_LENGTH) {
      setRefusal({ step: 1, field: 'name', title: label('errorInvalid'), body: label('nameTooLong') });
      return;
    }
    startTransition(async () => {
      let result: Awaited<ReturnType<typeof saveSetupServerAction>>;
      try {
        result = await saveSetupServerAction({ name: name.trim(), mode });
      } catch {
        setRefusal({ step: 1, field: null, title: label('errorUnexpected'), body: '' });
        return;
      }
      if (result.ok) {
        go(2);
        return;
      }
      if (result.error === 'alreadySetUp') {
        // Somebody finished the wizard in another tab or on the phone: the door is `/login` now.
        router.replace('/login');
        return;
      }
      setRefusal({ step: 1, field: null, title: label('errorInvalid'), body: '' });
    });
  };

  const refuseCeremony = (code: string | undefined) => {
    const message = describeAuthError(code);
    const field = fieldForErrorCode(code);
    setRefusal({
      step: 2,
      field: field === 'name' ? 'displayName' : field === 'email' ? 'email' : null,
      title: strings[message.titleKey] ?? label('web.auth.genericError'),
      body: strings[message.bodyKey] ?? '',
    });
  };

  /** Step 3: the ceremony — the same call as `/register`, with no invite: the first account needs none. */
  const createAccount = async () => {
    setRefusal(null);
    if (displayName.trim().length === 0) {
      refuseCeremony('display_name_required');
      return;
    }
    if (!email.includes('@')) {
      refuseCeremony('email_required');
      return;
    }
    setBusy(true);
    const result = await authClient.passkey.addPasskey({
      context: registrationContextJson({
        name: displayName.trim(),
        email: email.trim(),
        invite: null,
      }),
      createSession: true,
      returnWebAuthnResponse: true,
    });
    setBusy(false);
    if (result.error !== null || result.data === null) {
      const failure = result.error;
      const code = failure === null ? undefined : 'code' in failure ? failure.code : undefined;
      log('auth', 'the server refused the first registration', { status: failure?.status, code });
      refuseCeremony(typeof code === 'string' ? code : undefined);
      return;
    }
    const credentialId = 'webauthn' in result ? result.webauthn?.response.id : undefined;
    if (credentialId !== undefined) rememberPasskey(credentialId);
    go(3);
  };

  const mint = () => {
    if (pending) return;
    startTransition(async () => {
      let result: FirstInviteResult;
      try {
        result = await mintFirstInviteAction({ label: inviteLabel.trim() });
      } catch {
        setRefusal({ step: 3, field: null, title: label('errorUnexpected'), body: '' });
        return;
      }
      if (!result.ok) {
        setRefusal({ step: 3, field: null, title: label('errorInvalid'), body: '' });
        return;
      }
      setRefusal(null);
      setMinted(result);
    });
  };

  const copyLink = async (link: string) => {
    try {
      await navigator.clipboard.writeText(link);
    } catch {
      return;
    }
    setCopied(true);
    clearTimeout(timer.current);
    timer.current = setTimeout(() => setCopied(false), COPIED_MS);
  };

  const expiresOn = (iso: string) =>
    new Intl.DateTimeFormat(locale, { dateStyle: 'long' }).format(new Date(iso));

  const alert = shown === null ? null : <Alert title={shown.title} body={shown.body} />;

  return (
    <>
      {step === 0 ? <Brand instanceName={nameLocked ? instance.name : undefined} /> : null}
      {step === 1 || step === 2 ? (
        <>
          <button type="button" className={stepsBackClass} onClick={() => go((step - 1) as Step)}>
            <Icon name="chevL" size={14} />
            {label('back')}
          </button>
          <Steps at={step} total={2} label={stepLabels[step - 1] ?? ''} />
        </>
      ) : null}

      {step === 0 ? (
        <>
          <span className={authStyles.passkeyArt}>
            <Icon name="server" size={32} />
          </span>
          <h1 className={authStyles.title} ref={headingRef} tabIndex={-1}>
            {label('welcomeTitle')}
          </h1>
          <p className={authStyles.lede}>{label('welcomeBody')}</p>
          <dl className={styles.summary}>
            <div className={styles.summaryRow}>
              <dt>{label('version')}</dt>
              <dd>{instance.version}</dd>
            </div>
            <div className={styles.summaryRow}>
              <dt>{label('database')}</dt>
              <dd>
                <span className={styles.dot} aria-hidden="true" />
                {label('databaseOk')}
              </dd>
            </div>
            <div className={styles.summaryRow}>
              <dt>{label('accounts')}</dt>
              <dd>{label('accountsNone')}</dd>
            </div>
          </dl>
          <Button onClick={() => go(1)}>{label('start')}</Button>
          <p className={`${authStyles.hint} ${authStyles.centred}`}>{label('welcomeHint')}</p>
          <AuthFooter version={instance.version} host={instance.host} />
        </>
      ) : null}

      {step === 1 ? (
        <>
          <h1 className={authStyles.title} ref={headingRef} tabIndex={-1}>
            {label('serverTitle')}
          </h1>
          <p className={authStyles.lede}>{label('serverBody')}</p>
          {alert}
          <form
            className={authStyles.form}
            onSubmit={(event) => {
              event.preventDefault();
              submitServer();
            }}
          >
            <div className={authStyles.fields}>
              <TextField
                label={label('nameLabel')}
                placeholder={label('namePlaceholder')}
                value={nameLocked ? instance.name : name}
                onChange={(event) => setName(event.target.value)}
                disabled={nameLocked}
                maxLength={MAX_NAME_LENGTH}
                autoComplete="organization"
                invalid={shown?.field === 'name'}
              />
              <div className={styles.group}>
                <span className={styles.groupLabel} id="setup-registration-label">
                  {label('registrationLabel')}
                </span>
                <OptionList
                  label={label('registrationLabel')}
                  groups={[{ options: modeChoices }]}
                  selected={mode}
                  onSelect={setMode}
                  disabled={modeLocked}
                />
              </div>
              {lockedNote === null ? null : (
                <p className={styles.lockNote}>
                  <Icon name="shield" size={13} />
                  <span>{lockedNote}</span>
                </p>
              )}
            </div>
            <Button type="submit" busy={pending} busyLabel={label('working')}>
              {label('continue')}
            </Button>
          </form>
        </>
      ) : null}

      {step === 2 ? (

            <Icon name="key" size={32} />
          </span>
          <h1 className={authStyles.title} ref={headingRef} tabIndex={-1}>
            {label('accountTitle')}
          </h1>
          <p className={authStyles.lede}>
            {interpolate(label('accountBody'), { instance: shownInstanceName })}
          </p>
          {alert}
          <form
            className={authStyles.form}
            onSubmit={(event) => {
              event.preventDefault();
              void createAccount();
            }}
          >
            <div className={authStyles.fields}>
              <TextField
                label={label('yourNameLabel')}
                placeholder={label('yourNamePlaceholder')}
                value={displayName}
                onChange={(event) => setDisplayName(event.target.value)}
                autoComplete="given-name"
                maxLength={80}
                invalid={shown?.field === 'displayName'}
              />
              <TextField
                label={label('emailLabel')}
                placeholder={label('emailPlaceholder')}
                hint={label('emailHint')}
                value={email}
                onChange={(event) => setEmail(event.target.value)}
                type="email"
                autoComplete="email"
                autoCapitalize="none"
                spellCheck={false}
                invalid={shown?.field === 'email'}
              />
            </div>
            <Button type="submit" icon="key" busy={busy} busyLabel={label('waiting')}>
              {label('createButton')}
            </Button>
          </form>
          <p className={`${authStyles.hint} ${authStyles.centred}`}>{label('passkeyHint')}</p>
        </>
      ) : null}

      {step === 3 ? (
        <>
          <div className={authStyles.done}>
            <span className={authStyles.check}>
              <Icon name="check" size={26} />
            </span>
            <h1 className={authStyles.title} ref={headingRef} tabIndex={-1}>

              {interpolate(label('doneBody'), {
                name: displayName.trim(),
                instance: shownInstanceName,
              })}
            </p>
          </div>
          <dl className={styles.summary}>
            <div className={styles.summaryRow}>
              <dt>{label('summaryInstance')}</dt>
              <dd>{shownInstanceName}</dd>
            </div>
            <div className={styles.summaryRow}>
              <dt>{label('summaryRegistration')}</dt>
              <dd>{modeLabel}</dd>
```
