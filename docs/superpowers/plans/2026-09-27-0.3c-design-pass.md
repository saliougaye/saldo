# 0.3c — Web design pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Decide how every web page looks (one HTML mockup per page, iterated with the user), turn the `@saldo/ui`
tokens into CSS custom properties the web app reads, and move the phone's chart geometry into renderer-agnostic pure
functions both apps share.

**Architecture:** Three independent parts. **A** is design work gated by the user: one
`docs/superpowers/mockups/2026-09-27-web-<page>-variants.html` per page, Home (with the shell) first; each page
stays open until the user picks a variant, which is recorded in spec §17.1.7. **B** adds a pure `tokensCss()` to
`@saldo/ui`, injects it in `apps/web/app/layout.tsx`, and adds a test that refuses hand-typed colours, font sizes and
radii in any `.module.css`. **C** adds `packages/ui/src/charts/` (cashflow columns, polylines, spend-history
columns, split shares, target ring) and refactors the phone's chart components onto it without changing what they
draw. B and C can run while A waits on the user.

**Tech Stack:** TypeScript strict, Vitest (`packages/ui`, `apps/web`), jest-expo + RNTL (`apps/mobile`),
`react-native-svg`, Next.js App Router, plain HTML/CSS for the mockups.

**Formatting:** the code blocks below are not guaranteed to match Biome's formatter line for line. After writing a
file, run `pnpm biome format --write <file>` before the lint gate; `pnpm lint` counts formatting differences as
errors.

**Spec:** §17.1.7 and D34 (commit `bb30fe0`). Roadmap step 0.3c. Order decided 2026-09-27: 0.3c before 0.3b.

**Decisions taken in this plan (spec silent):**

- Font sizes are emitted in `rem` (`px / 16`), not `px`: a browser's text-size setting then scales them. Every
  size in `fontSize` divides into an exact binary fraction, so nothing rounds.
- Category colours are `--category-<index>`, not by name: the index is what entities store and sync.
- Palette arrays (`heatmap`, `segments`) become `--color-heatmap-0` … `--color-heatmap-4`.
- `motion` emits only durations (`…Ms` → `--motion-<name>: Nms`) and curves (`--motion-easing: cubic-bezier(…)`);
  scales and offsets stay in TypeScript until a web component needs one.
- `layout` becomes `--layout-<name>: Npx`, `tracking` becomes `--tracking-<name>: Nem`.
- The chart functions take the caller's items and hand them back with their geometry (`{ bar, …heights }`), so a
  component maps one array and never indexes a second one (`noUncheckedIndexedAccess`).

## Part A — Mockups, one page at a time

Rules for every mockup file (read them before each task):

- Follow the existing mockups in `docs/superpowers/mockups/` for the frame (caption per variant, dark page behind),
  but the pages here are **browser frames**, not phones: a desktop frame of 1280×800 and, beside or below it, the
  same variant at 390×844.
- The token block at the top uses the **same variable names `tokensCss()` emits** (Part B): `--color-surface`,
  `--color-text-muted`, `--radius-card`, `--font-size-body`, `--motion-easing`, `--layout-card-padding`… Copy the
  values from `packages/ui/src/tokens.ts`. Nothing below the token block types a colour, a radius or a font size;
  a new value the layout needs (sidebar width, content max-width, breakpoint) is declared once in a clearly
  labelled `/* NEW TOKENS */` block so it can move to `tokens.ts`.
- A fixed toolbar: theme (dark / light / system), accent (the four `accentOptions`), and a width toggle (desktop /
  narrow) for when the frames do not fit side by side.
- Data: the prototype's mock data (`docs/design/Spese.dc.html` lines 1811–2031), amounts formatted as
  `@saldo/i18n` does (`1.842,60 €`, `27 mar – 26 apr`), Italian copy. Hidden amounts are not on the web in 0.3
  (§17.1.6), so no mask.
- Behaviour follows the phone (§6 and the prototype's line ranges in `docs/design/README.md`); layout does not have
  to (§17.1.7: the phone is the reference for behaviour, not a template).
- Motion per `emil-design-eng`: pressables `scale(0.97)` on `:active` over `--motion-press`, no animation on
  navigation or keyboard actions, dialogs and popovers enter from `scale(0.96)` + opacity with `ease-out`, exits
  faster than entrances, popovers scale from their trigger, hover effects behind
  `@media (hover: hover) and (pointer: fine)`, everything off under `prefers-reduced-motion`.
- Polish per `better-ui`: concentric radii, tabular numbers on every amount, hit areas ≥ 44px on narrow,
  `text-wrap: pretty` on prose, focus rings visible.
- Each variant has a one-sentence caption that says what it bets on, and the file ends with a short comparison.
- Build with the `web-design-engineer` skill; check with `better-ui` before showing.

`packages/ui/src/css.ts`:

```ts
import {
  categoryColors,
  fontFamily,
  fontSize,
  fontWeight,
  layout,
  motion,
  type Palette,
  palettes,
  radii,
  tracking,
} from './tokens';

/** `textMuted` → `text-muted`: token names as CSS custom property names. */
export function kebab(name: string): string {
  return name.replace(/[A-Z]/g, (letter) => `-${letter.toLowerCase()}`);
}

/**
 * The browser's default root size. Font sizes are written in rem so a user's text-size setting
 * scales them; every size in `fontSize` divides into an exact binary fraction, so nothing rounds.
 */
const ROOT_FONT_PX = 16;

function paletteDeclarations(palette: Palette): string[] {
  const lines: string[] = [];
  for (const [name, value] of Object.entries(palette)) {
    if (typeof value === 'string') {
      lines.push(`--color-${kebab(name)}: ${value};`);
    } else {
      value.forEach((entry: string, index: number) => {
        lines.push(`--color-${kebab(name)}-${index}: ${entry};`);
      });
    }
  }
  return lines;
}

/** Durations (`pressMs` → `--motion-press: 120ms`) and curves; scales and offsets stay in TS. */
function motionDeclarations(): string[] {
  const lines: string[] = [];
  for (const [name, value] of Object.entries(motion)) {
    if (typeof value === 'number') {
      if (name.endsWith('Ms')) lines.push(`--motion-${kebab(name.slice(0, -2))}: ${value}ms;`);
    } else {
      lines.push(`--motion-${kebab(name)}: cubic-bezier(${value.join(', ')});`);
    }
  }
  return lines;
}

/** Everything that does not change with the theme. */
function sharedDeclarations(): string[] {
  return [
    `--font-family: ${fontFamily.primary}, "${fontFamily.fallback}", ui-sans-serif, system-ui, sans-serif;`,
    ...Object.entries(fontSize).map(
      ([name, px]) => `--font-size-${kebab(name)}: ${px / ROOT_FONT_PX}rem;`,
    ),
    ...Object.entries(fontWeight).map(([name, weight]) => `--font-weight-${kebab(name)}: ${weight};`),
    ...Object.entries(tracking).map(([name, em]) => `--tracking-${kebab(name)}: ${em}em;`),
    ...Object.entries(radii).map(([name, px]) => `--radius-${kebab(name)}: ${px}px;`),
    ...Object.entries(layout).map(([name, px]) => `--layout-${kebab(name)}: ${px}px;`),
    ...motionDeclarations(),
    ...categoryColors.map((colour, index) => `--category-${index}: ${colour};`),
  ];
}

function block(selector: string, lines: readonly string[], indent = ''): string {
  const body = lines.map((line) => `${indent}  ${line}`).join('\n');
  return `${indent}${selector} {\n${body}\n${indent}}`;
}

/**
 * The tokens as CSS custom properties (§17.1.7). Dark is the default, as on the phone; `system`
 * follows `prefers-color-scheme` unless the page says `data-theme="dark"`, and `data-theme="light"`
 * forces light. The web's root layout injects this string, so there is no generated file to fall
 * out of step with `tokens.ts`.
 */
export function tokensCss(): string {
  const light = ['color-scheme: light;', ...paletteDeclarations(palettes.light)];
  return [
    block(':root', ['color-scheme: dark;', ...paletteDeclarations(palettes.dark), ...sharedDeclarations()]),
    `@media (prefers-color-scheme: light) {\n${block(':root:not([data-theme="dark"])', light, '  ')}\n}`,
    block('[data-theme="light"]', light),
  ].join('\n\n');
}
```

import { readdirSync, readFileSync } from 'node:fs';
import { join, relative } from 'node:path';

const COLOUR = /#[0-9a-fA-F]{3,8}\b|\b(?:rgba?|hsla?)\(/g;
const SIZE = /\b(?:font-size|border(?:-[a-z]+)*-radius)\s*:\s*[\d.]+(?:px|rem|em)\b/g;

/**
 * §17.1.7: every colour, font size and radius comes from a token variable. Returns what it found
 * typed by hand, in order; comments are skipped so a note may still mention an old value.
 */
export function findHardCodedValues(css: string): string[] {
  const code = css.replace(/\/\*[\s\S]*?\*\//g, '');
  return [...code.matchAll(COLOUR), ...code.matchAll(SIZE)]
    .sort((a, b) => (a.index ?? 0) - (b.index ?? 0))
    .map((match) => match[0]);
}

const ROOT = join(import.meta.dirname, '..', '..');
const SEARCHED = ['app', 'src'];

/** Every `.module.css` of the web app, with its path from `apps/web`. */
export function moduleCssFiles(): { path: string; css: string }[] {
  return SEARCHED.flatMap((dir) =>
    readdirSync(join(ROOT, dir), { recursive: true, encoding: 'utf8' })
      .filter((file) => file.endsWith('.module.css'))
      .map((file) => {
        const full = join(ROOT, dir, file);
        return { path: relative(ROOT, full), css: readFileSync(full, 'utf8') };
      }),
  );
}

export interface Point {
  x: number;
  y: number;
}

/** Strokes of the line charts (§5.6, §6.10). */
export const chartLine = {
  usualStroke: 1.5,
  currentStroke: 2,
  dotRadius: 3,
  sparklineStroke: 1.5,
  hiddenStroke: 1.5,
  hiddenDash: '3 4',
} as const;

/**
 * SVG `points` for a series spread across `width`: `min` sits on the bottom edge and `min + span`
 * on the top. A single value sits in the middle. One decimal is all SVG needs.
 */
export function polylinePoints(
  series: readonly number[],
  width: number,
  height: number,
  min: number,
  span: number,
): string {
  if (series.length === 0) return '';
  const step = series.length === 1 ? 0 : width / (series.length - 1);
  return series
    .map((value, index) => {
      const x = series.length === 1 ? width / 2 : index * step;
      const y = height - ((value - min) / span) * height;
      return `${x.toFixed(1)},${y.toFixed(1)}`;
    })
    .join(' ');
}

/** What a line chart draws while its figures are hidden: "there is a chart here", and no more. */
export function hiddenBaseline(width: number, height: number): string {
  return `0,${(height / 2).toFixed(1)} ${width.toFixed(1)},${(height / 2).toFixed(1)}`;
}

export interface TrendGeometry {
  usual: string;
  current: string;
  /** The dot at the end of the current series; null when there is none. */
  last: Point | null;
}

/**
 * "Andamento del ciclo" (§5.6): cumulative spending of the current cycle over the usual one, on one
 * scale that starts at zero.
 */
export function trendGeometry(
  current: readonly number[],
  usual: readonly number[],
  width: number,
  height: number,
): TrendGeometry {
  const max = Math.max(1, ...current, ...usual);
  const lastValue = current[current.length - 1];
  return {
    usual: polylinePoints(usual, width, height, 0, max),
    current: polylinePoints(current, width, height, 0, max),
    last:
      lastValue === undefined
        ? null
        : { x: current.length <= 1 ? width / 2 : width, y: height - (lastValue / max) * height },
  };
}

/** Month-end balances (§6.10). Zero is always inside the scale, so a negative balance reads as one. */
export function sparklinePoints(series: readonly number[], width: number, height: number): string {
  const min = Math.min(...series, 0);
  const max = Math.max(...series, 0);
  return polylinePoints(series, width, height, min, max - min || 1);
}

  /** Dashes of the divider between what happened and what is expected. */
  dividerDash: '3 4',
} as const;

/**
 * The three diagonals of one 5x5 tile: the middle one plus the two that continue the stripes of
 * the neighbouring tiles, so the pattern is seamless. Lines rather than a rotated rectangle,
 * because `patternTransform` is unreliable in react-native-svg and renders as dots.
 */
export const CASHFLOW_HATCH_PATH = `M0,${HATCH_PERIOD} L${HATCH_PERIOD},0 M-1,1 L1,-1 M${HATCH_PERIOD - 1},${
  HATCH_PERIOD + 1
} L${HATCH_PERIOD + 1},${HATCH_PERIOD - 1}`;

export interface CashflowValues {
  income: number;
  expenses: number;
  /** A forecast period (§5.17): the expenses could end anywhere between `min` and `max`. */
  forecast?: { min: number; max: number };
}

export interface CashflowColumn<T> {
  bar: T;
  /** Bar heights in points, each within `halfHeight`. */
  income: number;
  expenses: number;
  /** The forecast range, measured down from the axis; null for a real period or when hidden. */
  band: { top: number; height: number } | null;
  /** The first forecast column: the seam between what happened and what is expected. */
  divider: boolean;
}

/**
 * Cashflow of §5.7: income above the axis, expenses below it, both halves on one scale so the
 * columns are comparable. A period with nothing in it gets no bar rather than a 1pt stub, so "no
 * data" reads as empty; hidden mode gives every bar the same stub, because the shape of the year
 * would otherwise still say which months were heavy.
 */
export function cashflowColumns<T extends CashflowValues>(
  bars: readonly T[],
  hidden: boolean,
): CashflowColumn<T>[] {
  const max = Math.max(
    1,
    ...bars.flatMap((bar) => [bar.income, bar.expenses, bar.forecast?.max ?? 0]),
  );
  const height = (value: number) => {
    if (hidden) return cashflowChart.hiddenStub;
    return value === 0 ? 0 : Math.max(1, Math.round((value / max) * HALF_HEIGHT));
  };
  return bars.map((bar, index) => {
    const forecast = bar.forecast;
    return {
      bar,
      income: height(bar.income),
      expenses: height(bar.expenses),
      band:
        forecast === undefined || hidden
          ? null
          : {
              top: height(forecast.min),
              height: Math.max(1, height(forecast.max) - height(forecast.min)),
            },
      divider: forecast !== undefined && bars[index - 1]?.forecast === undefined,
    };
  });
}

/**
 * The "Ripartizione" bar of §5.4: each segment's share of the total, in the order given. Null when
 * there is nothing to split, which callers draw as the empty track.
 */
export function splitShares<T extends { amount: number }>(
  segments: readonly T[],
): { segment: T; share: number }[] | null {
  const total = segments.reduce((sum, segment) => sum + segment.amount, 0);
  if (total <= 0) return null;
  return segments.map((segment) => ({ segment, share: segment.amount / total }));
}
