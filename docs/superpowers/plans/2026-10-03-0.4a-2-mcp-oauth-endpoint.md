# 0.4a-2 — OAuth authorization server, the `/mcp` endpoint, the switch, usage — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an MCP client registers itself, sends the user through `/login` and `/oauth/consent`, receives an opaque
token bound to `{PUBLIC_URL}/mcp`, and calls `POST /mcp`, which answers with the read tools of `@saldo/core`
(plus the write tools of 0.4b when the token has `write`); an admin's switch (`mcp.enabled`, `MCP_ENABLED`) turns the
whole thing off; every request leaves a trace in `mcp_usage` at most once a minute per user–client pair.

**Architecture:** `@better-auth/oauth-provider` is mounted on the existing Better Auth instance (OAuth endpoints under
`/api/auth/oauth2/*`), with a small Saldo plugin in front of dynamic client registration and a gate in the catch-all
route that serves only the five endpoints MCP needs and refuses new authorizations while MCP is off. The `/mcp` route
does **not** ask the plugin to validate tokens: it looks the token's hash up in `oauth_access_token` itself (the hash
function is ours, passed to the plugin as `storeTokens.hash`), checks audience, expiry, revocation, the client and
the user, then builds a fresh `McpServer` from core's catalogue and answers through the SDK — 2025-era clients
through a stateless JSON-response transport, 2026-07-28 clients through `createMcpHandler` in `json` mode. Consent
is Saldo's: `submitConsent` writes the `oauth_consent` row and sends the browser back to the plugin's authorize
endpoint, which then issues the code because the consent covers the request.

**Tech Stack:** Next.js 16 route handlers (Web `Request`/`Response`), Better Auth 1.7.7 + `@better-auth/oauth-provider`
1.7.7, `@modelcontextprotocol/server` 2.3.0 (dev: `@modelcontextprotocol/client` 2.3.0 for the end-to-end test),
drizzle + PGlite tests (vitest), Zod 4.

## Decisions (recorded here, as the roadmap asks)

1. **Where the OAuth endpoints live.** Better Auth is mounted at `/api/auth` (`app/api/auth/[...all]/route.ts`), so the
   plugin's endpoints are `/api/auth/oauth2/{register,authorize,token,revoke,introspect}` — the spec's `/auth/oauth2/*`
   is corrected in Task 14. **The issuer is `{PUBLIC_URL}/api/auth`**, not `PUBLIC_URL`: the plugin's issuer is Better
   Auth's `baseURL`, which includes the base path, and with `disableJwtPlugin` there is no other issuer setting. So the
   protected-resource document names `{PUBLIC_URL}/api/auth` as authorization server, and the RFC 8414 document is
   served both at `/.well-known/oauth-authorization-server` (what the spec names) and at
   `/.well-known/oauth-authorization-server/api/auth` (the RFC 8414 path-insertion form MCP clients compute from that
   issuer). The RFC 9728 document is served at `/.well-known/oauth-protected-resource` and, for clients that compute
   the path-aware form, at `/.well-known/oauth-protected-resource/mcp`.
2. **Route handlers, not a rewrite.** Next 16 ignores only `_`-prefixed folders (`route-discovery.js`), so
   `app/.well-known/**/route.ts` works and keeps the 404-when-off logic in TypeScript. Vitest's glob skips dot folders,
   so the logic lives in `src/server/mcp/discovery.ts` and is tested there.
3. **A third, technical scope: `offline_access`.** The plugin issues a refresh token **only** when the scope contains
   `offline_access` (`createUserTokens`: `isRefreshToken = … scopes.includes("offline_access")`). Without it there is no
   refresh token and no 180-day lapse. So `scopes: ['read', 'write', 'offline_access']`; the protected-resource document
   advertises all three, so MCP clients (which request `scopes_supported` when the challenge names none) ask for it.
   The consent page never shows it: it is granted with `read` whenever it was requested. The user-visible scopes stay
   `read` and `write` (D40).
4. **Saldo verifies `/mcp` tokens itself.** The plugin's validation treats an access token whose browser session has
   ended as inactive (`validateOpaqueAccessToken` checks `session.expiresAt`), which would tie an MCP client to the
   web session the consent was given in. Saldo's lookup ignores the session and checks: the row exists for the SHA-256
   of the token, `revoked` is null, `expires_at` is in the future, `resources` contains `{PUBLIC_URL}/mcp`, the client
   is not disabled, the user is not revoked. The hash is the plugin's default algorithm (SHA-256, base64url, no
   padding) but **owned by Saldo**, passed as `storeTokens.hash`, so the two can never drift.
5. **Tokens and lifetimes:** `disableJwtPlugin: true` (opaque only), `accessTokenExpiresIn` 3600,
   `refreshTokenExpiresIn` 180 days (each rotation issues a new one with a new 180 days), `refreshTokenReuseInterval`
   30, `codeExpiresIn` the default 600, `grantTypes: ['authorization_code', 'refresh_token']`.
6. **Registration (RFC 7591), open and public only.** `allowDynamicClientRegistration` and
   `allowUnauthenticatedClientRegistration` on; `rateLimit.register` `{ window: 60, max: 1 }` — the plugin's rule on
   Better Auth's per-IP limiter (same trusted-proxy resolution as sign-in). The plugin's defaults would turn a client
   that omits `token_endpoint_auth_method` into a confidential one and would refuse `http://localhost` redirects for the
   default `application_type: "web"`, which is what Claude Code sends. A Saldo plugin (`mcpRegistrationGuard`, a
   `hooks.before` on `/oauth2/register`) therefore: refuses any `token_endpoint_auth_method` but `none` (and sets it when
   absent); refuses any redirect URI that is not `https://` on a non-loopback host or `http://localhost` /
   `http://127.0.0.1` (any port), no fragment, no credentials; sets `application_type: "native"` when a loopback URI is
   present. Exact match at authorize: `validateRedirectUri: (uri, registered) => registered.includes(uri)` (the
   plugin's default would let a loopback port vary, RFC 8252).
7. **The resource.** `resources: ['{PUBLIC_URL}/mcp']` (seeded into `oauth_resource` on first use, `insertOnly`) and
   `enforcePerClientResources: false` — one resource, any registered client may ask for it. A token without that
   resource in its `resources` is refused by `/mcp` (audience check, D39). `clientPrivileges` and `resourcePrivileges`
   answer `false`: nobody manages clients or resources through the plugin's session-backed CRUD.
8. **The catch-all gate** (`src/server/mcp/oauthGate.ts`): under `/api/auth/oauth2/`, only `register`, `authorize`,
   `token`, `revoke`, `introspect` reach the plugin; everything else (`consent`, `continue`, `userinfo`, `end-session`,
   client/resource/consent CRUD, `public-client*`) answers 404. While MCP is off, `register`, `authorize` and
   `/api/auth/.well-known/*` answer 404 too; `token`, `revoke` and `introspect` keep working (a refresh while off is
   harmless — `/mcp` answers 404 — and a client that kept its refresh token works again when MCP is back on, which is
   what «tokens work again when it is on» needs).
9. **Consent is written by Saldo.** The plugin's own `/oauth2/consent` endpoint reads its request state from an
   `AsyncLocalStorage` that only a call carrying `oauth_query` fills, and needs the session headers. Instead,
   `submitConsent` verifies the signed query (`verifyOAuthQueryParams` with Better Auth's secret), upserts the
   `oauth_consent` row for (client, user) with the granted scopes and the requested resources, and returns
   `/api/auth/oauth2/authorize?{the query without its signature, prompt and max_age, scope = granted}`. The authorize
   endpoint re-validates everything (client, redirect URI, PKCE, resource, session) and, finding a consent that covers
   the request, redirects to the client with the code. A refusal redirects to the client's `redirect_uri` (which the
   signature vouches for) with `error=access_denied`, `state` and `iss`. «Remembered consent» is the plugin's own rule
   (a consent whose scopes and resources cover the request skips the page).
10. **`/login` resumes the flow.** The plugin sends an unauthenticated browser to `/login?{signed query}`.
    `oauthResumePath` verifies that query and returns `/api/auth/oauth2/authorize?{…}`; the login page redirects there
    at once when already signed in, and `LoginForm` navigates there (full navigation) after the passkey ceremony
    instead of `/home`. `loginPage` is `/login`, not `/oauth/consent`: going back through the authorize endpoint keeps
    the plugin's «remembered consent» (a user who consented before is not asked again after signing in), which a
    consent page reached straight from login would skip. For 0.4a-3: should `/oauth/consent` ever see a signed-out
    visitor (session lost between redirects), it redirects to `/login?{the same signed query}` — not `?next=` — and
    this resume takes over; `/login` gets no `next` parameter.
11. **`fresh`** (consent card note): the client was registered less than **10 minutes** ago **and** no user has ever
    consented to it (no `oauth_consent` row for its `client_id`).
12. **`insufficient_scope`.** A `tools/call` naming a write tool (core's `writeTools` or a registered handler) with a
    token that lacks `write` is answered **HTTP 403** with
    `WWW-Authenticate: Bearer error="insufficient_scope", scope="read write", resource_metadata="…"` — what the MCP
    authorization spec and the SDK's client step-up expect — and a JSON-RPC error body
    `{ jsonrpc, id, error: { code: -32600, message: "insufficient_scope", data: { required: "write" } } }`, so the
    spec's «JSON-RPC error `insufficient_scope`» is literally true too.
13. **Transport.** One `McpServer` per request (`capabilities.tools.listChanged: false`, nothing to subscribe to).
    The route reads the body once (≤ 1 MB), then: 2025-era (`isLegacyRequest`) → `WebStandardStreamableHTTPServerTransport`
    with `sessionIdGenerator: undefined, enableJsonResponse: true` (the SDK's own stateless fallback would stream
    SSE); 2026-07-28 → a process-wide `createMcpHandler(factory, { legacy: 'reject', responseMode: 'json' })` whose
    factory picks the per-request server from a `WeakMap<Request, McpServer>`. GET and DELETE answer 405.
14. **Results.** `structuredContent` is the tool's output and `content[0].text` is `JSON.stringify` of the same value.
    The SDK validates `structuredContent` against the tool's `output` schema and turns any thrown error, input
    validation failure or output mismatch into an `isError` result; a write handler's `{ ok: false, message }` becomes
    `isError` with that message. Only infrastructure failures (database down) answer 500.
15. **Order in `/mcp`:** off → 404 · not POST → 405 · declared `Content-Length` > 1 MB → 413 · token → 401/400 ·
    per-token limit (120/min, per process) → 429 · measured body > 1 MB → 413 · not JSON → 400 (JSON-RPC parse error)
    · write tool without `write` → 403 · usage recorded · data loaded · served.
16. **Usage** (`mcp_usage`): in memory per process, per pair: the first request writes at once; later requests inside
    60 s only count; the first request after 60 s writes the count of everything since the last write, in one upsert
    (`calls = calls + n`, `last_used_at = now`). Writes go through `inBackground` (`src/server/background.ts`). Counts not
    yet written are lost if the process stops — accepted, like the rate limiter's per-process state (§18). Revoking
    deletes the pair's row and forgets its pending count.
17. **Foreign keys.** The plugin declares no `onDelete` on its references to `user`; Saldo's tables cascade them (an
    account deleted from `/admin` takes its consents, tokens and usage), and the references to `oauth_client` cascade
    too. `oauth_consent` gets a unique index on (`client_id`, `user_id`).
18. **Settings.** `mcp.enabled` (key `'mcp.enabled'`, a JSON boolean) joins `resolveSettings`: `MCP_ENABLED=true|false`
    wins and locks, else the row, else **on**. Names for 0.4a-3: `mcpEnabled(db, source?)`, `mcpSetting(db, source?)`,
    `saveMcpEnabled(db, actorId, raw, now, source?)`, `pageMcpSetting()`, `MCP_ENABLED_KEY`.
19. **Not here:** the screens (`/oauth/consent`, `/profile/connectors`, `/admin/mcp`, strings) are 0.4a-3, which calls this
    plan's functions; the catalogue is 0.4a-1; write handlers are 0.4b; `SECURITY.md` / `docs/self-hosting.md` sections
    are 0.4a-3's closing task (they describe the screens). CORS on the discovery documents and on `/mcp` is not added:
    the clients named in the spec run outside a browser.

## Assumed core contract (0.4a-1)

This plan compiles against these exports of `@saldo/core` (the shared contract):

```ts
export type ToolScope = 'read' | 'write';
export type ToolContext = { today: LocalDate; timeZone: string };
export type ToolSpec<I, O> = {
  name: string; title: string; description: string; scope: ToolScope;
  input: z.ZodType<I>; output: z.ZodType<O>;
  annotations: { readOnlyHint: boolean; destructiveHint: boolean; idempotentHint: boolean; openWorldHint: false };
};
export type ReadTool<I, O> = ToolSpec<I, O> & { scope: 'read'; run(data: UserData, ctx: ToolContext, input: I): O };
export type WriteToolSpec<I, O> = ToolSpec<I, O> & { scope: 'write' };
export type AnyReadTool;      // type-erased: name/title/description/input/output/annotations + run(data, ctx, input: unknown): unknown
export type AnyWriteToolSpec; // type-erased WriteToolSpec
export const readTools: readonly AnyReadTool[];
export const writeTools: readonly AnyWriteToolSpec[]; // empty until 0.4b
export function assistantInstructions(data: UserData, ctx: ToolContext): string;
```

`input`/`output` are classic `zod` schemas, which carry `~standard.jsonSchema` (Zod ≥ 4.2), so they satisfy the SDK's
`StandardSchemaWithJSON` directly. If `AnyReadTool` exposes `run` differently, adapt `registerReadTool` in Task 11 and
say so in the commit; do not cast.

```ts
import { createHash } from 'node:crypto';

/**
 * How access tokens, refresh tokens and authorization codes are stored (§17.4.1: «stored hashed»).
 * The same algorithm as the plugin's default (`defaultHasher`: SHA-256, base64url, no padding), but
 * passed to it as `storeTokens.hash` so the function `/mcp` looks tokens up with is, by construction,
 * the one they were stored with.
 */
export function hashOAuthToken(token: string): string {
  return createHash('sha256').update(token).digest('base64url');
}

/** RFC 6750 `b64token`. */
const BEARER = /^Bearer +([A-Za-z0-9\-._~+/]+=*) *$/i;

/** The token of `Authorization: Bearer …`, the only place one is accepted (OAuth 2.1). */
export function bearerToken(request: Request): string | undefined {
  const header = request.headers.get('authorization');
  if (header === null) return undefined;
  return BEARER.exec(header)?.[1];
}
```

- [x] **Step 8: Implement `registrationGuard.ts`**

```ts
import type { BetterAuthPlugin } from 'better-auth';
import { APIError, createAuthMiddleware } from 'better-auth/api';

/**
 * §17.4.1: every client is public (PKCE S256, no secret) and its redirect URIs are `https://` or
 * loopback (`http://localhost`, `http://127.0.0.1`, any port).
 *
 * The plugin alone would do otherwise: a client that omits `token_endpoint_auth_method` becomes
 * confidential (`client_secret_basic`) and gets a secret, and the default `application_type: "web"`
 * refuses `http://localhost` — which is exactly what Claude Code registers. So the body is checked
 * and completed here, before the plugin sees it.
 */
export type RegistrationCheck =
  | { ok: true; body: Record<string, unknown> }
  | {
      ok: false;
      error: 'invalid_redirect_uri' | 'invalid_client_metadata';
      description: string;
    };

const LOOPBACK_HOSTS = new Set(['localhost', '127.0.0.1']);

function redirectKind(uri: string): 'https' | 'loopback' | null {
  if (!URL.canParse(uri) || uri.includes('#')) return null;
  const url = new URL(uri);
  if (url.username !== '' || url.password !== '') return null;
  if (url.protocol === 'https:') return LOOPBACK_HOSTS.has(url.hostname) ? null : 'https';
  if (url.protocol === 'http:' && LOOPBACK_HOSTS.has(url.hostname)) return 'loopback';
  return null;
}

export function checkRegistration(raw: unknown): RegistrationCheck {
  if (typeof raw !== 'object' || raw === null || Array.isArray(raw)) {
    return {
      ok: false,
      error: 'invalid_client_metadata',
      description: 'The registration must be a JSON object',
    };
  }
  const body: Record<string, unknown> = Object.fromEntries(Object.entries(raw));
  const method = body.token_endpoint_auth_method;
  if (method !== undefined && method !== 'none') {
    return {
      ok: false,
      error: 'invalid_client_metadata',
      description: 'Only public clients may register: token_endpoint_auth_method must be "none"',
    };
  }
  const uris = body.redirect_uris;
  if (!Array.isArray(uris) || uris.length === 0) {
    return { ok: false, error: 'invalid_redirect_uri', description: 'redirect_uris is required' };
  }
  let loopback = false;
  for (const uri of uris) {
    const kind = typeof uri === 'string' ? redirectKind(uri) : null;
    if (kind === null) {
      return {
        ok: false,
        error: 'invalid_redirect_uri',
        description:
          'Redirect URIs must be https:// on a public host, or http://localhost / http://127.0.0.1',
      };
    }
    if (kind === 'loopback') loopback = true;
  }
  return {
    ok: true,
    body: {
      ...body,
      token_endpoint_auth_method: 'none',
      // The plugin refuses loopback for `web`; `native` also accepts https on a public host.
      application_type: loopback ? 'native' : (body.application_type ?? 'web'),
    },
  };
}

/** `POST /api/auth/oauth2/register` passes through `checkRegistration` first. */
export function mcpRegistrationGuard() {
  return {
    id: 'saldo-mcp-registration',
    hooks: {
      before: [
        {
          matcher: (context: { path?: string }) => context.path === '/oauth2/register',
          handler: createAuthMiddleware(async (ctx) => {
            const checked = checkRegistration(ctx.body);
            if (!checked.ok) {
              throw new APIError('BAD_REQUEST', {
                error: checked.error,
                error_description: checked.description,
              });
            }
            return { context: { body: checked.body } };
          }),
        },
      ],
    },
  } satisfies BetterAuthPlugin;
}
```

If `satisfies BetterAuthPlugin` rejects the `matcher` parameter type, type it as Better Auth's own
`HookEndpointContext` (`import type { HookEndpointContext } from 'better-auth'`) and keep the body unchanged.

```ts
import { getDb } from '../db/client';
import type { ServerDatabase } from '../db/types';
import { mcpEnabled } from '../settings/serverSettings';

const OAUTH_PREFIX = '/api/auth/oauth2/';
const WELL_KNOWN_PREFIX = '/api/auth/.well-known/';

/** What MCP clients use (§17.4.1). Everything else the plugin serves, Saldo does not offer. */
const OFFERED = new Set(['register', 'authorize', 'token', 'revoke', 'introspect']);

/**
 * Refused while MCP is off: what starts a new authorization. Token, revoke and introspect stay — a
 * refresh while off is harmless (`/mcp` answers 404), and a client that keeps its refresh token works
 * again when MCP is back on.
 */
const NEEDS_MCP = new Set(['register', 'authorize']);

const notFound = () => Response.json({ error: 'not_found' }, { status: 404 });

/**
 * Runs in the catch-all route before Better Auth: `null` lets the request through. The plugin's
 * consent/continue endpoints, its userinfo and end-session, and its client, resource and consent CRUD
 * all answer 404 — Saldo's consent is `/oauth/consent` (`consent.ts`), and nobody manages clients.
 */
export async function oauthGate(
  request: Request,
  db: ServerDatabase = getDb(),
): Promise<Response | null> {
  const { pathname } = new URL(request.url);
  if (pathname.startsWith(WELL_KNOWN_PREFIX)) return (await mcpEnabled(db)) ? null : notFound();
  if (!pathname.startsWith(OAUTH_PREFIX)) return null;
  const endpoint = pathname.slice(OAUTH_PREFIX.length);
  if (!OFFERED.has(endpoint)) return notFound();
  if (NEEDS_MCP.has(endpoint) && !(await mcpEnabled(db))) return notFound();
  return null;
}
```

```ts
import { sql } from 'drizzle-orm';
import { inBackground } from '../background';
import { getDb } from '../db/client';
import { mcpUsage } from '../db/schema';

/** §17.4.3: `mcp_usage` is written at most once a minute per (user, client). */
export const USAGE_WRITE_INTERVAL_MS = 60_000;

interface PairState {
  lastWriteAt: number;
  /** Calls counted since the last write. */
  pending: number;
}

/**
 * Per process, like the rate limiters (§18): a second replica keeps its own counts and writes its own
 * minute. Counts not yet written are lost when the process stops — at most one minute of «calls» per
 * pair. Bounded by the number of (user, client) pairs that ever called, which is small.
 */
const pairs = new Map<string, PairState>();
const pairKey = (userId: string, clientId: string) => `${userId}\u0000${clientId}`;

/**
 * Counts one `/mcp` request. The first request of a pair writes at once; the next ones inside the
 * minute only count; the first one after the minute writes everything counted since, in one upsert.
 * The write runs in the background and never holds the response.
 */
export function recordMcpUsage(userId: string, clientId: string, now: Date): void {
  const key = pairKey(userId, clientId);
  const state = pairs.get(key) ?? { lastWriteAt: Number.NEGATIVE_INFINITY, pending: 0 };
  state.pending += 1;
  pairs.set(key, state);
  if (now.getTime() - state.lastWriteAt < USAGE_WRITE_INTERVAL_MS) return;
  const calls = state.pending;
  state.pending = 0;
  state.lastWriteAt = now.getTime();
  inBackground(async () => {
    await getDb()
      .insert(mcpUsage)
      .values({ userId, clientId, lastUsedAt: now, calls })
      .onConflictDoUpdate({
        target: [mcpUsage.userId, mcpUsage.clientId],
        set: { calls: sql`${mcpUsage.calls} + ${calls}`, lastUsedAt: now },
      });
  });
}

/** On revocation: the pair starts again from nothing. */
export function forgetMcpUsage(userId: string, clientId: string): void {
  pairs.delete(pairKey(userId, clientId));
}

export function resetMcpUsageForTests(): void {
  pairs.clear();
}
```

```ts
/**
 * §17.4.2: 120 requests per minute per token, in memory and per process like Better Auth's limiter
 * (§18: a second replica multiplies it). The key is the token's hash, never the token.
 */
export type LimitVerdict = { allowed: true } | { allowed: false; retryAfterSeconds: number };

export interface FixedWindowLimiter {
  allow(key: string, nowMs: number): LimitVerdict;
  size(): number;
  reset(): void;
}

interface Window {
  startedAt: number;
  count: number;
}

export function createFixedWindowLimiter(options: {
  max: number;
  windowMs: number;
  maxKeys?: number;
}): FixedWindowLimiter {
  const maxKeys = options.maxKeys ?? 10_000;
  const windows = new Map<string, Window>();

  function sweep(nowMs: number): void {
    for (const [key, window] of windows) {
      if (nowMs - window.startedAt >= options.windowMs) windows.delete(key);
    }
    while (windows.size >= maxKeys) {
      const oldest = windows.keys().next();
      if (oldest.done === true) break;
      windows.delete(oldest.value);
    }
  }

  return {
    allow(key, nowMs) {
      const current = windows.get(key);
      if (current === undefined || nowMs - current.startedAt >= options.windowMs) {
        if (current === undefined && windows.size >= maxKeys) sweep(nowMs);
        windows.delete(key);
        windows.set(key, { startedAt: nowMs, count: 1 });
        return { allowed: true };
      }
      if (current.count < options.max) {
        current.count += 1;
        return { allowed: true };
      }
      const waitMs = options.windowMs - (nowMs - current.startedAt);
      return { allowed: false, retryAfterSeconds: Math.max(1, Math.ceil(waitMs / 1000)) };
    },
    size: () => windows.size,
    reset() {
      windows.clear();
    },
  };
}

export const MCP_REQUESTS_PER_MINUTE = 120;

/** The process's one `/mcp` limiter. */
export const mcpRequestLimiter: FixedWindowLimiter = createFixedWindowLimiter({
  max: MCP_REQUESTS_PER_MINUTE,
  windowMs: 60_000,
});
```

```ts
import type { ToolScope } from '@saldo/core';
import { eq } from 'drizzle-orm';
import { getDb } from '../db/client';
import { oauthAccessToken, oauthClient, user } from '../db/schema';
import { bearerToken, hashOAuthToken } from './oauthToken';
import { mcpResourceUrl, protectedResourceMetadataUrl } from './urls';

/** Who is calling `/mcp`: the user who consented, the client they consented to, what they granted. */
export type McpPrincipal = { userId: string; clientId: string; scopes: ToolScope[] };

/** What the lookup reads for a token hash. */
export interface AccessTokenRow {
  userId: string;
  clientId: string;
  scopes: string[];
  resources: string[] | null;
  expiresAt: Date;
  revoked: Date | null;
  clientDisabled: boolean | null;
  banned: boolean | null;
}

const TOOL_SCOPES: readonly string[] = ['read', 'write'] satisfies readonly ToolScope[];
const isToolScope = (scope: string): scope is ToolScope => TOOL_SCOPES.includes(scope);

/**
 * §17.4.1, decision 4: the whole acceptance rule, pure. The browser session the consent was given in
 * is deliberately not consulted — an MCP client must not stop when its user signs out of the web.
 */
export function acceptAccessToken(
  row: AccessTokenRow | null,
  now: Date,
  resource: string,
): { ok: true; principal: McpPrincipal } | { ok: false } {
  if (row === null) return { ok: false };
  if (row.revoked !== null) return { ok: false };
  if (row.expiresAt.getTime() <= now.getTime()) return { ok: false };
  if (!(row.resources ?? []).includes(resource)) return { ok: false };
  if (row.clientDisabled === true || row.banned === true) return { ok: false };
  return {
    ok: true,
    principal: { userId: row.userId, clientId: row.clientId, scopes: row.scopes.filter(isToolScope) },
  };
}

/** RFC 6750 §3 + RFC 9728 §5.1. With no error it is exactly `Bearer resource_metadata="…"`. */
export function bearerChallenge(
  params: { error?: 'invalid_token' | 'invalid_request' | 'insufficient_scope'; scope?: string } = {},
): string {
  const parts: string[] = [];
  if (params.error !== undefined) parts.push(`error="${params.error}"`);
  if (params.scope !== undefined) parts.push(`scope="${params.scope}"`);
  parts.push(`resource_metadata="${protectedResourceMetadataUrl()}"`);
  return `Bearer ${parts.join(', ')}`;
}

function unauthorized(invalid: boolean): Response {
  return Response.json(
    invalid
      ? { error: 'invalid_token', error_description: 'The access token is not valid' }
      : { error: 'unauthorized', error_description: 'A bearer token is required' },
    {
      status: 401,
      headers: { 'www-authenticate': bearerChallenge(invalid ? { error: 'invalid_token' } : {}) },
    },
  );
}

/**
 * The first thing `/mcp` does after the switch. The token is accepted only in the header (OAuth 2.1),
 * looked up by its hash, and never logged.
 */
export async function verifyMcpRequest(
  request: Request,
): Promise<{ ok: true; principal: McpPrincipal } | { ok: false; response: Response }> {
  if (new URL(request.url).searchParams.has('access_token')) {
    return {
      ok: false,
      response: Response.json(
        {
          error: 'invalid_request',
          error_description: 'An access token is accepted only in the Authorization header',
        },
        { status: 400, headers: { 'www-authenticate': bearerChallenge({ error: 'invalid_request' }) } },
      ),
    };
  }
  const token = bearerToken(request);
  if (token === undefined) return { ok: false, response: unauthorized(false) };
  const [row] = await getDb()
    .select({
      userId: user.id,
      clientId: oauthAccessToken.clientId,
      scopes: oauthAccessToken.scopes,
      resources: oauthAccessToken.resources,
      expiresAt: oauthAccessToken.expiresAt,
      revoked: oauthAccessToken.revoked,
      clientDisabled: oauthClient.disabled,
      banned: user.banned,
    })
    .from(oauthAccessToken)
    .innerJoin(oauthClient, eq(oauthClient.clientId, oauthAccessToken.clientId))
    .innerJoin(user, eq(user.id, oauthAccessToken.userId))
    .where(eq(oauthAccessToken.token, hashOAuthToken(token)))
    .limit(1);
  const verdict = acceptAccessToken(row ?? null, new Date(), mcpResourceUrl());
  if (!verdict.ok) return { ok: false, response: unauthorized(true) };
  return verdict;
}
```

```ts
import { verifyOAuthQueryParams } from '@better-auth/oauth-provider';
import type { ToolScope } from '@saldo/core';
import { and, eq } from 'drizzle-orm';
import { auth } from '../auth/auth';
import { getDb } from '../db/client';
import { oauthClient, oauthConsent } from '../db/schema';
import { log, shortId } from '../log';
import { mcpEnabled } from '../settings/serverSettings';
import { oauthIssuer } from './urls';

/** Decision 11: a client registered less than this long ago, that nobody has consented to, is «fresh». */
export const FRESH_CLIENT_MS = 10 * 60_000;

/**
 * Added by the plugin to sign the query, or meaningless once the user is on the consent page:
 * never forwarded to the authorize endpoint. `prompt` and `max_age` would send the browser back to
 * `/login` or to this page in a loop.
 */
const NOT_FORWARDED = new Set(['sig', 'exp', 'ba_iat', 'ba_param', 'ba_pl', 'prompt', 'max_age']);

export type ConsentRequest = {
  clientId: string;
  clientName: string;
  redirectHost: string;
  requestedScopes: ToolScope[];
  fresh: boolean;
  previouslyAuthorizedAt: Date | null;
};

/** Next's `searchParams` as the exact query the plugin signed (repeated keys kept: `ba_param`, `resource`). */
export function consentSearchParams(
  record: Record<string, string | string[] | undefined>,
): URLSearchParams {
  const params = new URLSearchParams();
  for (const [key, value] of Object.entries(record)) {
    if (value === undefined) continue;
    for (const one of Array.isArray(value) ? value : [value]) params.append(key, one);
  }
  return params;
}

/** The signature and expiry the plugin put on the query it redirected with (`verifyOAuthQueryParams`). */
export async function signedQueryHolds(searchParams: URLSearchParams): Promise<boolean> {
  if (!searchParams.has('sig')) return false;
  const { secret } = await auth().$context;
  return verifyOAuthQueryParams(searchParams.toString(), secret);
}

/** The authorize query to resume with: the signed one without its signature, optionally narrowed. */
export function authorizeQuery(searchParams: URLSearchParams, scope?: string): URLSearchParams {
  const params = new URLSearchParams();
  for (const [key, value] of searchParams) {
    if (!NOT_FORWARDED.has(key)) params.append(key, value);
  }
  if (scope !== undefined) params.set('scope', scope);
  return params;
}

/** `read` is always asked for and always granted (the consent page marks it «richiesto»). */
export function requestedToolScopes(scope: string | null): ToolScope[] {
  return (scope ?? '').split(' ').includes('write') ? ['read', 'write'] : ['read'];
}

/** What a consent grants: `read`, `write` if asked and kept, `offline_access` if asked (decision 3). */
export function grantedScopes(
  requested: readonly ToolScope[],
  chosen: readonly ToolScope[],
  originalScope: string | null,
): string[] {
  const tools = requested.filter((scope) => scope === 'read' || chosen.includes(scope));
  const offline = (originalScope ?? '').split(' ').includes('offline_access') ? ['offline_access'] : [];
  return [...tools, ...offline];
}

type Inspected =
  | { ok: true; request: ConsentRequest; redirectUri: string }
  | { ok: false; reason: 'invalid' | 'disabled' };

async function inspect(searchParams: URLSearchParams, userId: string): Promise<Inspected> {
  const db = getDb();
  if (!(await mcpEnabled(db))) return { ok: false, reason: 'disabled' };
  if (!(await signedQueryHolds(searchParams))) return { ok: false, reason: 'invalid' };
  const clientId = searchParams.get('client_id');
  const redirectUri = searchParams.get('redirect_uri');
  if (clientId === null || redirectUri === null || !URL.canParse(redirectUri)) {
    return { ok: false, reason: 'invalid' };
  }
  const [client] = await db
    .select({ name: oauthClient.name, disabled: oauthClient.disabled, createdAt: oauthClient.createdAt })
    .from(oauthClient)
    .where(eq(oauthClient.clientId, clientId));
  if (client === undefined || client.disabled === true) return { ok: false, reason: 'invalid' };
  const [mine] = await db
    .select({ createdAt: oauthConsent.createdAt })
    .from(oauthConsent)
    .where(and(eq(oauthConsent.clientId, clientId), eq(oauthConsent.userId, userId)));
  const [anyone] = await db
    .select({ id: oauthConsent.id })
    .from(oauthConsent)
    .where(eq(oauthConsent.clientId, clientId))
    .limit(1);
  const fresh =
    anyone === undefined &&
    client.createdAt !== null &&
    Date.now() - client.createdAt.getTime() < FRESH_CLIENT_MS;
  return {
    ok: true,
    redirectUri,
    request: {
      clientId,
      clientName: client.name ?? clientId,
      redirectHost: new URL(redirectUri).host,
      requestedScopes: requestedToolScopes(searchParams.get('scope')),
      fresh,
      previouslyAuthorizedAt: mine?.createdAt ?? null,
    },
  };
}

/**
 * §17.4.3, `/oauth/consent`: what the page shows. `invalid` for a query the plugin did not sign (or
 * signed more than ten minutes ago), an unknown or disabled client; `disabled` while MCP is off.
 */
export async function readConsentRequest(
  searchParams: URLSearchParams,
  userId: string,
): Promise<{ ok: true; request: ConsentRequest } | { ok: false; reason: 'invalid' | 'disabled' }> {
  const inspected = await inspect(searchParams, userId);
  return inspected.ok ? { ok: true, request: inspected.request } : inspected;
}

/** RFC 6749 §4.1.2.1 + RFC 9207: back to the client, which the signature vouches for. */
export function deniedRedirect(redirectUri: string, state: string | null): string {
  const url = new URL(redirectUri);
  url.searchParams.set('error', 'access_denied');
  url.searchParams.set('error_description', 'The user denied access');
  if (state !== null) url.searchParams.set('state', state);
  url.searchParams.set('iss', oauthIssuer());
  return url.toString();
}

/**
 * «Autorizza» / «Nega» (decision 9). Accepting stores the consent and returns the authorize URL to
 * navigate to, where the plugin re-checks everything and issues the code; refusing returns the
 * client's `redirect_uri` with `access_denied`. A query that no longer holds (or MCP switched off
 * meanwhile) returns the consent page itself, which then shows why.
 */
export async function submitConsent(args: {
  searchParams: URLSearchParams;
  userId: string;
  accept: boolean;
  scopes: ToolScope[];
}): Promise<{ redirectTo: string }> {
  const inspected = await inspect(args.searchParams, args.userId);
  if (!inspected.ok) return { redirectTo: `/oauth/consent?${args.searchParams.toString()}` };
  const { request, redirectUri } = inspected;
  if (!args.accept) {
    log('mcp', 'consent refused', { user: shortId(args.userId), client: shortId(request.clientId) });
    return { redirectTo: deniedRedirect(redirectUri, args.searchParams.get('state')) };
  }
  const scopes = grantedScopes(request.requestedScopes, args.scopes, args.searchParams.get('scope'));
  const now = new Date();
  await getDb()
    .insert(oauthConsent)
    .values({
      id: crypto.randomUUID(),
      clientId: request.clientId,
      userId: args.userId,
      scopes,
      resources: args.searchParams.getAll('resource'),
      requestedUserInfoClaims: [],
      createdAt: now,
      updatedAt: now,
    })
    .onConflictDoUpdate({
      target: [oauthConsent.clientId, oauthConsent.userId],
      set: { scopes, resources: args.searchParams.getAll('resource'), updatedAt: now },
    });
  log('mcp', 'consent given', {
    user: shortId(args.userId),
    client: shortId(request.clientId),
    scopes: scopes.join(' '),
  });
  return {
    redirectTo: `/api/auth/oauth2/authorize?${authorizeQuery(args.searchParams, scopes.join(' ')).toString()}`,
  };
}
```

```ts
  mcpUsage,
  oauthAccessToken,
  oauthClient,
  oauthConsent,
  oauthRefreshToken,
  user,
} from '../db/schema';
import { log, shortId } from '../log';
import { forgetMcpUsage } from './usage';

/** One row of «Autorizzate» on `/profile/connectors` (§17.4.3). */
export type Connector = {
  clientId: string;
  /** The name the client registered itself with; its id when it gave none. */
  name: string;
  redirectHost: string;
  /** Only the granted tool scopes («Lettura», «Scrittura»); `offline_access` is not shown. */
  scopes: ToolScope[];
  authorizedAt: Date;
  lastUsedAt: Date | null;
  calls: number;
};

const toolScopes = (scopes: readonly string[]): ToolScope[] =>
  scopes.filter((scope): scope is ToolScope => scope === 'read' || scope === 'write');

function hostOf(uris: readonly string[]): string {
  const first = uris[0];
  return first !== undefined && URL.canParse(first) ? new URL(first).host : '';
}

/** The user's consents, newest first, with what `mcp_usage` knows. */
export async function listConnectors(userId: string): Promise<Connector[]> {
  const rows = await getDb()
    .select({
      clientId: oauthConsent.clientId,
      scopes: oauthConsent.scopes,
      authorizedAt: oauthConsent.createdAt,
      name: oauthClient.name,
      redirectUris: oauthClient.redirectUris,
      lastUsedAt: mcpUsage.lastUsedAt,
      calls: mcpUsage.calls,
    })
    .from(oauthConsent)
    .innerJoin(oauthClient, eq(oauthClient.clientId, oauthConsent.clientId))
    .leftJoin(
      mcpUsage,
      and(eq(mcpUsage.clientId, oauthConsent.clientId), eq(mcpUsage.userId, oauthConsent.userId)),
    )
    .where(eq(oauthConsent.userId, userId))
    .orderBy(desc(oauthConsent.createdAt));
  return rows.map((row) => ({
    clientId: row.clientId,
    name: row.name ?? row.clientId,
    redirectHost: hostOf(row.redirectUris),
    scopes: toolScopes(row.scopes),
    authorizedAt: row.authorizedAt,
    lastUsedAt: row.lastUsedAt,
    calls: row.calls ?? 0,
  }));
}

/**
 * «Revoca accesso» (§17.4.1): the pair's consent and every token, in one transaction, so the client's
 * next request is a 401 and it has to be authorized again. Its usage goes too.
 */
export async function revokeConnector(userId: string, clientId: string): Promise<void> {
  await getDb().transaction(async (tx) => {
    await tx
      .delete(oauthAccessToken)
      .where(and(eq(oauthAccessToken.userId, userId), eq(oauthAccessToken.clientId, clientId)));
    await tx
      .delete(oauthRefreshToken)
      .where(and(eq(oauthRefreshToken.userId, userId), eq(oauthRefreshToken.clientId, clientId)));
    await tx
      .delete(oauthConsent)
      .where(and(eq(oauthConsent.userId, userId), eq(oauthConsent.clientId, clientId)));
    await tx.delete(mcpUsage).where(and(eq(mcpUsage.userId, userId), eq(mcpUsage.clientId, clientId)));
  });
  forgetMcpUsage(userId, clientId);
  log('mcp', 'app revoked', { user: shortId(userId), client: shortId(clientId) });
}

const WEEK_MS = 7 * 86_400_000;

export async function mcpAdminStats(now: Date): Promise<{
  usersWithConnectors: number;
  totalUsers: number;
  connectorsAuthorized: number;
  connectorsUsedLast7Days: number;
}> {
  const db = getDb();
  const [users] = await db.select({ n: count() }).from(user);
  const [consents] = await db
    .select({ connectors: count(), users: countDistinct(oauthConsent.userId) })

    .select({ n: count() })

    )

  return {
    usersWithConnectors: consents?.users ?? 0,
    totalUsers: users?.n ?? 0,
    connectorsAuthorized: consents?.connectors ?? 0,
    connectorsUsedLast7Days: used?.n ?? 0,
  };
}
```

```ts
import {
  type AuthInfo,
  createMcpHandler,
  isLegacyRequest,
  type McpHttpHandler,
  type McpServer,
  WebStandardStreamableHTTPServerTransport,
} from '@modelcontextprotocol/server';
import { log } from '../log';

/** §17.4.2: body limit of `/mcp`. */
export const MCP_MAX_BODY_BYTES = 1024 * 1024;

/** The server built for each in-flight 2026-07-28 request, found by the shared handler's factory. */
const servers = new WeakMap<Request, McpServer>();
let modern: McpHttpHandler | null = null;

/**
 * Created on first use, not at import: `next build` imports the route, and the handler logs a
 * one-line warning about `json` mode when it is created.
 */
function modernHandler(): McpHttpHandler {
  modern ??= createMcpHandler(
    ({ requestInfo }) => {
      const server = requestInfo === undefined ? undefined : servers.get(requestInfo);
      if (server === undefined) throw new Error('No MCP server was built for this request');
      return server;
    },
    {
      legacy: 'reject',
      responseMode: 'json',
      maxRequestBodySize: MCP_MAX_BODY_BYTES,
      onerror: (error) => log('mcp', 'exchange refused', { kind: error.name }),
    },
  );
  return modern;
}

/**
 * Serves one already-authenticated exchange (decision 13). The body was read once by the route and is
 * handed over parsed. 2025-era clients (`initialize`, no per-request envelope) get a stateless
 * transport with JSON responses; 2026-07-28 clients go through `createMcpHandler` in `json` mode.
 * Either way the server instance serves this request and is dropped.
 */
export async function serveMcpExchange(
  server: McpServer,
  request: Request,
  body: unknown,
  authInfo: AuthInfo,
): Promise<Response> {
  if (await isLegacyRequest(request, body, { maxRequestBodySize: MCP_MAX_BODY_BYTES })) {
    const transport = new WebStandardStreamableHTTPServerTransport({
      sessionIdGenerator: undefined,
      enableJsonResponse: true,
      maxRequestBodySize: MCP_MAX_BODY_BYTES,
    });
    await server.connect(transport);
    try {
      return await transport.handleRequest(request, { parsedBody: body, authInfo });
    } finally {
      await server.close();
    }
  }
  servers.set(request, server);
  try {
    return await modernHandler().fetch(request, { parsedBody: body, authInfo });
  } finally {
    servers.delete(request);
  }
}
```

```ts
import { type CallToolResult, McpServer } from '@modelcontextprotocol/server';
import {
  type AnyReadTool,
  assistantInstructions,
  readTools,
  type ToolContext,
  type UserData,
} from '@saldo/core';
import { APP_VERSION } from '../version';
import type { McpPrincipal } from './token';
import type { AnyWriteToolHandler } from './types';

/** §17.4.2: `structuredContent`, and the same JSON as `content[0].text` for clients that read only text. */
export function toolResult(value: unknown): CallToolResult {
  return { content: [{ type: 'text', text: JSON.stringify(value) }], structuredContent: value };
}

/** A refused write, readable by the model; never an exception, never a 500. */
export function toolError(message: string): CallToolResult {
  return { content: [{ type: 'text', text: message }], isError: true };
}

function registerReadTool(server: McpServer, tool: AnyReadTool, data: UserData, ctx: ToolContext): void {
  server.registerTool(
    tool.name,
    {
      title: tool.title,
      description: tool.description,
      inputSchema: tool.input,
      outputSchema: tool.output,
      annotations: tool.annotations,
    },
    async (input) => toolResult(tool.run(data, ctx, input)),
  );
}

function registerWriteTool(
  server: McpServer,
  handler: AnyWriteToolHandler,
  principal: McpPrincipal,
  ctx: ToolContext,
): void {
  const { spec } = handler;
  server.registerTool(
    spec.name,
    {
      title: spec.title,
      description: spec.description,
      inputSchema: spec.input,
      outputSchema: spec.output,
      annotations: spec.annotations,
    },
    async (input) => {
      const result = await handler.handle(principal, input, ctx);
      return result.ok ? toolResult(result.value) : toolError(result.message);
    },
  );
}

/**
 * One server per request (§17.4.2), from core's catalogue, holding this user's data and «today».
 * Tools are filtered by scope here, so a `read` token never even lists a write tool. The SDK
 * validates input and output against each tool's schemas and turns any error into an `isError`
 * result. Nothing to subscribe to: `listChanged` is off.
 */
export function buildMcpServer(args: {
  data: UserData;
  ctx: ToolContext;
  principal: McpPrincipal;
  writeHandlers: readonly AnyWriteToolHandler[];
}): McpServer {
  const { data, ctx, principal, writeHandlers } = args;
  const server = new McpServer(
    { name: 'saldo', version: APP_VERSION },
    {
      instructions: assistantInstructions(data, ctx),
      capabilities: { tools: { listChanged: false } },
    },
  );
  if (principal.scopes.includes('read')) {
    for (const tool of readTools) registerReadTool(server, tool, data, ctx);
  }
  if (principal.scopes.includes('write')) {
    for (const handler of writeHandlers) registerWriteTool(server, handler, principal, ctx);
  }
  return server;
}
```

```ts
export interface McpEndpointDeps {
  writeHandlers: readonly AnyWriteToolHandler[];
  now: () => Date;
  limiter: FixedWindowLimiter;
}

const defaults: McpEndpointDeps = {
  writeHandlers: writeToolHandlers,
  now: () => new Date(),
  limiter: mcpRequestLimiter,

const jsonRpcError = (id: unknown, code: number, message: string, status: number, data?: unknown) =>
  Response.json(
    { jsonrpc: '2.0', id: id ?? null, error: data === undefined ? { code, message } : { code, message, data } },
    { status },
  );

function declaredTooLarge(request: Request): boolean {
  const declared = Number(request.headers.get('content-length') ?? Number.NaN);
  return Number.isFinite(declared) && declared > MCP_MAX_BODY_BYTES;
}

function parseJson(text: string): { ok: true; value: unknown } | { ok: false } {
  try {
    return { ok: true, value: JSON.parse(text) };
  } catch {
    return { ok: false };
  }
}

/** The `tools/call` messages of a body (one message, or a 2025-03 batch), with their ids. */
export function toolCalls(body: unknown): Array<{ id: unknown; name: string }> {
  const messages: unknown[] = Array.isArray(body) ? body : [body];
  const calls: Array<{ id: unknown; name: string }> = [];
  for (const message of messages) {
    if (typeof message !== 'object' || message === null) continue;
    if (Reflect.get(message, 'method') !== 'tools/call') continue;
    const params: unknown = Reflect.get(message, 'params');
    const name = typeof params === 'object' && params !== null ? Reflect.get(params, 'name') : undefined;
    if (typeof name === 'string') calls.push({ id: Reflect.get(message, 'id'), name });
  }
  return calls;
}

/** Decision 12: HTTP 403 with the step-up challenge, and a JSON-RPC error saying `insufficient_scope`. */
function insufficientScope(id: unknown, required: ToolScope): Response {
  return Response.json(
    {
      jsonrpc: '2.0',
      id: id ?? null,
      error: { code: -32600, message: 'insufficient_scope', data: { required } },
    },
    {
      status: 403,
      headers: {
        'www-authenticate': bearerChallenge({ error: 'insufficient_scope', scope: 'read write' }),
      },
    },
  );
}

/**
 * `POST /mcp` (§17.4.2), in decision 15's order. The route is thin: authenticate → `loadUserData` and
 * `todayFor` → build the server → answer. The token is never logged; the AuthInfo handed to the SDK
 * carries its hash.
 */
export async function serveMcp(request: Request, deps: McpEndpointDeps = defaults): Promise<Response> {
  const startedAt = Date.now();
  try {
    if (!(await mcpEnabled(getDb()))) return Response.json({ error: 'not_found' }, { status: 404 });
    if (request.method !== 'POST') return new Response(null, { status: 405, headers: { allow: 'POST' } });
    if (declaredTooLarge(request)) return Response.json({ error: 'payload_too_large' }, { status: 413 });

    const verified = await verifyMcpRequest(request);
    if (!verified.ok) return verified.response;
    const { principal } = verified;
    const now = deps.now();
    const tokenHash = hashOAuthToken(bearerToken(request) ?? '');
    const limit = deps.limiter.allow(tokenHash, now.getTime());
    if (!limit.allowed) {
      return Response.json(
        { error: 'rate_limited' },
        { status: 429, headers: { 'retry-after': String(limit.retryAfterSeconds) } },
      );
    }

    const text = await request.text();
    if (Buffer.byteLength(text, 'utf8') > MCP_MAX_BODY_BYTES) {
      return Response.json({ error: 'payload_too_large' }, { status: 413 });
    }
    const parsed = parseJson(text);
    if (!parsed.ok) return jsonRpcError(null, -32700, 'Parse error', 400);

    if (!principal.scopes.includes('write')) {
      const writeNames = new Set([
        ...writeTools.map((tool) => tool.name),
        ...deps.writeHandlers.map((handler) => handler.spec.name),
      ]);
      const blocked = toolCalls(parsed.value).find((call) => writeNames.has(call.name));
      if (blocked !== undefined) return insufficientScope(blocked.id, 'write');
    }

    recordMcpUsage(principal.userId, principal.clientId, now);
    const data = await loadUserData(principal.userId);
    const ctx = todayFor(data.settings, env().defaultTimeZone, now);
    const server = buildMcpServer({ data, ctx, principal, writeHandlers: deps.writeHandlers });
    const response = await serveMcpExchange(server, request, parsed.value, {
      token: tokenHash,
      clientId: principal.clientId,
      scopes: principal.scopes,
      resource: new URL(mcpResourceUrl()),
    });
    log('mcp', 'request served', {
      user: shortId(principal.userId),
      client: shortId(principal.clientId),
      status: response.status,
      took: ms(startedAt),
    });
    return response;
  } catch (error) {
    // Infrastructure only (database, …): tool failures never reach here. The name, not the message.
    log('mcp', 'request failed', { kind: error instanceof Error ? error.name : 'unknown' });
    return jsonRpcError(null, -32603, 'Internal error', 500);
  }
}
```

```ts
function router(ip: string): FetchLike {
  return async (input, init) => {
    const original = new Request(input, init);
    const headers = new Headers(original.headers);
    headers.set('x-forwarded-for', ip);
    const body =
      original.method === 'GET' || original.method === 'HEAD' ? undefined : await original.arrayBuffer();
    const request = new Request(original.url, { method: original.method, headers, body });
    const { pathname } = new URL(request.url);
    if (pathname.startsWith('/.well-known/oauth-protected-resource')) return protectedResourceMetadataResponse();
    if (pathname.startsWith('/.well-known/oauth-authorization-server')) {
      return authorizationServerMetadataResponse(request);
    }
    if (pathname.startsWith('/api/auth/')) return request.method === 'GET' ? authGet(request) : authPost(request);
    if (pathname === '/mcp') {
      if (request.method === 'POST') return mcpPost(request);
      return request.method === 'DELETE' ? mcpDelete(request) : mcpGet(request);
    }
    return new Response('not found', { status: 404 });
  };
}

  expect(response.status).toBe(302);
  return new URL(response.headers.get('location') ?? '', ORIGIN);
}
```
