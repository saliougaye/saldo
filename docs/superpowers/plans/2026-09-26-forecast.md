# Forecast: the next three periods, from what already repeats

**Goal.** Statistics shows, on the current period, three forecast periods in the cashflow chart and a sheet with the
detail (spec D29, §5.7, §5.17; ROADMAP 0.2 «Forecast»).

**Decisions (2026-09-26, mockup `docs/superpowers/mockups/2026-09-26-forecast-variants.html`, `?variant=mix`).**

- Six columns stay six: 2 closed + current + 3 forecast, dimmed (0.5) and hatched, a 22px min–max band behind each
  forecast expense bar, a dashed divider before the first. Caption «3 periodi · 3 previsti».
- Only on a whole period containing today (`period.isPeriod && period.isCurrent`) and with ≥ 3 used periods in the
  window. A custom range, a closed period or the period ahead keep the six historical columns.
- «Al {data} circa {saldo} ›» under the chart (`formatLongDate` of the last forecast period's end, so it reads for every
  kind) opens `ForecastSheet`: title «Previsione» + ⓘ `forecast`, the end balance at `amountMd`, one row per period, a
  footnote.
- Start balance = `netWorth` today. The rest of the current period = scheduled income after today − (`projectEndOfCycle`
  − spent).
- Fix carried with it: a closed period the user navigated to is no longer hatched in Flussi (`current` only when
  `period.isCurrent`).
- Name `forecastPeriods`, not the roadmap's `forecastCycles`.
