# Phase 06 — Server & passkey authentication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up `apps/web` — the self-hostable Saldo server — with passkey registration and login, a PKCE
authorization-code exchange for the mobile app, JWT access tokens and rotating refresh tokens with reuse detection.

**Architecture:** Next.js 16 App Router, `output: 'standalone'`. Route handlers under `app/api/**/route.ts`, all
`runtime = 'nodejs'`. Layers under `src/server/`: `db` (Drizzle `node-postgres`), `auth` (webauthn, challenges, codes,
tokens, rate limit), `http` (JSON errors, body reading, `requireUser`). Every service takes its database handle and its
`now: Date` as arguments, so route handlers stay thin and the services are testable against PGlite without a clock
hack — the same shape phases 02–05 used on the mobile side.

**Tech Stack:** Next.js 16, React 19, Drizzle ORM + `pg`, `@electric-sql/pglite` (tests), `@simplewebauthn/server` 14 +
`@simplewebauthn/browser` 14, `jose` (HS256 JWT), Zod 4, Vitest 5.

**Spec sections:** §9 (authentication), §14 (server), §18 (security checklist), §16 (testing strategy), §3.1 (layout).

## Decisions taken while planning

- **Database handle type.** `ServerDatabase = PgDatabase<PgQueryResultHKT, typeof schema, …>` — the common base of
  `NodePgDatabase` (production) and `PgliteDatabase` (tests), mirroring `RepositoryDatabase` in `apps/mobile`. Route
  handlers call `getDb()`; tests call the services directly with a PGlite handle, and override the module-level handle
  with `setDatabaseForTests()` when they need to go through a route handler.
- **`now` is a parameter, never `new Date()` inside a service.** Expiry, rotation and rate-limit tests need to move
  time, and §3.2's rule against hidden clocks is the house style.
- **Registration policy** (`REGISTRATION` env): `open`, `first-user` (allowed only while `users` is empty) or
  `closed`. `/api/health` reports whether registration is currently allowed so the mobile connect screen (phase 07)
  and `/auth/mobile` can hide the "create account" affordance.
- **No user enumeration** (§18): every login failure answers `401 invalid_credentials`, and register failures never
  reveal whether a display name is taken (display names are not unique — the passkey is the identity).
- **PKCE is S256 only.** A `plain` challenge method is not accepted at all, so there is nothing to downgrade to.
- **Refresh reuse revokes the chain forward.** Presenting a revoked token revokes every token reachable through
  `replaced_by` from it, which is the whole live tail of that chain.
- **`sync_rows` and attachments are not in this phase.** Phase 07 adds the sync tables and 08 the attachment table;
  this phase only creates what §9.1 lists.
- **No Tailwind, no ESLint.** `create-next-app` is run with those off: the repo formats and lints with Biome, and the
  two server pages are small enough to style inline like the mobile app does.

```ts
import { z } from 'zod';

export const REGISTRATION_MODES = ['open', 'first-user', 'closed'] as const;
export type RegistrationMode = (typeof REGISTRATION_MODES)[number];

/**
 * WebAuthn requires a secure context. Browsers make one exception — `http://localhost` — which is
 * what web development uses, so the check mirrors the browsers' own rule rather than banning http.
 */
function isSecureOrigin(url: URL): boolean {
  return url.protocol === 'https:' || url.hostname === 'localhost' || url.hostname === '127.0.0.1';
}

const schema = z.object({
  PUBLIC_URL: z
    .string()
    .refine((value) => URL.canParse(value), 'must be an absolute URL')
    .refine((value) => isSecureOrigin(new URL(value)), 'must be https (or http://localhost)'),
  WEBAUTHN_RP_ID: z.string().min(1),
  WEBAUTHN_RP_NAME: z.string().min(1),
  // 32 bytes base64 is 44 characters; anything shorter is not worth signing with.
  JWT_SECRET: z.string().min(32),
  DATABASE_URL: z.string().min(1),
  STORAGE_DIR: z.string().min(1),
  REGISTRATION: z.enum(REGISTRATION_MODES).default('first-user'),
  APP_REDIRECT_SCHEMES: z.string().default('saldo'),
});

export interface ServerEnv {
  publicUrl: string;
  rpId: string;
  rpName: string;
  jwtSecret: Uint8Array;
  databaseUrl: string;
  storageDir: string;
  registration: RegistrationMode;
  appRedirectSchemes: string[];
}

export function readEnv(source: Record<string, string | undefined>): ServerEnv {
  const parsed = schema.safeParse(source);
  if (!parsed.success) {
    const lines = parsed.error.issues.map(
      (issue) => `${issue.path.join('.') || '(root)'}: ${issue.message}`,
    );
    throw new Error(`Invalid server environment:\n${lines.join('\n')}`);
  }
  const value = parsed.data;
  return {
    publicUrl: value.PUBLIC_URL.replace(/\/$/, ''),
    rpId: value.WEBAUTHN_RP_ID,
    rpName: value.WEBAUTHN_RP_NAME,
    jwtSecret: new TextEncoder().encode(value.JWT_SECRET),
    databaseUrl: value.DATABASE_URL,
    storageDir: value.STORAGE_DIR,
    registration: value.REGISTRATION,
    appRedirectSchemes: value.APP_REDIRECT_SCHEMES.split(',')
      .map((scheme) => scheme.trim())
      .filter((scheme) => scheme.length > 0),
  };
}

let cached: ServerEnv | null = null;

/** Read once per process. Route handlers call this; only tests reset it. */
export function env(): ServerEnv {
  if (cached === null) cached = readEnv(process.env);
  return cached;
}

export function resetEnvCache(): void {
  cached = null;
}
```

- [x] **Step 1: Write `apps/web/src/server/db/schema.ts` (§9.1)**

```ts
import {
  type AnyPgColumn,
  bigint,
  boolean,
  customType,
  index,
  pgTable,
  text,
  timestamp,
  uuid,
} from 'drizzle-orm/pg-core';

/**
 * `bytea` for the credential public key. Drizzle has no built-in column for it, and the two
 * drivers disagree on the value they hand back (`Buffer` from `pg`, `Uint8Array` from PGlite), so
 * the codec normalises both to `Uint8Array` — which is also what `@simplewebauthn/server` wants.
 */
const bytea = customType<{ data: Uint8Array; driverData: Uint8Array }>({
  dataType() {
    return 'bytea';
  },
  toDriver(value) {
    return Buffer.from(value);
  },
  fromDriver(value) {
    return new Uint8Array(value);
  },
});

const createdAt = timestamp('created_at', { withTimezone: true }).notNull().defaultNow();

export const users = pgTable('users', {
  id: uuid('id').primaryKey().defaultRandom(),
  displayName: text('display_name').notNull(),
  createdAt,
});

export const passkeys = pgTable(
  'passkeys',
  {
    /** Credential id, base64url — the identifier the authenticator itself returns. */
    id: text('id').primaryKey(),
    userId: uuid('user_id')
      .notNull()
      .references(() => users.id, { onDelete: 'cascade' }),
    publicKey: bytea('public_key').notNull(),
    counter: bigint('counter', { mode: 'number' }).notNull(),
    transports: text('transports').array(),
    deviceType: text('device_type').notNull(),
    backedUp: boolean('backed_up').notNull(),
    createdAt,
    lastUsedAt: timestamp('last_used_at', { withTimezone: true }),
  },
  (table) => [index('passkeys_user_id_idx').on(table.userId)],
);

export const webauthnChallenges = pgTable('webauthn_challenges', {
  id: uuid('id').primaryKey().defaultRandom(),
  challenge: text('challenge').notNull(),
  /** Null for a login ceremony: a discoverable credential names the user, not the server. */
  userId: uuid('user_id').references(() => users.id, { onDelete: 'cascade' }),
  kind: text('kind').notNull(),
  expiresAt: timestamp('expires_at', { withTimezone: true }).notNull(),
  createdAt,
});

export const authCodes = pgTable('auth_codes', {
  /** sha256(code), base64url. The code itself is never stored. */
  codeHash: text('code_hash').primaryKey(),
  userId: uuid('user_id')
    .notNull()
    .references(() => users.id, { onDelete: 'cascade' }),
  codeChallenge: text('code_challenge').notNull(),
  redirectUri: text('redirect_uri').notNull(),
  expiresAt: timestamp('expires_at', { withTimezone: true }).notNull(),
  usedAt: timestamp('used_at', { withTimezone: true }),
  createdAt,
});

export const refreshTokens = pgTable(
  'refresh_tokens',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    userId: uuid('user_id')
      .notNull()
      .references(() => users.id, { onDelete: 'cascade' }),
    /** sha256(token), base64url. */
    tokenHash: text('token_hash').notNull().unique(),
    deviceName: text('device_name').notNull(),
    createdAt,
    expiresAt: timestamp('expires_at', { withTimezone: true }).notNull(),
    revokedAt: timestamp('revoked_at', { withTimezone: true }),
    /** The token this one was rotated into; the chain a reuse revokes (§9.3 step 6). */
    replacedBy: uuid('replaced_by').references((): AnyPgColumn => refreshTokens.id, {
      onDelete: 'set null',
    }),
  },
  (table) => [index('refresh_tokens_user_id_idx').on(table.userId)],
);

export const schema = {
  users,
  passkeys,
  webauthnChallenges,
  authCodes,
  refreshTokens,
};
```

/** §14 error format: `{ "error": { "code", "message" } }` with a real status code. */
export class ApiError extends Error {
  constructor(
    readonly status: number,
    readonly code: string,
    message: string,
  ) {
    super(message);
    this.name = 'ApiError';
  }

  toResponse(): Response {
    return Response.json(
      { error: { code: this.code, message: this.message } },
      { status: this.status },
    );
  }
}

/**
 * Wraps a route handler: `ApiError` becomes its envelope, anything else becomes a 500 that says
 * nothing about the failure. The detail is logged server-side instead.
 */
export function handle(fn: () => Promise<Response>): Promise<Response> {
  return fn().catch((error: unknown) => {
    if (error instanceof ApiError) return error.toResponse();
    console.error('[saldo] unhandled route error', error);
    return new ApiError(500, 'internal_error', 'Unexpected server error').toResponse();
  });
}

import type { z } from 'zod';
import { ApiError } from './errors';

/** 64 KB is far more than any auth body needs; sync raises its own cap in phase 07. */
const DEFAULT_MAX_BYTES = 64 * 1024;

export async function readJson<T>(
  request: Request,
  schema: z.ZodType<T>,
  maxBytes: number = DEFAULT_MAX_BYTES,
): Promise<T> {
  const text = await request.text();
  if (Buffer.byteLength(text, 'utf8') > maxBytes) {
    throw new ApiError(413, 'payload_too_large', `Body must be at most ${maxBytes} bytes`);
  }
  let raw: unknown;
  try {
    raw = JSON.parse(text);
  } catch {
    throw new ApiError(400, 'invalid_json', 'Body is not valid JSON');
  }
  const parsed = schema.safeParse(raw);
  if (!parsed.success) {
    const detail = parsed.error.issues
      .map((issue) => `${issue.path.join('.') || '(root)'}: ${issue.message}`)
      .join('; ');
    throw new ApiError(400, 'invalid_body', detail);
  }
  return parsed.data;
}

```ts
import { ApiError } from '../http/errors';

/** §9.3: 10 requests per minute per IP on the auth endpoints. */
const CAPACITY = 10;
const WINDOW_MS = 60_000;
const REFILL_PER_MS = CAPACITY / WINDOW_MS;
/** Buckets idle for longer than this are dropped, so a long-running process cannot grow forever. */
const IDLE_EVICTION_MS = 10 * WINDOW_MS;

interface Bucket {
  tokens: number;
  updatedAt: number;
}

/**
 * In-memory token bucket. **Single-instance only** by design (§9.3): behind more than one replica
 * each process limits its own share, which for a self-hosted server is an acceptable trade against
 * requiring Redis. Replace this module to change that.
 */
const buckets = new Map<string, Bucket>();

export function clientIp(request: Request): string {
  const forwarded = request.headers.get('x-forwarded-for');
  const first = forwarded?.split(',')[0]?.trim();
  if (first !== undefined && first.length > 0) return first;
  const real = request.headers.get('x-real-ip')?.trim();
  if (real !== undefined && real.length > 0) return real;
  return 'unknown';
}

export function enforceRateLimit(key: string, now: Date): void {
  const at = now.getTime();
  for (const [existing, bucket] of buckets) {
    if (at - bucket.updatedAt > IDLE_EVICTION_MS) buckets.delete(existing);
  }
  const bucket = buckets.get(key) ?? { tokens: CAPACITY, updatedAt: at };
  const refilled = Math.min(CAPACITY, bucket.tokens + (at - bucket.updatedAt) * REFILL_PER_MS);
  if (refilled < 1) {
    buckets.set(key, { tokens: refilled, updatedAt: at });
    throw new ApiError(429, 'rate_limited', 'Too many requests, try again in a minute');
  }
  buckets.set(key, { tokens: refilled - 1, updatedAt: at });
}

export function resetRateLimits(): void {
  buckets.clear();
}
```

import { and, eq, lt } from 'drizzle-orm';
import { webauthnChallenges } from '../db/schema';
import type { ServerDatabase } from '../db/types';
import { ApiError } from '../http/errors';

/** §9.3: challenges expire after 5 minutes and are deleted on use. */
export const CHALLENGE_TTL_MS = 5 * 60_000;

export type ChallengeKind = 'register' | 'login';

export interface ConsumedChallenge {
  challenge: string;
  displayName: string | null;
}

export async function createChallenge(
  db: ServerDatabase,
  input: { challenge: string; kind: ChallengeKind; displayName?: string },
  now: Date,
): Promise<void> {
  // Opportunistic sweep: no cron job in a single-container deployment.
  await db.delete(webauthnChallenges).where(lt(webauthnChallenges.expiresAt, now));
  await db.insert(webauthnChallenges).values({
    challenge: input.challenge,
    kind: input.kind,
    displayName: input.displayName ?? null,
    expiresAt: new Date(now.getTime() + CHALLENGE_TTL_MS),
  });
}

/** Deletes the row whatever the outcome: a challenge is single-use even when it has expired. */
export async function consumeChallenge(
  db: ServerDatabase,
  challenge: string,
  kind: ChallengeKind,
  now: Date,
): Promise<ConsumedChallenge> {
  const [row] = await db
    .delete(webauthnChallenges)
    .where(and(eq(webauthnChallenges.challenge, challenge), eq(webauthnChallenges.kind, kind)))
    .returning();
  if (row === undefined) {
    throw new ApiError(400, 'challenge_not_found', 'Unknown or already used challenge');
  }
  if (row.expiresAt.getTime() < now.getTime()) {
    throw new ApiError(400, 'challenge_expired', 'The ceremony took too long, try again');
  }
  return { challenge: row.challenge, displayName: row.displayName };
}

  PublicKeyCredentialCreationOptionsJSON,
  PublicKeyCredentialRequestOptionsJSON,
  RegistrationResponseJSON,
} from '@simplewebauthn/server';
import { env } from '../env';
import { ApiError } from '../http/errors';

/**
 * The one place that talks to `@simplewebauthn/server`, so the ceremony parameters of §9.3 live
 * together: resident (discoverable) credentials are required — login sends an empty
 * `allowCredentials` and lets the authenticator name the user — and attestation is not collected.
 */
export function registrationOptions(
  displayName: string,
): Promise<PublicKeyCredentialCreationOptionsJSON> {
  const { rpId, rpName } = env();
  return generateRegistrationOptions({
    rpID: rpId,
    rpName,
    userName: displayName,
    userDisplayName: displayName,
    attestationType: 'none',
    authenticatorSelection: { residentKey: 'required', userVerification: 'preferred' },
  });
}

export function authenticationOptions(): Promise<PublicKeyCredentialRequestOptionsJSON> {
  return generateAuthenticationOptions({
    rpID: env().rpId,
    allowCredentials: [],
    userVerification: 'preferred',
  });
}

export interface VerifiedRegistration {
  credentialId: string;
  publicKey: Uint8Array;
  counter: number;
  transports: string[] | null;
  deviceType: string;
  backedUp: boolean;
}

export async function verifyRegistration(
  response: RegistrationResponseJSON,
  expectedChallenge: string,
): Promise<VerifiedRegistration> {
  const { publicUrl, rpId } = env();
  const result = await verifyRegistrationResponse({
    response,
    expectedChallenge,
    expectedOrigin: publicUrl,
    expectedRPID: rpId,
  });
  if (!result.verified) {
    throw new ApiError(400, 'registration_failed', 'The passkey could not be verified');
  }
  const info = result.registrationInfo;
  return {
    credentialId: info.credential.id,
    publicKey: info.credential.publicKey,
    counter: info.credential.counter,
    transports: info.credential.transports ?? null,
    deviceType: info.credentialDeviceType,
    backedUp: info.credentialBackedUp,
  };
}

export async function verifyAuthentication(
  response: AuthenticationResponseJSON,
  expectedChallenge: string,
  credential: { id: string; publicKey: Uint8Array; counter: number; transports: string[] | null },
): Promise<{ newCounter: number }> {
  const { publicUrl, rpId } = env();
  const result = await verifyAuthenticationResponse({
    response,
    expectedChallenge,
    expectedOrigin: publicUrl,
    expectedRPID: rpId,
    credential: {
      id: credential.id,
      publicKey: credential.publicKey,
      counter: credential.counter,
      ...(credential.transports === null ? {} : { transports: credential.transports }),
    },
  });
  // §18: no user enumeration — a wrong signature reads exactly like an unknown credential.
  if (!result.verified) {
    throw new ApiError(401, 'invalid_credentials', 'Could not sign you in');
  }
  return { newCounter: result.authenticationInfo.newCounter };
}

/**
 * The challenge the browser actually signed, read back out of `clientDataJSON`. It is what lets a
 * ceremony be looked up in `webauthn_challenges` without a cookie or a session.
 */
export function challengeFromClientData(clientDataJSON: string): string {
  let parsed: unknown;
  try {
    parsed = JSON.parse(Buffer.from(clientDataJSON, 'base64url').toString('utf8'));
  } catch {
    throw new ApiError(400, 'invalid_body', 'clientDataJSON is not valid');
  }
  const challenge =
    typeof parsed === 'object' && parsed !== null
      ? (parsed as { challenge?: unknown }).challenge
      : undefined;
  if (typeof challenge !== 'string' || challenge.length === 0) {
    throw new ApiError(400, 'invalid_body', 'clientDataJSON carries no challenge');
  }
  return challenge;
}

import { createHash, randomBytes, timingSafeEqual } from 'node:crypto';
import { and, eq, isNull, lt } from 'drizzle-orm';
import { authCodes } from '../db/schema';
import type { ServerDatabase } from '../db/types';
import { ApiError } from '../http/errors';

/** §18: auth codes are single-use with a 60 second TTL. */
export const CODE_TTL_MS = 60_000;

function sha256(value: string): string {
  return createHash('sha256').update(value).digest('base64url');
}

function equals(a: string, b: string): boolean {
  const left = Buffer.from(a);
  const right = Buffer.from(b);
  return left.length === right.length && timingSafeEqual(left, right);
}

/**
 * §18: the redirect target is allow-listed **by scheme**, which is what stops a crafted
 * `/auth/mobile?redirect_uri=…` from handing a code to somewhere else.
 */
export function validateRedirectUri(uri: string, allowedSchemes: readonly string[]): string {
  if (!URL.canParse(uri)) {
    throw new ApiError(400, 'invalid_redirect_uri', 'redirect_uri is not a valid URI');
  }
  const scheme = new URL(uri).protocol.replace(/:$/, '');
  if (!allowedSchemes.includes(scheme)) {
    throw new ApiError(400, 'invalid_redirect_uri', `redirect_uri scheme "${scheme}" is not allowed`);
  }
  return uri;
}

export interface CreatedAuthCode {
  code: string;
  /** Where `/auth/mobile` sends the browser once the ceremony succeeds (§9.3 step 4). */
  redirect: string;
}

export async function createAuthCode(
  db: ServerDatabase,
  input: { userId: string; codeChallenge: string; redirectUri: string; state: string },
  now: Date,
): Promise<CreatedAuthCode> {
  await db.delete(authCodes).where(lt(authCodes.expiresAt, now));
  const code = randomBytes(32).toString('base64url');
  await db.insert(authCodes).values({
    codeHash: sha256(code),
    userId: input.userId,
    codeChallenge: input.codeChallenge,
    redirectUri: input.redirectUri,
    expiresAt: new Date(now.getTime() + CODE_TTL_MS),
  });
  const url = new URL(input.redirectUri);
  url.searchParams.set('code', code);
  url.searchParams.set('state', input.state);
  return { code, redirect: url.toString() };
}

/**
 * Exchanges a code for its user. Every failure answers `invalid_grant`: which of the four reasons
 * it was is useful to an attacker and to nobody else.
 */
export async function consumeAuthCode(
  db: ServerDatabase,
  code: string,
  codeVerifier: string,
  now: Date,
): Promise<{ userId: string }> {
  const [row] = await db.select().from(authCodes).where(eq(authCodes.codeHash, sha256(code)));
  const invalid = new ApiError(400, 'invalid_grant', 'The authorization code is not usable');
  if (row === undefined || row.usedAt !== null) throw invalid;
  if (row.expiresAt.getTime() < now.getTime()) throw invalid;
  if (!equals(row.codeChallenge, sha256(codeVerifier))) throw invalid;
  // Mark used only now, and only if still unused: two concurrent exchanges cannot both win.
  const claimed = await db
    .update(authCodes)
    .set({ usedAt: now })
    .where(and(eq(authCodes.codeHash, row.codeHash), isNull(authCodes.usedAt)))
    .returning();
  if (claimed.length === 0) throw invalid;
  return { userId: row.userId };
}

import { z } from 'zod';
import { consumeChallenge } from '../../../../../src/server/auth/challenges';
import { createAuthCode, validateRedirectUri } from '../../../../../src/server/auth/codes';
import { clientIp, enforceRateLimit } from '../../../../../src/server/auth/rateLimit';
import { registrationAllowed } from '../../../../../src/server/auth/registration';
import {
  challengeFromClientData,
  verifyRegistration,
} from '../../../../../src/server/auth/webauthn';
import { getDb } from '../../../../../src/server/db/client';
import { passkeys, users } from '../../../../../src/server/db/schema';
import { env } from '../../../../../src/server/env';
import { ApiError, handle } from '../../../../../src/server/http/errors';
import { readJson } from '../../../../../src/server/http/json';

export const runtime = 'nodejs';

const bodySchema = z.object({
  // The attestation as `@simplewebauthn/browser` produces it; its own verifier validates the shape.
  response: z.looseObject({
    id: z.string().min(1),
    response: z.looseObject({ clientDataJSON: z.string().min(1) }),
  }),
  code_challenge: z.string().min(43).max(128),
  redirect_uri: z.string().min(1),
  state: z.string().min(1).max(128),
});

export function POST(request: Request): Promise<Response> {
  return handle(async () => {
    const now = new Date();
    enforceRateLimit(clientIp(request), now);
    const body = await readJson(request, bodySchema);
    const redirectUri = validateRedirectUri(body.redirect_uri, env().appRedirectSchemes);
    const db = getDb();
    if (!(await registrationAllowed(db, env().registration))) {
      throw new ApiError(403, 'registration_closed', 'This server is not accepting new accounts');
    }

    const signed = challengeFromClientData(body.response.response.clientDataJSON);
    const stored = await consumeChallenge(db, signed, 'register', now);
    if (stored.displayName === null) {
      throw new ApiError(400, 'challenge_not_found', 'Unknown or already used challenge');
    }
    const credential = await verifyRegistration(
      body.response as Parameters<typeof verifyRegistration>[0],
      stored.challenge,
    );

    const [user] = await db.insert(users).values({ displayName: stored.displayName }).returning();
    if (user === undefined) throw new ApiError(500, 'internal_error', 'Could not create the user');
    await db.insert(passkeys).values({
      id: credential.credentialId,
      userId: user.id,
      publicKey: credential.publicKey,
      counter: credential.counter,
      transports: credential.transports,
      deviceType: credential.deviceType,
      backedUp: credential.backedUp,
      lastUsedAt: now,
    });

    const { redirect } = await createAuthCode(
      db,
      {
        userId: user.id,
        codeChallenge: body.code_challenge,
        redirectUri,
        state: body.state,
      },
      now,
    );
    return Response.json({ redirect });
  });
}

import { createHash, randomBytes } from 'node:crypto';
import { eq } from 'drizzle-orm';
import { jwtVerify, SignJWT } from 'jose';
import { refreshTokens } from '../db/schema';
import type { ServerDatabase } from '../db/types';
import { env } from '../env';
import { ApiError } from '../http/errors';

/** §9.3 step 5: the app is told `expires_in: 900`. */
export const ACCESS_TTL_SECONDS = 900;
export const REFRESH_TTL_DAYS = 90;
const AUDIENCE = 'saldo-app';

function sha256(value: string): string {
  return createHash('sha256').update(value).digest('base64url');
}

export function issueAccessToken(userId: string, now: Date): Promise<string> {
  const issuedAt = Math.floor(now.getTime() / 1000);
  return new SignJWT({})
    .setProtectedHeader({ alg: 'HS256' })
    .setSubject(userId)
    .setIssuer(env().publicUrl)
    .setAudience(AUDIENCE)
    .setIssuedAt(issuedAt)
    .setExpirationTime(issuedAt + ACCESS_TTL_SECONDS)
    .sign(env().jwtSecret);
}

export async function verifyAccessToken(token: string, now: Date): Promise<{ userId: string }> {
  try {
    const { payload } = await jwtVerify(token, env().jwtSecret, {
      issuer: env().publicUrl,
      audience: AUDIENCE,
      currentDate: now,
    });
    if (typeof payload.sub !== 'string' || payload.sub.length === 0) {
      throw new Error('no subject');
    }
    return { userId: payload.sub };
  } catch {
    throw new ApiError(401, 'invalid_token', 'The access token is not valid');
  }
}

export async function issueRefreshToken(
  db: ServerDatabase,
  input: { userId: string; deviceName: string },
  now: Date,
): Promise<string> {
  const token = randomBytes(32).toString('base64url');
  await db.insert(refreshTokens).values({
    userId: input.userId,
    tokenHash: sha256(token),
    deviceName: input.deviceName,
    createdAt: now,
    expiresAt: new Date(now.getTime() + REFRESH_TTL_DAYS * 24 * 3600 * 1000),
  });
  return token;
}

/**
 * Walks `replaced_by` forward from a row and revokes everything still live. Called when a revoked
 * token is presented again: either the client replayed it or somebody stole it, and in both cases
 * the safe move is to end the whole chain (§9.3 step 6).
 */
async function revokeChain(db: ServerDatabase, startId: string, now: Date): Promise<void> {
  let current: string | null = startId;
  const seen = new Set<string>();
  while (current !== null && !seen.has(current)) {
    seen.add(current);
    const [row] = await db
      .update(refreshTokens)
      .set({ revokedAt: now })
      .where(eq(refreshTokens.id, current))
      .returning();
    current = row?.replacedBy ?? null;
  }
}

export interface RotatedRefresh {
  userId: string;
  refreshToken: string;
}

export async function rotateRefreshToken(
  db: ServerDatabase,
  presented: string,
  now: Date,
): Promise<RotatedRefresh> {
  const invalid = new ApiError(401, 'invalid_grant', 'The refresh token is not usable');
  const [row] = await db
    .select()
    .from(refreshTokens)
    .where(eq(refreshTokens.tokenHash, sha256(presented)));
  if (row === undefined) throw invalid;
  if (row.revokedAt !== null) {
    await revokeChain(db, row.id, now);
    throw invalid;
  }
  if (row.expiresAt.getTime() < now.getTime()) throw invalid;

  const next = await issueRefreshToken(
    db,
    { userId: row.userId, deviceName: row.deviceName },
    now,
  );
  const [created] = await db
    .select()
    .from(refreshTokens)
    .where(eq(refreshTokens.tokenHash, sha256(next)));
  await db
    .update(refreshTokens)
    .set({ revokedAt: now, replacedBy: created?.id ?? null })
    .where(eq(refreshTokens.id, row.id));
  return { userId: row.userId, refreshToken: next };
}

/** Logout (§9.3 step 7). Revoking an unknown or already revoked token is a no-op, not an error. */
export async function revokeRefreshToken(
  db: ServerDatabase,
  presented: string,
  now: Date,
): Promise<void> {
  await db
    .update(refreshTokens)
    .set({ revokedAt: now })
    .where(eq(refreshTokens.tokenHash, sha256(presented)));
}

  return handle(async () => {
    const now = new Date();
    enforceRateLimit(clientIp(request), now);
    const body = await readJson(request, bodySchema);
    const db = getDb();

    const { userId, refreshToken } =
      body.grant_type === 'authorization_code'
        ? await (async () => {
            const consumed = await consumeAuthCode(db, body.code, body.code_verifier, now);
            const token = await issueRefreshToken(
              db,
              { userId: consumed.userId, deviceName: body.device_name },
              now,
            );
            return { userId: consumed.userId, refreshToken: token };
          })()
        : await rotateRefreshToken(db, body.refresh_token, now);

    const [user] = await db.select().from(users).where(eq(users.id, userId));
    if (user === undefined) throw new ApiError(401, 'invalid_grant', 'Unknown user');

    return Response.json({
      access_token: await issueAccessToken(userId, now),
      expires_in: ACCESS_TTL_SECONDS,
      refresh_token: refreshToken,
      user: { id: user.id, displayName: user.displayName },
    });
  });
}

import { eq } from 'drizzle-orm';
import { verifyAccessToken } from '../auth/tokens';
import { getDb } from '../db/client';
import { users } from '../db/schema';
import { ApiError } from './errors';

export interface AuthenticatedUser {
  id: string;
  displayName: string;
}

/**
 * §14: every bearer route starts here, and every query downstream scopes on the id it returns.
 */
export async function requireUser(request: Request, now: Date): Promise<AuthenticatedUser> {
  const header = request.headers.get('authorization') ?? '';
  const [scheme, token] = header.split(' ');
  if (scheme?.toLowerCase() !== 'bearer' || token === undefined || token.length === 0) {
    throw new ApiError(401, 'unauthorized', 'A bearer token is required');
  }
  const { userId } = await verifyAccessToken(token, now);
  const [user] = await getDb().select().from(users).where(eq(users.id, userId));
  if (user === undefined) throw new ApiError(401, 'unauthorized', 'A bearer token is required');
  return { id: user.id, displayName: user.displayName };
}

/**
 * The two ceremonies of §9.3. On success the server answers with the `saldo://` redirect it minted
 * and the browser follows it, which is what closes `openAuthSessionAsync` on the app side.
 */
export function MobileAuth({
  redirectUri,
  codeChallenge,
  state,
  canRegister,
  initialMode,
}: Props) {
  const [mode, setMode] = useState<'login' | 'register'>(initialMode);
  const [displayName, setDisplayName] = useState('');
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const finish = (payload: unknown) => {
    const redirect =
      typeof payload === 'object' && payload !== null
        ? (payload as { redirect?: unknown }).redirect
        : undefined;
    if (typeof redirect !== 'string') throw new Error('The server did not return a redirect');
    window.location.href = redirect;
  };

  const run = async (action: () => Promise<void>) => {
    setBusy(true);
    setError(null);
    try {
      await action();
    } catch (caught) {
      setError(caught instanceof Error ? caught.message : 'Something went wrong');
    } finally {
      setBusy(false);
    }
  };

    run(async () => {
      const options = await postJson('/api/auth/login/options', {});

          code_challenge: codeChallenge,
          redirect_uri: redirectUri,
          state,
        }),
      );
    });

    run(async () => {

      const attestation = await startRegistration({
        optionsJSON: options as Parameters<typeof startRegistration>[0]['optionsJSON'],
      });
      finish(
        await postJson('/api/auth/register/verify', {
          response: attestation,
          code_challenge: codeChallenge,
          redirect_uri: redirectUri,
          state,
        }),
      );
    });

          style={input}
          placeholder="Your name"
          value={displayName}
          maxLength={80}
          onChange={(event) => setDisplayName(event.target.value)}
          autoComplete="name"
        />
      ) : null}

        type="button"

        disabled={busy}
