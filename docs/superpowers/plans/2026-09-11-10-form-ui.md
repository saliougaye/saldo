# Form UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every create/edit form in the app fit on one screen, and make the screens that still
scroll say so.

**Architecture:** Three moves, in this order. (1) `Screen` stops cutting its content on a hard edge
and stops losing taps and its save button to the keyboard — one component, every screen. (2) The
transaction form keeps its five frequent fields on the first screen and collapses the other four
into a disclosure that summarises what it holds. (3) The account and category forms move their
grids — colour, icon, type, credit days, parent — behind rows that open sheets, which is the only
change that makes them fit. The tag edit sheet becomes a card on the screen that already exists for
it, because it holds three destructive actions and a sheet is for a choice made and closed.

**Tech Stack:** React Native 0.86 / Expo SDK 57, expo-router, `react-native-svg` 15.15.4 (already a
dependency — it draws the fade, no new package), jest + `@testing-library/react-native`, i18next.

**Decisions this implements:** `docs/superpowers/plans/2026-09-11-form-architecture.md` §§0–10.

- [ ] **Step 4: Rewrite `Screen`**

Replace the whole of `apps/mobile/src/components/Screen.tsx` with:

```tsx
import { type ReactNode, useState } from 'react';
import { KeyboardAvoidingView, Platform, ScrollView, View } from 'react-native';
import { useSafeAreaInsets } from 'react-native-safe-area-context';
import { useTheme } from '../theme/ThemeProvider';
import { ScrollFade } from './ScrollFade';

export interface ScreenProps {
  children: ReactNode;
  /** Screens with their own list use `scroll={false}` (§6). */
  scroll?: boolean;
  /** Pinned over the content rather than below it, so the content can run under it. */
  footer?: ReactNode;
  /**
   * Tab screens clear the FAB, which is lifted over the top edge of the tab bar. The bar itself
   * needs no room: a custom `tabBar` is laid out in flow by the navigator, so the screen already
   * ends above it — reserving its height again left a dead band the content could not scroll
   * into. Push screens and onboarding have no tab bar, so they leave this off.
   */
  underTabBar?: boolean;
  /**
   * A screen presented as a sheet (`presentation: 'modal'`) already starts below the status bar,
   * so the device's top inset would be dead space above the header — it uses a plain gap instead.
   */
  sheet?: boolean;
}

/** Screen frame: theme background, safe-area insets and the §6 horizontal padding. */
export function Screen({
  children,
  scroll = true,
  footer,
  underTabBar = false,
  sheet = false,
}: ScreenProps) {
  const theme = useTheme();
  const insets = useSafeAreaInsets();
  // The footer is drawn over the content, so the content has to be told how much of itself the
  // footer covers. Measured rather than assumed: it is one button on most screens and three
  // stacked elements on the transaction form.
  const [footerHeight, setFooterHeight] = useState(0);
  const padding = {
    paddingHorizontal: theme.layout.screenPaddingX,
    paddingTop: sheet ? 12 : insets.top + 8,
  };
  const tabBarSpace = underTabBar ? theme.layout.fabLift : 0;
  return (
    <View style={{ flex: 1, backgroundColor: theme.palette.bg }}>
      <KeyboardAvoidingView
        style={{ flex: 1 }}
        /*
         * Android resizes the window itself (`android.softwareKeyboardLayoutMode` defaults to
         * `resize` in SDK 57), so padding on top of that would lift the footer twice. iOS does
         * nothing at all without this, which is why the save button used to sit under the
         * keyboard — on Android, with no `InputAccessoryView` to rescue it, unreachable.
         */
        behavior={Platform.OS === 'ios' ? 'padding' : undefined}
      >
        {scroll ? (
          <ScrollView
            /*
             * The default is `'never'`: while the keyboard is up the first tap on any control is
             * swallowed to dismiss it. On the transaction form that is a tap wasted on every
             * entry — type the amount, tap a category, nothing happens, tap it again.
             */
            keyboardShouldPersistTaps="handled"
            contentContainerStyle={{
              ...padding,
              paddingBottom: 24 + tabBarSpace + footerHeight,
              gap: theme.layout.cardGap,
            }}
          >
            {children}
          </ScrollView>
        ) : (
          <View
            style={{
              flex: 1,
              ...padding,
              paddingBottom: tabBarSpace + footerHeight,
              gap: theme.layout.cardGap,
            }}
          >
            {children}
          </View>
        )}
        {footer === undefined ? null : (
          <View
            onLayout={(event) => setFooterHeight(event.nativeEvent.layout.height)}
            style={{ position: 'absolute', left: 0, right: 0, bottom: 0 }}
          >
            <ScrollFade />
            <View
              style={{
                backgroundColor: theme.palette.bg,
                paddingHorizontal: theme.layout.screenPaddingX,
                paddingBottom: insets.bottom + 16,
                paddingTop: 4,
                gap: 8,
              }}
            >
              {footer}
            </View>
          </View>
        )}
      </KeyboardAvoidingView>
    </View>
  );
}
```

```ts
/**
 * What the form's `Dettagli` disclosure is holding (§6.16 / form-architecture §2).
 *
 * Tags, attachments, repeat and exclude are the four fields that are rarely touched and that
 * together pushed the frequent ones off the screen. Collapsing them is only safe if a *set* value
 * stays readable without opening anything, which is what this counts.
 */
export interface DetailsSummary {
  tags: number;
  attachments: number;
  repeat: boolean;
  excludeFromTotals: boolean;
}

export function detailsSummary(
  values: Pick<TransactionFormValues, 'tagIds' | 'repeat' | 'excludeFromTotals'>,
  attachments: number,
): DetailsSummary {
  return {
    tags: values.tagIds.length,
    attachments,
    repeat: values.repeat,
    excludeFromTotals: values.excludeFromTotals,
  };
}

export function detailsAreEmpty(summary: DetailsSummary): boolean {
  return (
    summary.tags === 0 &&
    summary.attachments === 0 &&
    !summary.repeat &&
    !summary.excludeFromTotals
  );
}

/**
 * Closed on a new transaction — nothing is set, and the point of the disclosure is that the form
 * fits in one screen. Open on an edit that has something in it: edit is random access, and the
 * field you came back for is the one that is already filled.
 */
export function detailsOpenInitially(mode: 'new' | 'edit', summary: DetailsSummary): boolean {
  return mode === 'edit' && !detailsAreEmpty(summary);
}
```

```tsx
import { categoryColors, ICON_NAMES, type IconName } from '@saldo/ui';
import { useMemo, useState } from 'react';
import { useTranslation } from 'react-i18next';
import { Pressable, ScrollView, View } from 'react-native';
import { Icon } from '../theme/Icon';
import { Text } from '../theme/Text';
import { useTheme } from '../theme/ThemeProvider';
import { Sheet } from './Sheet';
import { TextField } from './TextField';

export interface IconGroup {
  /** Translated through `iconGroups.<key>`; only shown when there is more than one group. */
  key: string;
  icons: readonly IconName[];
}

export interface AppearanceSheetProps {
  visible: boolean;
  onClose: () => void;
  colorIndex: number;
  icon: IconName;
  groups: readonly IconGroup[];
  /** Category icons come from the whole library, so they need a search; account icons do not. */
  searchable?: boolean;
  onChange: (value: { colorIndex: number; icon: IconName }) => void;
}

/**
 * Colour and icon, together, out of the form.
 *
 * Both used to be wrapping grids at the bottom of `AccountForm` and in the middle of
 * `CategoryForm`, where they were the tallest thing on the screen and buried everything after
 * them. They are one choice — what the thing looks like — made and closed, which by the rule in
 * `2026-09-11-form-architecture.md` §9 is a sheet.
 */
export function AppearanceSheet({
  visible,
  onClose,
  colorIndex,
  icon,
  groups,
  searchable = false,
  onChange,
}: AppearanceSheetProps) {
  const theme = useTheme();
  const { t } = useTranslation();
  const [query, setQuery] = useState('');
  const colour = theme.categoryColor(colorIndex);

  const results = useMemo(() => {
    const normalized = query.trim().toLowerCase();
    if (!searchable || normalized.length === 0) return null;
    return ICON_NAMES.filter((name) => name.toLowerCase().includes(normalized));
  }, [query, searchable]);

  return (
    <Sheet visible={visible} onClose={onClose} title={t('common.appearance')} tall>
      <View style={{ flexDirection: 'row', flexWrap: 'wrap', gap: 8 }}>
        {categoryColors.map((swatch, index) => (
          <Pressable
            key={swatch}
            accessibilityRole="button"
            accessibilityState={{ selected: index === colorIndex }}
            accessibilityLabel={swatch}
            onPress={() => onChange({ colorIndex: index, icon })}
            style={{
              width: 30,
              height: 30,
              borderRadius: 15,
              backgroundColor: swatch,
              borderWidth: index === colorIndex ? 2 : 0,
              borderColor: theme.palette.text,
            }}
          />
        ))}
      </View>

      {searchable ? (
        <TextField label={t('categories.iconSearch')} value={query} onChangeText={setQuery} />
      ) : null}

      <ScrollView style={{ maxHeight: 360 }} showsVerticalScrollIndicator={false}>
        {results === null ? (
          <View style={{ gap: 12 }}>
            {groups.map((group) => (
              <View key={group.key} style={{ gap: 6 }}>
                {groups.length > 1 ? (
                  <Text size="caption" color="textFaint">
                    {t(`iconGroups.${group.key}`)}
                  </Text>
                ) : null}
                <IconGrid
                  names={group.icons}
                  selected={icon}
                  colour={colour}
                  onSelect={(next) => onChange({ colorIndex, icon: next })}
                />
              </View>
            ))}
          </View>
        ) : (
          <IconGrid
            names={results}
            selected={icon}
            colour={colour}
            onSelect={(next) => onChange({ colorIndex, icon: next })}
          />
        )}
      </ScrollView>
    </Sheet>
  );
}

function IconGrid({
  names,
  selected,
  colour,
  onSelect,
}: {
  names: readonly IconName[];
  selected: IconName;
  colour: string;
  onSelect: (name: IconName) => void;
}) {
  const theme = useTheme();
  return (
    <View style={{ flexDirection: 'row', flexWrap: 'wrap', gap: 6 }}>
      {names.map((name) => {
        const isSelected = name === selected;
        return (
          <Pressable
            key={name}
            accessibilityRole="button"
            accessibilityState={{ selected: isSelected }}
            accessibilityLabel={name}
            onPress={() => onSelect(name)}
            style={({ pressed }) => ({
              width: 36,
              height: 36,
              alignItems: 'center',
              justifyContent: 'center',
              borderRadius: theme.radii.iconBox,
              backgroundColor: isSelected ? theme.tint(colour, 0.18) : theme.palette.raised,
              transform: [{ scale: pressed ? 0.96 : 1 }],
            })}
          >
            <Icon name={name} size={18} color={isSelected ? colour : theme.palette.textMuted} />
          </Pressable>
        );
      })}
    </View>
  );
}
```

Create `apps/mobile/src/features/tags/TagEditCard.tsx`:

```tsx
import type { Tag } from '@saldo/core';
import { useState } from 'react';
import { useTranslation } from 'react-i18next';
import { Pressable, View } from 'react-native';
import { PrimaryButton, SecondaryButton } from '../../components/Button';
import { Card } from '../../components/Card';
import { ConfirmDialog } from '../../components/ConfirmDialog';
import { TextField } from '../../components/TextField';
import { deleteTag, mergeTags, renameTag } from '../../db/adminService';
import { db } from '../../db/client';
import { useRepositories } from '../../db/DatabaseProvider';
import { useTags } from '../../db/hooks';
import { Text } from '../../theme/Text';
import { useTheme } from '../../theme/ThemeProvider';

export interface TagEditCardProps {
  tag: Pick<Tag, 'id' | 'name'>;
  /** Called after a merge or a delete, when there is no tag left to show. */
  onDeleted: () => void;
}

/**
 * §6.24 / §5.10: rename, merge into another tag, or delete while keeping the transactions.
 *
 * A card on the tag's own screen rather than a sheet over it. Two of the three actions are
 * irreversible and one asks for confirmation, which is the line the form-architecture decisions
 * draw: a sheet is for a choice made and closed.
 */
export function TagEditCard({ tag, onDeleted }: TagEditCardProps) {
  const theme = useTheme();
  const { t } = useTranslation();
  const repos = useRepositories();
  const tags = useTags();
  const [name, setName] = useState(tag.name);
  const [confirmDelete, setConfirmDelete] = useState(false);

  const others = tags.filter((candidate) => candidate.id !== tag.id);
  const ready = name.trim().length > 0;

  return (
    <Card>
      <View style={{ gap: 12 }}>
        {/* The sheet carried this as its title; on a screen the section needs its own heading. */}
        <Text size="footnote" color="textMuted">
          {t('tags.editTag')}
        </Text>
        <TextField label={t('tags.name')} value={name} onChangeText={setName} />

        {others.length === 0 ? null : (
          <View style={{ gap: 8 }}>
            <Text size="footnote" color="textMuted">
              {t('tags.mergeInto')}
            </Text>
            <View style={{ flexDirection: 'row', flexWrap: 'wrap', gap: 6 }}>
              {others.map((other) => (
                <Pressable
                  key={other.id}
                  accessibilityRole="button"
                  onPress={() => {
                    mergeTags(db, repos, tag.id, other.id);
                    onDeleted();
                  }}
                  style={({ pressed }) => ({
                    paddingHorizontal: 10,
                    height: 30,
                    justifyContent: 'center',
                    borderRadius: theme.radii.chipSmall,
                    backgroundColor: theme.palette.raised,
                    transform: [{ scale: pressed ? 0.96 : 1 }],
                  })}
                >
                  <Text size="footnote">{other.name}</Text>
                </Pressable>
              ))}
            </View>
          </View>
        )}

        <View style={{ gap: 8 }}>
          <PrimaryButton
            label={t('common.save')}
            disabled={!ready}
            onPress={() => renameTag(repos, tag.id, name.trim())}
          />
          <SecondaryButton label={t('tags.delete')} onPress={() => setConfirmDelete(true)} />
        </View>
      </View>

      <ConfirmDialog
        visible={confirmDelete}
        title={t('tags.deleteConfirm', { name: tag.name })}
        confirmLabel={t('common.delete')}
        cancelLabel={t('common.cancel')}
        onConfirm={() => {
          deleteTag(db, repos, tag.id);
          setConfirmDelete(false);
          onDeleted();
        }}
        onCancel={() => setConfirmDelete(false)}
      />
    </Card>
  );
}
```
