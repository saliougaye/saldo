# 0.3e-2 — Conti and Budget write from the web

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** from the web a user creates, edits, archives and restores an account; creates, edits, closes and restores a
goal and moves money in and out of it («Metti da parte», «Preleva»); creates, edits and deletes a budget. Every change
reaches the phone on its next pull.

**Architecture:** the same shape as 0.3e-1. The pure rules the phone's forms and services already hold move into
`@saldo/core` (form values and their "what is missing" checks, the goal create/close/restore plans); the phone is
repointed at them and its existing tests stay unchanged. The server adds `write/accounts.ts`, `write/goals.ts` and
`write/budgets.ts`, each a `writeInTransaction` that builds rows with core and stamps them with the server HLC. The forms
are client components in the trailing `Panel`, and the URL carries the state (`?new`, `?a={id}&edit`, `?newGoal`,
`?g={id}&edit`, `?archived`, `/budgets?new`, `/budgets?b={id}`).

**Tech Stack:** Next 16 App Router (Server Components, Server Actions), Drizzle over Postgres (PGlite in tests), Base UI
(`Select`, `AlertDialog`), CSS Modules over the token custom properties, `@saldo/core`, `@saldo/i18n`. Tests: Vitest in
`apps/web` and `packages/core`, Jest in `apps/mobile` for the refactors.

## Scope

Spec §17.1.3 ("the web writes accounts (including pockets and their goals) … budgets") and the 0.3e roadmap row.
0.3e-1 built the write path (`writeInTransaction`, `EntityWrite.basis`, `WriteRefused`, the server clock); this plan
only adds callers of it. 0.3e-3 (Profilo) is untouched.

**In:** «Nuovo conto» and the account form (new, edit) · archive · the archived list with «Ripristina» · «Nuovo
obiettivo», the goal form (new, edit) · «Metti da parte» / «Preleva» · close a goal («Riporta in {conto}» and «Registra la
spesa») · restore a closed goal · a `/budgets` page with the budget form (new, edit, delete).

**Out (phone only, §17.1.9):** reordering accounts, the account "Salda carta" shortcut, budget detail chart and "Periodi
precedenti", notifications, recurrences (a goal's recurrences are *stopped* on close, as the phone does, never edited).

## Decisions taken while writing this plan

1. **The forms' rules move to core, as 0.3e-1 did for the transaction form.** `views/accountForm.ts`,
   `views/goalForm.ts` and `views/budgetForm.ts` receive the pure parts of the phone's `AccountForm.tsx`,
   `goalFormValues.ts` + `steps.ts` and `budgetFormValues.ts` + `steps.ts`, with `icon: string` instead of `IconName`
   (core imports no other workspace package). The phone imports them from `@saldo/core`; no re-export shims.
2. **The goal plans move to core** (`goalPlans.ts`): `newGoalFields`, `newGoalTransferFields`, `planCloseGoal`,
   `restoreGoalFields`, `canRestoreGoal`. The phone's `goalService.ts` becomes a thin caller of them and
   `goalService.test.ts` is **not edited**: it is the proof the move changed nothing. The web calls the same plans.
3. **A goal wizard is one panel on the web.** The phone's four steps (`GOAL_STEPS`) exist because a phone screen is
   small. The panel shows name, look, target, deadline, account and «Già da parte» as one form, checked by the same
   `goalStepMissing('account', …)` (all four checks, in the wizard's order). Edit is `goalStepMissing('edit', …)`.
4. **The account panel edits the current balance** (§6.22), and the server turns it into an opening balance with
   `openingBalanceForCurrent` over the whole ledger, exactly as the phone does. A new account's typed balance *is* its
   opening balance.
5. **A pocket is never created or edited through the account form.** `saveAccount` answers `notFound` for a pocket id;
   the goal form is the only door. A goal is created with `openingBalance: 0` and, when «Già da parte» > 0, a transfer
   from the parent (never an opening balance: it would count the money twice in Patrimonio, §5.14).
6. **Closing a goal is one atomic write** of: the tombstones of its future rows, the recurrence edits/deletes
   `planStopRecurrence` returns, the settlement transfer that brings the pocket to exactly zero, and the pocket's
   `archivedAt`. «Registra la spesa» is the same write plus the expense: `saveTransaction` gains an optional
   `closeGoalId` (validated: an open pocket, the form's account is that pocket) and appends `closeGoalWrites` to its own.
7. **«Metti da parte» / «Preleva» are links** to `/transactions?new&from={id}&to={id}&description={name}`. `formView`
   learns to read those three parameters (and `closeGoal`, `amount` for the expense). No new form.
8. **Budgets get their own page, `/budgets`** (no mockup exists; decided here, please confirm). Home's Budget section
   already lists budgets with no place to go: its header gets a «Tutti i budget» link, its rows link to
   `/budgets?b={id}`, and the empty card links to `/budgets?new` (the phone's «Crea un budget»). `/budgets` is the
   open list (a ring per row, as Home draws it) with the form in the trailing panel. It is **not** in the top bar or the
   tab bar: Home is the way in, as on the phone (§5.8). The budget detail chart stays on the phone.
9. **The budget's "suggested amount" is computed on the client** from the six past periods' spend the server hands over
   as plain numbers (`history`), using core's `suggestBudgetAmount` with the phone's 12% headroom.
10. **Delete of a budget asks first and has no undo**, like the phone (`ConfirmDialog`, `budgets.deleteTitle`).
    Archiving an account also asks and has no undo; «Ripristina» in the archived list is the way back.
11. **Errors.** `AccountWriteError = WriteError | 'holdsGoals' | 'parentArchived'`. A Server Action never throws for a
    refusal; a thrown action shows `web.accounts.error_unexpected` and keeps the draft (0.3e-1's I1).
12. **Everything in the account, goal and budget forms is a catalog key that already exists** except the handful listed
    in Task 3 (`web.accounts.*`, `web.budgets.*`). Grep before use; the parity test compares all seven locales.

## Rules every task follows (0.3e-1's, plus the ones its review wrote down)

- **Grep before you use.** Every i18n key: `grep -n "keyName" packages/i18n/src/locales/it.ts`. Every CSS custom
  property must be one `tokensCss()` emits (`packages/ui/src/css.ts`); `--color-raised`, not `--color-surface-raised`.
  Every core function: open it and read its signature.
- **A new i18n key goes into all seven catalogs** (`it en fr de sv es pt`).
- **Fixtures go through the schema** (`accountSchema.parse(...)`), never a cast.
- **Stage files by full path**, never a directory; `git status` before committing; one implementing agent at a time.
- **Gates are read, not trusted:** run `rtk proxy pnpm lint`, `rtk proxy pnpm typecheck`, `rtk proxy pnpm test`. Clean
  means no `lint/…` lines and no `× Some errors were emitted while running checks.`
- No `any`, no `!`, no hex/rgb colours or literal `font-size`/`border-radius` lengths in `.module.css`.
- A `'use client'` file never imports the `@saldo/i18n` root, only `@saldo/i18n/format` and `@saldo/i18n/translate`.
- Every page under `(app)` exports `runtime = 'nodejs'` and `dynamic = 'force-dynamic'`.
- `SYNC_SCHEMA_VERSION` does not move (memory: frozen until Saldo is public). No schema change is needed anyway.
- Every write is `writeInTransaction`; nothing else writes `sync_rows`. Every write of an existing row carries its
  `basis` (the `updatedAt` it read); a row `build` creates carries `basis: null`.

- [x] **Step 3: Write `packages/core/src/views/accountForm.ts`**

```ts
import { accountTypeSchema, type Account } from '../entities';
import { openingBalanceForCurrent } from '../accountSeries';
import { amountBufferToMinor, type MinorDigits, minorToAmountBuffer } from '../money';
import { POCKET_PARENT_TYPES, pocketsOf } from '../pockets';

/** A pocket is a goal (§5.14): made by the goal form, never picked as a type. */
export const ACCOUNT_TYPES = accountTypeSchema.options.filter((type) => type !== 'pocket');

export interface AccountFormValues {
  name: string;
  institution: string;
  type: Account['type'];
  /** Keypad buffer of the **current** balance, not the opening one (§6.22). */
  buffer: string;
  includeInSpendable: boolean;
  colorIndex: number;
  icon: string;
  creditCloseDay: number | null;
  creditChargeDay: number | null;
  /** Credit cards only: the account the card is charged to (§4, §6.22). */
  creditPaymentAccountId: string | null;
}

export function emptyAccountForm(): AccountFormValues {
  return {
    name: '',
    institution: '',
    type: 'checking',
    buffer: '',
    includeInSpendable: true,
    colorIndex: 0,
    icon: 'landmark',
    creditCloseDay: null,
    creditChargeDay: null,
    creditPaymentAccountId: null,
  };
}

export function accountFormFrom(
  account: Account,
  currentBalance: number,
  minorDigits: MinorDigits,
): AccountFormValues {
  return {
    name: account.name,
    institution: account.institution ?? '',
    type: account.type,
    buffer: minorToAmountBuffer(currentBalance, minorDigits),
    includeInSpendable: account.includeInSpendable,
    colorIndex: account.colorIndex,
    icon: account.icon,
    creditCloseDay: account.creditCloseDay,
    creditChargeDay: account.creditChargeDay,
    creditPaymentAccountId: account.creditPaymentAccountId,
  };
}

/**
 * The opening balance to store for what the user typed (§6.22). In edit mode the amount is the
 * *current* balance, so it is turned back into an opening balance.
 */
export function openingBalanceFrom(
  values: Pick<AccountFormValues, 'buffer'>,
  minorDigits: MinorDigits,
  context: {
    accountId: string | null;
    txs: Parameters<typeof openingBalanceForCurrent>[0]['txs'];
    today: string;
  },
): number {
  const current = amountBufferToMinor(values.buffer, minorDigits);
  if (context.accountId === null) return current;
  return openingBalanceForCurrent({
    accountId: context.accountId,
    currentBalance: current,
    txs: context.txs,
    today: context.today,
  });
}

/** The name is the only thing an account cannot be saved without (§6.22): zero is a balance. */
export function accountMissingForSave(values: Pick<AccountFormValues, 'name'>): 'name' | null {
  return values.name.trim().length > 0 ? null : 'name';
}

/** An account that holds goals stays one that can (§5.14, D24): no card, no investments. */
export function accountTypesFor(
  accounts: readonly Pick<Account, 'id' | 'type' | 'archivedAt'>[] &
    readonly { parentAccountId?: string | null }[],
  accountId: string | null,
): Account['type'][] {
  return accountId !== null && pocketsOf(accounts, accountId).length > 0
    ? ACCOUNT_TYPES.filter((type) => POCKET_PARENT_TYPES.includes(type))
    : [...ACCOUNT_TYPES];
}
```

  If the `accountTypesFor` parameter type does not typecheck against `pocketsOf`'s `PocketFields`, use
  `readonly (Pick<Account, 'id' | 'type' | 'archivedAt'> & { parentAccountId?: string | null })[]`.

```ts
import { accountBalances } from './accounts';
import type { LocalDate } from './dates';
import type { Account, Recurrence, Transaction } from './entities';
import { planStopRecurrence } from './recurrence';

/** A row's fields without what the store adds: id, the three stamps. */
export type AccountFields = Omit<Account, 'id' | 'createdAt' | 'updatedAt' | 'deletedAt'>;
export type TransactionFields = Omit<Transaction, 'id' | 'createdAt' | 'updatedAt' | 'deletedAt'>;

export interface NewGoalInput {
  name: string;
  icon: string;
  colorIndex: number;
  parentAccountId: string;
  goalTarget: number;
  goalDeadline: LocalDate | null;
  /** «Già da parte»: moved from the parent on creation, never an opening balance. */
  alreadySaved: number;
  today: LocalDate;
  sortOrder: number;
}

/**
 * A goal (§5.14) is an empty, unspendable pocket inside its parent. An opening balance would count
 * the same money twice in Patrimonio complessivo, which is why the money arrives by transfer
 * (`newGoalTransferFields`).
 */
export function newGoalFields(input: NewGoalInput): AccountFields {
  return {
    name: input.name,
    type: 'pocket',
    institution: null,
    openingBalance: 0,
    includeInSpendable: false,
    colorIndex: input.colorIndex,
    icon: input.icon,
    creditCloseDay: null,
    creditChargeDay: null,
    creditPaymentAccountId: null,
    archivedAt: null,
    sortOrder: input.sortOrder,
    parentAccountId: input.parentAccountId,
    goalTarget: input.goalTarget,
    goalDeadline: input.goalDeadline,
    goalStartDate: input.today,
  };
}

/** The transfer that moves «Già da parte» from the parent into the new pocket, or `null`. */
export function newGoalTransferFields(input: NewGoalInput, pocketId: string): TransactionFields | null {
  if (input.alreadySaved <= 0) return null;
  return {
    kind: 'transfer',
    amount: input.alreadySaved,
    date: input.today,
    accountId: input.parentAccountId,
    toAccountId: pocketId,
    categoryId: null,
    description: input.name,
    note: null,
    tagIds: [],
    excludeFromTotals: false,
    recurrenceId: null,
  };
}

export interface CloseGoalPlan {
  /** Recurrences in or out of the pocket: ended today, or deleted when they never started. */
  recurrenceEdits: { id: string; endDate: LocalDate | null; delete: boolean }[];
  /** Every row dated after today that touches the pocket, occurrences of those recurrences included. */
  tombstoneTransactionIds: string[];
  /** Brings the pocket to exactly zero: what is left goes to the parent; a deficit is topped up from it. */
  settlement: TransactionFields | null;
}

/**
 * Closing (§5.14), as the phone's `closeGoalIn`:
 *
 * 1. recurrences in or out of the pocket stop, and every row dated after today that touches it
 *    goes — an automatic contribution must not keep draining the parent into an archived account;
 * 2. the pocket is brought to exactly zero;
 * 3. the caller archives it. An archived pocket always has a zero balance, so archiving never
 *    hides money from the totals.
 */
export function planCloseGoal(input: {
  pocket: Account;
  transactions: readonly Transaction[];
  recurrences: readonly Recurrence[];
  today: LocalDate;
}): CloseGoalPlan {
  const { pocket, transactions, recurrences, today } = input;
  const parentId = pocket.parentAccountId;
  if (pocket.type !== 'pocket' || pocket.archivedAt !== null || parentId == null) {
    throw new Error(`No open goal ${pocket.id}`);
  }
  const touches = (row: { accountId: string; toAccountId: string | null }) =>
    row.accountId === pocket.id || row.toAccountId === pocket.id;

  const tombstones = new Set<string>();
  const recurrenceEdits: CloseGoalPlan['recurrenceEdits'] = [];
  for (const recurrence of recurrences) {
    if (!touches(recurrence.template)) continue;
    const occurrences = transactions
      .filter((row) => row.recurrenceId === recurrence.id)
      .map((row) => ({ id: row.id, date: row.date }));
    const plan = planStopRecurrence(recurrence, occurrences, today);
    for (const id of plan.tombstoneOccurrenceIds) tombstones.add(id);
    if (plan.deleteRecurrence) recurrenceEdits.push({ id: recurrence.id, endDate: null, delete: true });
    else if (plan.endDate !== null) {
      recurrenceEdits.push({ id: recurrence.id, endDate: plan.endDate, delete: false });
    }
  }
  for (const row of transactions) {
    if (row.date > today && touches(row)) tombstones.add(row.id);
  }

  const remaining = transactions.filter((row) => !tombstones.has(row.id));
  const balance = accountBalances([pocket], remaining, today).get(pocket.id) ?? 0;
  const settlement: TransactionFields | null =
    balance === 0
      ? null
      : {
          kind: 'transfer',
          amount: Math.abs(balance),
          date: today,
          accountId: balance > 0 ? pocket.id : parentId,
          toAccountId: balance > 0 ? parentId : pocket.id,
          categoryId: null,
          description: pocket.name,
          note: null,
          tagIds: [],
          excludeFromTotals: false,
          recurrenceId: null,
        };
  return { recurrenceEdits, tombstoneTransactionIds: [...tombstones], settlement };
}

/** A goal whose parent is archived stays closed: it would be invisible in Conti and still counted in Patrimonio. */
export function canRestoreGoal(
  pocket: Pick<Account, 'type' | 'parentAccountId'>,
  accounts: readonly Pick<Account, 'id' | 'archivedAt'>[],
): boolean {
  if (pocket.type !== 'pocket' || pocket.parentAccountId == null) return false;
  const parent = accounts.find((account) => account.id === pocket.parentAccountId);
  return parent !== undefined && parent.archivedAt === null;
}

/** Reopens a closed goal, empty (§5.14): its pace starts again today, a deadline that has passed is dropped. */
export function restoreGoalFields(
  pocket: Pick<Account, 'goalDeadline'>,
  today: LocalDate,
): { archivedAt: null; goalStartDate: LocalDate; goalDeadline: LocalDate | null } {
  return {
    archivedAt: null,
    goalStartDate: today,
    goalDeadline: pocket.goalDeadline != null && pocket.goalDeadline > today ? pocket.goalDeadline : null,
  };
}
```

```ts
/** A stored row without the stamp: `stampAndApply` mints a new one for every write. */
export function unstamped<T extends { updatedAt: string }>(row: T): Omit<T, 'updatedAt'> {
  const { updatedAt: _stamp, ...rest } = row;
  return rest;
}

/** The row as a tombstone (§7), stamp dropped. */
export function tombstoned<T extends { updatedAt: string; deletedAt: string | null }>(
  row: T,
  at: string,
): Omit<T, 'updatedAt'> & { deletedAt: string } {
  return { ...unstamped(row), deletedAt: at };
}
```

```ts
// amounts.ts
import { amountBufferToMinor, type MinorDigits, sanitizeAmountInput } from '@saldo/core';

/**
 * A balance buffer one the keypad could have typed in this currency, minus sign allowed (a card
 * may be in debt): `sanitizeAmountInput` leaves it as it is and its minor units are a safe integer.
 * An edit may send back the stored value's own buffer untouched (`stored`), which an import or the
 * phone may have written larger than the keypad types.
 */
export function signedBufferOk(buffer: string, minorDigits: MinorDigits, stored?: string): boolean {
  if (stored !== undefined && buffer === stored) return true;
  if (buffer !== sanitizeAmountInput(buffer, minorDigits, { allowNegative: true })) return false;
  return Number.isSafeInteger(amountBufferToMinor(buffer, minorDigits));
}
```

```ts
  try {
    return await writeInTransaction<AccountSaveResult>(db, userId, now, async (tx) => {
      const data = await readUserData(tx, userId);
      const settings = readSettings(data.settings);
      const { minorDigits } = getCurrency(settings.currency);
      const { today } = todayFor(settings, env().defaultTimeZone, now);
      const fail = (error: AccountWriteError) => ({
        writes: [],
        result: { ok: false, error } as const,
      });

      const existing = input.id === null ? null : (data.accounts.find((row) => row.id === input.id) ?? null);
      if (input.id !== null && (existing === null || isPocket(existing) || existing.archivedAt !== null)) {
        return fail('notFound');
      }
      const stored =
        existing === null
          ? undefined
          : accountFormFrom(
              existing,
              accountBalances(data.accounts, data.transactions, today).get(existing.id) ?? 0,
              minorDigits,
            ).buffer;
      if (!signedBufferOk(input.buffer, minorDigits, stored)) return fail('invalid');
      // §5.14: an account that holds goals stays one that can.
      if (!accountTypesFor(data.accounts, input.id).includes(input.type)) return fail('invalid');

      const card = input.type === 'credit_card';
      if (card && input.creditPaymentAccountId !== null) {
        const candidates = paymentAccountCandidates(data.accounts, input.id);
        const keepsOwn = input.creditPaymentAccountId === existing?.creditPaymentAccountId;
        if (!keepsOwn && !candidates.some((row) => row.id === input.creditPaymentAccountId)) {
          return fail('invalid');
        }
      }

      const fields = {
        name: input.name.trim(),
        type: input.type,
        institution: input.institution.trim().length > 0 ? input.institution.trim() : null,
        openingBalance: openingBalanceFrom(input, minorDigits, {
          accountId: existing?.id ?? null,
          txs: data.transactions,
          today,
        }),
        includeInSpendable: input.includeInSpendable,
        colorIndex: input.colorIndex,
        icon: input.icon,
        creditCloseDay: card ? input.creditCloseDay : null,
        creditChargeDay: card ? input.creditChargeDay : null,
        creditPaymentAccountId: card ? input.creditPaymentAccountId : null,
      };

        existing === null

              ...fields,
              id,
              archivedAt: null,
              sortOrder: data.accounts.length,
              createdAt: now.toISOString(),
              deletedAt: null,
            }

      return {
        writes: [{ entity: 'account', id, data: row, basis: existing?.updatedAt ?? null }],
        result: { ok: true, id },
      };
    });
  } catch (error) {
    if (error instanceof WriteRefused) return { ok: false, error: error.reason };
    throw error;
  }
```

```ts
/**
 * The writes that close `goalId` (§5.14): its future rows and recurrences stop, the pocket is
 * brought to zero and archived. Shared by «Chiudi» and by «Registra la spesa», whose expense
 * `saveTransaction` writes beside them. `null` when there is no open goal by that id.
 */
export function closeGoalWrites(
  data: UserData,
  goalId: string,
  today: string,
  now: Date,
): EntityWrite[] | null {
  const pocket = data.accounts.find((row) => row.id === goalId);
  if (pocket === undefined || !isPocket(pocket) || pocket.archivedAt !== null) return null;
  const plan = planCloseGoal({ pocket, transactions: data.transactions, recurrences: data.recurrences, today });
  const at = now.toISOString();
  const writes: EntityWrite[] = [];
  for (const id of plan.tombstoneTransactionIds) {
    const row = data.transactions.find((tx) => tx.id === id);
    if (row === undefined) continue;
    writes.push({ entity: 'transaction', id, data: tombstoned(row, at), basis: row.updatedAt });
  }
  for (const edit of plan.recurrenceEdits) {
    const row = data.recurrences.find((rec) => rec.id === edit.id);
    if (row === undefined) continue;
    writes.push({
      entity: 'recurrence',
      id: edit.id,
      data: edit.delete ? tombstoned(row, at) : { ...unstamped(row), endDate: edit.endDate },
      basis: row.updatedAt,
    });
  }
  if (plan.settlement !== null) {
    const id = newId();
    writes.push({
      entity: 'transaction',
      id,
      data: { ...plan.settlement, id, createdAt: at, deletedAt: null },
      basis: null,
    });
  }
  writes.push({
    entity: 'account',
    id: goalId,
    data: { ...unstamped(pocket), archivedAt: at },
    basis: pocket.updatedAt,
  });
  return writes;
}

/** «Riporta in {conto}» and the close of an empty goal (§6.38). */
export async function closeGoal(

  userId: string,
  goalId: string,
  now: Date,

  try {
    return await writeInTransaction<AccountResult>(db, userId, now, async (tx) => {
      const data = await readUserData(tx, userId);
      const { today } = todayFor(readSettings(data.settings), env().defaultTimeZone, now);
      const writes = closeGoalWrites(data, goalId, today, now);
      if (writes === null) return { writes: [], result: { ok: false, error: 'notFound' } };
      return { writes, result: { ok: true } };
    });
  } catch (error) {
    if (error instanceof WriteRefused) return { ok: false, error: error.reason };
    throw error;
  }
}

/** Ripristina on a closed goal (§5.14): from today, or refused while its account is archived. */
export async function restoreGoal(
  db: ServerDatabase,
  userId: string,
  goalId: string,
  now: Date,
): Promise<AccountResult> {

    return await writeInTransaction<AccountResult>(db, userId, now, async (tx) => {
      const data = await readUserData(tx, userId);
      const { today } = todayFor(readSettings(data.settings), env().defaultTimeZone, now);
      const pocket: Account | undefined = data.accounts.find((row) => row.id === goalId);
      if (pocket === undefined || !isPocket(pocket) || pocket.archivedAt === null) {
        return { writes: [], result: { ok: false, error: 'notFound' } };
      }
      if (!canRestoreGoal(pocket, data.accounts)) {
        return { writes: [], result: { ok: false, error: 'parentArchived' } };

      return {
        writes: [

            entity: 'account',
            id: goalId,
            data: { ...unstamped(pocket), ...restoreGoalFields(pocket, today) },
            basis: pocket.updatedAt,
          },
        ],
        result: { ok: true },
      };
    });
  } catch (error) {
    if (error instanceof WriteRefused) return { ok: false, error: error.reason };
    throw error;
  }
}
```

```ts
export type BudgetWriteError = WriteError | 'taken';

export const budgetInputSchema = z.object({
  /** Null for «Nuovo budget». */
  id: z.string().min(1).nullable(),
  /** Already resolved by the form: what was typed, or the name built from the categories (§6.18). */
  name: z.string().min(1).max(40),
  categoryIds: z.array(z.string().min(1)).max(50),
  buffer: z.string().max(32).refine((v) => v === '' || /^\d{1,13}(\.\d{0,3})?$/.test(v), 'Not an amount'),
  period: budgetPeriodSchema,
  alertThreshold: z
    .number()
    .refine((value) => (BUDGET_ALERT_THRESHOLDS as readonly number[]).includes(value))
    .nullable(),
  rollover: z.boolean(),
  icon: z.string().min(1).max(40),
});

export type BudgetInput = z.infer<typeof budgetInputSchema>;

export type BudgetSaveResult =
  | { ok: true; id: string }
  | { ok: false; missing: 'categories' | 'amount' }
  | { ok: false; error: BudgetWriteError };

export type BudgetResult = { ok: true } | { ok: false; error: BudgetWriteError };

export async function saveBudget(
  db: ServerDatabase,
  userId: string,
  raw: unknown,
  now: Date,
): Promise<BudgetSaveResult> {
  const parsed = budgetInputSchema.safeParse(raw);
  if (!parsed.success) return { ok: false, error: 'invalid' };
  const input = parsed.data;
  try {
    return await writeInTransaction<BudgetSaveResult>(db, userId, now, async (tx) => {
      const data = await readUserData(tx, userId);
      const { minorDigits } = getCurrency(readSettings(data.settings).currency);
      const fail = (error: BudgetWriteError) => ({ writes: [], result: { ok: false, error } as const });

      if (input.buffer !== sanitizeAmountInput(input.buffer, minorDigits)) return fail('invalid');
      const amount = amountBufferToMinor(input.buffer, minorDigits);
      if (!Number.isSafeInteger(amount)) return fail('invalid');

      const existing = input.id === null ? null : (data.budgets.find((row) => row.id === input.id) ?? null);
      if (input.id !== null && existing === null) return fail('notFound');

      const gap = budgetStepMissing(
        'details',
        { ...input, icon: input.icon },
        minorDigits,
      );
      if (gap !== null) return { writes: [], result: { ok: false, missing: gap } };

      // Categories: distinct, live, spending ones (the phone's grid offers top-level expense
      // categories; a child rides with its parent through `expandCategoryIds`).
      const ids = [...new Set(input.categoryIds)];
      const valid = ids.every((id) =>
        data.categories.some(
          (category) => category.id === id && category.direction === 'expense' && category.archivedAt === null,
        ),
      );
      if (!valid) return fail('invalid');
      const taken = takenCategoryIds(data.budgets, data.categories, existing?.id ?? null);
      if (ids.some((id) => taken.has(id))) return fail('taken');

      const fields = {
        name: input.name.trim(),
        categoryIds: ids,
        amount,
        period: input.period,
        alertThreshold: input.alertThreshold,
        rollover: input.period === 'period' ? input.rollover : false,
        icon: input.icon,
      };
      const id = existing?.id ?? newId();
      const row =
        existing === null
          ? { ...fields, id, sortOrder: data.budgets.length, createdAt: now.toISOString(), deletedAt: null }
          : { ...unstamped(existing), ...fields };
      return {
        writes: [{ entity: 'budget', id, data: row, basis: existing?.updatedAt ?? null }],
        result: { ok: true, id },
      };
    });
  } catch (error) {
    if (error instanceof WriteRefused) return { ok: false, error: error.reason };
    throw error;
  }
}

/** The budget is a tombstone (§7); the phone asks first and offers no undo, and so does the web. */
export async function deleteBudget(
  db: ServerDatabase,
  userId: string,
  id: string,
  now: Date,
): Promise<BudgetResult> {
  try {
    return await writeInTransaction<BudgetResult>(db, userId, now, async (tx) => {
      const data = await readUserData(tx, userId);
      const existing = data.budgets.find((row) => row.id === id);
      if (existing === undefined) return { writes: [], result: { ok: false, error: 'notFound' } };
      return {
        writes: [
          { entity: 'budget', id, data: tombstoned(existing, now.toISOString()), basis: existing.updatedAt },
        ],
        result: { ok: true },
      };
    });
  } catch (error) {
    if (error instanceof WriteRefused) return { ok: false, error: error.reason };
    throw error;
  }
}
```

```tsx
'use client';

import type { IconName } from '@saldo/ui';
import { categoryColors } from '@saldo/ui';
import { Icon } from './Icon';
import { paletteIndex } from './IconBox';
import styles from './AppearancePicker.module.css';

interface Props {
  colorLabel: string;
  iconLabel: string;
  colorIndex: number;
  icon: string;
  icons: readonly IconName[];
  /** A budget has no colour of its own (it follows its first category): its picker offers icons only. */
  showColors?: boolean;
  onChange: (next: { colorIndex: number; icon: string }) => void;
}

export function AppearancePicker({
  colorLabel,
  iconLabel,
  colorIndex,
  icon,
  icons,
  showColors = true,
  onChange,
}: Props) {
  const chosen = paletteIndex(colorIndex);
  return (
    <div className={styles.picker}>
      {showColors ? (
        <div className={styles.group} role="radiogroup" aria-label={colorLabel}>
          {categoryColors.map((_, index) => (
            // biome-ignore lint/a11y/useSemanticElements: a swatch is drawn as a button; the radio role keeps the group's one tab stop.
            <button
              // biome-ignore lint/suspicious/noArrayIndexKey: the palette is a fixed list; the index is its identity.
              key={index}
              type="button"
              role="radio"
              aria-checked={index === chosen}
              aria-label={String(index + 1)}
              tabIndex={index === chosen ? 0 : -1}
              className={styles.swatch}
              style={{ background: `var(--category-${index})` }}
              onClick={() => onChange({ colorIndex: index, icon })}
            />
          ))}
        </div>
      ) : null}
      <div className={styles.group} role="radiogroup" aria-label={iconLabel}>
        {icons.map((name) => (
          // biome-ignore lint/a11y/useSemanticElements: as above.
          <button
            key={name}
            type="button"
            role="radio"
            aria-checked={name === icon}
            aria-label={name}
            tabIndex={name === icon ? 0 : -1}
            className={styles.iconButton}
            onClick={() => onChange({ colorIndex, icon: name })}
          >
            <Icon name={name} size={18} />
          </button>
        ))}
      </div>
    </div>
  );
}
```

```tsx
'use client';

import { useRouter } from 'next/navigation';
import { useState, useTransition } from 'react';
import { Button } from '../../../src/ui/Button';
import { restoreAccountAction, restoreGoalAction } from './actions';

interface Props {
  id: string;
  kind: 'account' | 'goal';
  label: string;
  busyLabel: string;
  /** Resolved by the page: `web.accounts.error_<error>` for each error, and a throw. */
  errors: Record<string, string>;
  disabledNote?: string;
}

export function RestoreButton({ id, kind, label, busyLabel, errors, disabledNote }: Props) {
  const router = useRouter();
  const [pending, startTransition] = useTransition();
  const [error, setError] = useState<string | null>(null);
  const restore = () =>
    startTransition(async () => {
      let result: Awaited<ReturnType<typeof restoreAccountAction>>;
      try {
        result = await (kind === 'account' ? restoreAccountAction(id) : restoreGoalAction(id));
      } catch {
        setError(errors.unexpected ?? '');
        return;
      }
      if (result.ok) {
        router.refresh();
        return;
      }
      setError(errors[result.error] ?? errors.unexpected ?? '');
    });
  return (
    <>
      <Button variant="secondary" busy={pending} busyLabel={busyLabel} onClick={restore}>
        {label}
      </Button>
      {error === null ? null : <span role="alert">{error}</span>}
      {disabledNote === undefined ? null : <span>{disabledNote}</span>}
    </>
  );
}
```
