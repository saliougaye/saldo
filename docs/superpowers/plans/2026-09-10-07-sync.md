# Phase 07 — Sync engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make two devices signed into the same self-hosted server converge: whole-row last-writer-wins sync over an
HLC, with push/pull routes on the server, a scheduler and a "Server e sincronizzazione" screen on the app.

**Architecture:** The protocol schemas and the merge rule live in `@saldo/core/sync`, so the server and the app agree
by construction instead of by convention. The server stores one opaque `jsonb` row per entity with a monotonic `seq`,
which is the cursor a client pulls from. On the app, a `localStore` module owns the sync-specific data access —
repositories stamp every write pending and filter tombstones, which is exactly wrong for sync — and a `SyncScheduler`
serialises cycles, so no two run at once.

**Tech Stack:** Zod 4 (protocol), Drizzle + Postgres (`sync_rows`, `sync_seq`), TanStack Query (network layer only,
per D22), `expo-secure-store`, `expo-web-browser`, `expo-crypto`.

**Spec sections:** §8 (whole), §6.29 step 0, §6.30, §9.3 (mobile side), §3.2 (purity), §16 (testing).

## Decisions taken while planning

- **§8.1 (unknown enum values on pull) is resolved: a schema-version gate, plus per-row error state as the backstop.**
  Answered by the user. `SYNC_SCHEMA_VERSION` is an integer in `@saldo/core`, bumped whenever an enum widens or a
  field is added. It travels in the push body, in the pull response and in `/api/health`. A mismatch stops the sync
  cycle with a message that names the fix ("update the app" / "update the server") instead of letting rows diverge
  silently. A row that still fails validation is marked `sync_state = 2` and counted on the Server screen; the cursor
  moves past it, because one bad row must not wedge sync forever.
- **`sync_state = 2` means "the server rejected this row"**, joining 0 = synced and 1 = pending. No migration: the
  column is already an integer. Any later edit of that row stamps it pending again, which is the retry path.
- **Sync does not go through the repositories.** They stamp every write `pending` and hide tombstones — both correct
  for the UI and both wrong here. `apps/mobile/src/sync/localStore.ts` reads pending rows *including* tombstones and
  applies remote rows without touching the HLC.
- **`attachment` rows are not synced in this phase.** The mobile side has no attachment repository until phase 08. The
  server accepts all eight entity names so it needs no change when they arrive.
- **The server rejects an HLC more than 24h ahead of its own clock** (§8.2) as `invalid`, so one device with a broken
  clock cannot park a row permanently in everyone's future.
- **Convergence is proven by a test, not by two simulators.** Two `better-sqlite3` "devices" and one PGlite-backed
  server in one test file give the same guarantee deterministically and run in CI; the roadmap's two-simulator script
  stays as a manual extra.

```ts
import { z } from 'zod';
import { type EntityName, entitySchemas } from '../entities';
import { isHlc } from './hlc';

/**
 * Bumped whenever a synced schema changes in a way an older peer cannot represent — a widened
 * enum, a new required field. §8.1: rather than letting an older device silently drop rows it
 * cannot parse, both sides compare this number first and refuse to sync on a mismatch, so the user
 * is told to update instead of losing data.
 */
export const SYNC_SCHEMA_VERSION = 1;

/** §8.3: the client batches at this size. */
export const MAX_CHANGES_PER_PUSH = 500;
export const MAX_CHANGES_PER_PULL = 500;

export const entityNameSchema = z.enum(
  Object.keys(entitySchemas) as [EntityName, ...EntityName[]],
);

const hlcSchema = z.string().refine(isHlc, 'must be an HLC timestamp');

/**
 * One row in flight. `data` is the whole entity, and the three envelope fields must repeat what is
 * inside it: the server indexes on the envelope and stores `data` opaquely, so a disagreement
 * would make the two views of the same row permanently inconsistent.
 */
export const syncChangeSchema = z
  .object({
    entity: entityNameSchema,
    id: z.string().min(1),
    updatedAt: hlcSchema,
    deletedAt: z.iso.datetime().nullable(),
    data: z.unknown(),
  })
  .superRefine((change, ctx) => {
    const schema = entitySchemas[change.entity];
    const parsed = schema.safeParse(change.data);
    if (!parsed.success) {
      ctx.addIssue({
        code: 'custom',
        path: ['data'],
        message: parsed.error.issues
          .map((issue) => `${issue.path.join('.') || '(root)'}: ${issue.message}`)
          .join('; '),
      });
      return;
    }
    const entity = parsed.data;
    if (entity.id !== change.id) {
      ctx.addIssue({ code: 'custom', path: ['id'], message: 'does not match data.id' });
    }
    if (entity.updatedAt !== change.updatedAt) {
      ctx.addIssue({
        code: 'custom',
        path: ['updatedAt'],
        message: 'does not match data.updatedAt',
      });
    }
    if ((entity.deletedAt ?? null) !== change.deletedAt) {
      ctx.addIssue({
        code: 'custom',
        path: ['deletedAt'],
        message: 'does not match data.deletedAt',
      });
    }
  });

export type SyncChange = z.infer<typeof syncChangeSchema>;

/**
 * The envelope without the deep body check. The push *request* is parsed with this, not with
 * `syncChangeSchema`: §8.3 answers `invalid` for the one bad row and applies the rest, so a single
 * unparsable body must not reject the whole batch with a 400.
 */
export const syncChangeEnvelopeSchema = z.object({
  entity: entityNameSchema,
  id: z.string().min(1),
  updatedAt: hlcSchema,
  deletedAt: z.iso.datetime().nullable(),
  data: z.unknown(),
});

export type SyncChangeEnvelope = z.infer<typeof syncChangeEnvelopeSchema>;

export const pushRequestSchema = z.object({
  schemaVersion: z.number().int().positive(),
  deviceId: z.string().min(1).max(128),
  changes: z.array(syncChangeEnvelopeSchema).max(MAX_CHANGES_PER_PUSH),
});

export type PushRequest = z.infer<typeof pushRequestSchema>;

export const pushResultStatusSchema = z.enum(['applied', 'stale', 'invalid']);

export const pushResponseSchema = z.object({
  schemaVersion: z.number().int().positive(),
  serverTime: z.iso.datetime(),
  results: z.array(
    z.object({
      entity: entityNameSchema,
      id: z.string().min(1),
      status: pushResultStatusSchema,
      error: z.string().optional(),
    }),
  ),
});

export type PushResponse = z.infer<typeof pushResponseSchema>;
export type PushResult = PushResponse['results'][number];

/**
 * A pulled row. `data` stays `unknown` here: the client validates it with `entitySchemas` as it
 * applies, so one unparsable row becomes one error instead of failing the whole page.
 */
export const pullChangeSchema = z.object({
  entity: entityNameSchema,
  id: z.string().min(1),
  updatedAt: hlcSchema,
  deletedAt: z.iso.datetime().nullable(),
  data: z.unknown(),
  seq: z.number().int().nonnegative(),
});

export type PullChange = z.infer<typeof pullChangeSchema>;

export const pullResponseSchema = z.object({
  schemaVersion: z.number().int().positive(),
  changes: z.array(pullChangeSchema),
  nextSince: z.number().int().nonnegative(),
  hasMore: z.boolean(),
});

export type PullResponse = z.infer<typeof pullResponseSchema>;

export type SchemaVersionVerdict = 'ok' | 'peer-too-old' | 'peer-too-new';

/**
 * Compares a peer's schema version with ours. Split out so both the app and the server phrase the
 * same verdict in their own words ("update the app" vs "update the server").
 */
export function compareSchemaVersion(peer: number): SchemaVersionVerdict {
  if (peer === SYNC_SCHEMA_VERSION) return 'ok';
  return peer < SYNC_SCHEMA_VERSION ? 'peer-too-old' : 'peer-too-new';
}
```

```ts
  it('keeps the winner whole — no field-level merge', () => {
    expect(mergeRecord(record(A, 'local'), record(B, 'remote')).value).toBe('remote');
    expect(mergeRecord(record(B, 'local'), record(A, 'remote')).value).toBe('local');
    expect(mergeRecord(null, record(A, 'remote')).value).toBe('remote');
  });

  it('lets a tombstone win like any other write', () => {
    const tombstone = { ...record(B, 'remote'), deletedAt: '2026-09-10T10:00:00.000Z' };
    expect(mergeRecord(record(A, 'local'), tombstone).deletedAt).not.toBeNull();

    const undeleted = record('001775000000002-0000-device-a', 'local');
    expect(mergeRecord(undeleted, tombstone).deletedAt).toBeNull();
  });

/** Deterministic PRNG: §3.2 forbids hidden randomness, and a flaky property test is useless. */
function lcg(seed: number): () => number {
  let state = seed >>> 0;
  return () => {
    state = (state * 1664525 + 1013904223) >>> 0;
    return state / 0x100000000;
  };
}

describe('convergence', () => {
  it('converges for random interleavings of two replicas', () => {
    for (let seed = 1; seed <= 40; seed += 1) {
      const random = lcg(seed);
      const clocks: Record<'a' | 'b', HlcState> = {
        a: { wallMs: 0, counter: 0, deviceId: 'device-a' },
        b: { wallMs: 0, counter: 0, deviceId: 'device-b' },
      };
      const replicas: Record<'a' | 'b', Map<string, SyncRecord & { value: number }>> = {
        a: new Map(),
        b: new Map(),
      };
      const outbox: { from: 'a' | 'b'; record: SyncRecord & { value: number } }[] = [];
      let wall = 1_700_000_000_000;

      const write = (side: 'a' | 'b', id: string, value: number) => {
        // Wall clocks drift in both directions, which is the whole point of an HLC.
        wall += Math.floor(random() * 5) - 2;
        const step = hlcNow(clocks[side], wall);
        clocks[side] = step.state;
        const next = { id, updatedAt: step.hlc, deletedAt: null, value };
        replicas[side].set(id, next);
        outbox.push({ from: side, record: next });
      };

      const deliver = (index: number) => {
        const message = outbox.splice(index, 1)[0];
        if (message === undefined) return;
        const to = message.from === 'a' ? 'b' : 'a';
        clocks[to] = hlcReceive(clocks[to], message.record.updatedAt, wall).state;
        const merged = mergeRecord(replicas[to].get(message.record.id) ?? null, message.record);
        replicas[to].set(message.record.id, merged);
      };

      for (let step = 0; step < 60; step += 1) {
        const id = `row-${Math.floor(random() * 4)}`;
        if (outbox.length > 0 && random() < 0.45) {
          deliver(Math.floor(random() * outbox.length));
        } else {
          write(random() < 0.5 ? 'a' : 'b', id, step);
        }
      }
      while (outbox.length > 0) deliver(0);

      const snapshot = (side: 'a' | 'b') =>
        [...replicas[side].entries()]
          .sort(([left], [right]) => left.localeCompare(right))
          .map(([id, row]) => `${id}:${row.updatedAt}:${row.value}`);
      expect(snapshot('a')).toEqual(snapshot('b'));
    }
  });

  it('is order-independent: the same writes delivered backwards land on the same row', () => {
    const writes = [record(A, 'first'), record(B, 'second')];
    const forward = writes.reduce<(SyncRecord & { value: string }) | null>(
      (local, remote) => mergeRecord(local, remote),
      null,
    );
    const backward = [...writes]
      .reverse()
      .reduce<(SyncRecord & { value: string }) | null>(
        (local, remote) => mergeRecord(local, remote),
        null,
      );
    expect(forward).toEqual(backward);
    expect(formatHlc({ wallMs: 1, counter: 0, deviceId: 'x' })).toBe('000000000000001-0000-x');
  });
});
```

```ts
import { compareHlc, type HlcString } from './hlc';

/** The three fields every synced row carries (§8.1). */
export interface SyncRecord {
  id: string;
  updatedAt: HlcString;
  deletedAt: string | null;
}

/**
 * §8.1: whole-row last-writer-wins. `updatedAt` is an HLC, so this is a total order every replica
 * computes the same way — which is what makes convergence independent of delivery order. Equal
 * timestamps mean the same write (the device id is inside the HLC), so the local row stays.
 */
export function shouldApplyRemote(remote: HlcString, local: HlcString | null): boolean {
  if (local === null) return true;
  return compareHlc(remote, local) > 0;
}

/**
 * The winning row, whole. No field-level merge: a tombstone and an edit are both just writes, and
 * whichever is later wins — including an undelete that comes after a delete.
 */
export function mergeRecord<T extends SyncRecord>(local: T | null, remote: T): T {
  if (local === null) return remote;
  return shouldApplyRemote(remote.updatedAt, local.updatedAt) ? remote : local;
}
```

```ts
import { sql } from 'drizzle-orm';
import type { ServerDatabase } from './types';

/**
 * §8.4: one global sequence, read per applied row. A sequence and not `max(seq) + 1`, because two
 * concurrent pushes must never mint the same cursor value — a client that pulled the lower one
 * would step over the higher one and never see it.
 */
export async function nextSeq(db: ServerDatabase): Promise<number> {
  const result = await db.execute<{ seq: string }>(sql`select nextval('sync_seq') as seq`);
  const rows = result.rows as { seq: string | number }[];
  const raw = rows[0]?.seq;
  if (raw === undefined) throw new Error('sync_seq returned no value');
  return typeof raw === 'number' ? raw : Number.parseInt(raw, 10);
}
```

```ts
import {
  type PushRequest,
  type PushResult,
  parseHlc,
  type SyncChangeEnvelope,
  syncChangeSchema,
} from '@saldo/core';
import { and, eq, sql } from 'drizzle-orm';
import { nextSeq } from '../db/syncSequence';
import { syncRows } from '../db/schema';
import type { ServerDatabase } from '../db/types';

/** §8.2: a device whose clock is further ahead than this cannot park rows in everyone's future. */
const MAX_CLOCK_SKEW_MS = 24 * 3600 * 1000;

function validate(change: SyncChangeEnvelope, now: Date): string | null {
  const parsed = syncChangeSchema.safeParse(change);
  if (!parsed.success) {
    return parsed.error.issues
      .map((issue) => `${issue.path.join('.') || '(root)'}: ${issue.message}`)
      .join('; ');
  }
  const hlc = parseHlc(change.updatedAt);
  if (hlc === null) return 'updatedAt: not an HLC';
  if (hlc.wallMs - now.getTime() > MAX_CLOCK_SKEW_MS) {
    return 'updatedAt: device clock is more than 24h ahead of the server';
  }
  return null;
}

/**
 * §8.3. One row at a time, each with its own verdict: `applied`, `stale` (the server already has a
 * newer row — the client will receive it on the next pull) or `invalid`.
 *
 * The upsert carries its own `where`, so two concurrent pushes of the same row cannot lose the
 * newer one: whichever commits second only wins if its HLC is greater.
 */
export async function applyPush(
  db: ServerDatabase,
  userId: string,
  request: PushRequest,
  now: Date,
): Promise<PushResult[]> {
  const results: PushResult[] = [];
  for (const change of request.changes) {
    const error = validate(change, now);
    if (error !== null) {
      results.push({ entity: change.entity, id: change.id, status: 'invalid', error });
      continue;
    }
    const seq = await nextSeq(db);
    const applied = await db
      .insert(syncRows)
      .values({
        userId,
        entity: change.entity,
        id: change.id,
        updatedAt: change.updatedAt,
        deletedAt: change.deletedAt === null ? null : new Date(change.deletedAt),
        data: change.data,
        seq,
      })
      .onConflictDoUpdate({
        target: [syncRows.userId, syncRows.entity, syncRows.id],
        set: {
          updatedAt: sql`excluded.updated_at`,
          deletedAt: sql`excluded.deleted_at`,
          data: sql`excluded.data`,
          seq: sql`excluded.seq`,
        },
        setWhere: sql`${syncRows.updatedAt} < excluded.updated_at`,
      })
      .returning({ id: syncRows.id });
    results.push({
      entity: change.entity,
      id: change.id,
      status: applied.length > 0 ? 'applied' : 'stale',
    });
  }
  return results;
}
```

```ts
import { MAX_CHANGES_PER_PULL, type PullChange } from '@saldo/core';
import { and, asc, eq, gt } from 'drizzle-orm';
import { syncRows } from '../db/schema';
import type { ServerDatabase } from '../db/types';
import type { EntityName } from '@saldo/core';

export interface PullPage {
  changes: PullChange[];
  nextSince: number;
  hasMore: boolean;
}

/**
 * §8.3. Ordered by `seq`, which is the only ordering a cursor can page over safely: HLCs are
 * assigned by devices and can arrive out of order, `seq` is assigned by the server as it applies.
 *
 * One row over the limit is fetched to answer `hasMore` without a second count query.
 */
export async function readPull(
  db: ServerDatabase,
  userId: string,
  options: { since: number; limit: number },
): Promise<PullPage> {
  const limit = Math.min(Math.max(1, options.limit), MAX_CHANGES_PER_PULL);
  const rows = await db
    .select()
    .from(syncRows)
    .where(and(eq(syncRows.userId, userId), gt(syncRows.seq, options.since)))
    .orderBy(asc(syncRows.seq))
    .limit(limit + 1);

  const page = rows.slice(0, limit);
  const changes: PullChange[] = page.map((row) => ({
    entity: row.entity as EntityName,
    id: row.id,
    updatedAt: row.updatedAt,
    deletedAt: row.deletedAt === null ? null : row.deletedAt.toISOString(),
    data: row.data,
    seq: row.seq,
  }));
  return {
    changes,
    nextSince: page.at(-1)?.seq ?? options.since,
    hasMore: rows.length > limit,
  };
}
```

```ts
import * as SecureStore from 'expo-secure-store';

export interface Tokens {
  accessToken: string;
  refreshToken: string;
  /** Epoch ms. Computed from `expires_in` when the pair is issued. */
  expiresAt: number;
  userId: string;
  displayName: string;
}

export interface TokenStore {
  load(serverUrl: string): Promise<Tokens | null>;
  save(serverUrl: string, tokens: Tokens): Promise<void>;
  clear(serverUrl: string): Promise<void>;
}

/**
 * §9.3 step 8: keys are scoped by server URL, so pointing the app at a second server does not
 * overwrite the first one's session. SecureStore only accepts alphanumerics, `.`, `-` and `_`,
 * hence the sanitising.
 */
export function tokenKey(serverUrl: string): string {
  return `saldo_tokens_${serverUrl.replace(/[^A-Za-z0-9.\-_]/g, '_')}`;
}

export function createSecureTokenStore(): TokenStore {
  return {
    async load(serverUrl) {
      const raw = await SecureStore.getItemAsync(tokenKey(serverUrl));
      if (raw === null) return null;
      try {
        return JSON.parse(raw) as Tokens;
      } catch {
        // Corrupt entry: treat it as signed out rather than crashing the app on boot.
        return null;
      }
    },
    async save(serverUrl, tokens) {
      await SecureStore.setItemAsync(tokenKey(serverUrl), JSON.stringify(tokens));
    },
    async clear(serverUrl) {
      await SecureStore.deleteItemAsync(tokenKey(serverUrl));
    },
  };
}

/** In-memory store for tests and for the "not signed in" case. */
export function createMemoryTokenStore(): TokenStore {
  const map = new Map<string, Tokens>();
  return {
    load: async (serverUrl) => map.get(serverUrl) ?? null,
    save: async (serverUrl, tokens) => {
      map.set(serverUrl, tokens);
    },
    clear: async (serverUrl) => {
      map.delete(serverUrl);
    },
  };
}
```

```ts
import type { z } from 'zod';
import type { TokenStore, Tokens } from '../auth/tokenStore';

export class ApiClientError extends Error {
  constructor(
    readonly status: number,
    readonly code: string,
    message: string,
  ) {
    super(message);
    this.name = 'ApiClientError';
  }
}

export interface ApiClient {
  get<T>(path: string, schema: z.ZodType<T>): Promise<T>;
  post<T>(path: string, body: unknown, schema: z.ZodType<T>): Promise<T>;
  /** Whether a session is stored for this server. */
  hasSession(): Promise<boolean>;
}

export interface ApiClientOptions {
  serverUrl: string;
  store: TokenStore;
  onSessionExpired?: () => void;
  fetchImpl?: (request: Request) => Promise<Response>;
}

interface TokenPairBody {
  access_token: string;
  refresh_token: string;
  expires_in: number;
  user: { id: string; displayName: string };
}

export function tokensFromBody(body: TokenPairBody, now: number): Tokens {
  return {
    accessToken: body.access_token,
    refreshToken: body.refresh_token,
    expiresAt: now + body.expires_in * 1000,
    userId: body.user.id,
    displayName: body.user.displayName,
  };
}

async function readError(response: Response): Promise<ApiClientError> {
  const payload: unknown = await response.json().catch(() => null);
  const error =
    typeof payload === 'object' && payload !== null
      ? (payload as { error?: { code?: string; message?: string } }).error
      : undefined;
  return new ApiClientError(
    response.status,
    error?.code ?? 'http_error',
    error?.message ?? `Request failed with ${response.status}`,
  );
}

/**
 * The one place that talks to the server. It attaches the bearer, and on a 401 it refreshes **once**
 * and retries. The refresh is shared between concurrent callers on purpose: the server revokes a
 * whole refresh chain when a token is presented twice (§9.3 step 6), so two parallel refreshes
 * would sign the device out.
 */
export function createApiClient(options: ApiClientOptions): ApiClient {
  const fetchImpl = options.fetchImpl ?? ((request: Request) => fetch(request));
  const base = options.serverUrl.replace(/\/$/, '');
  let refreshing: Promise<Tokens | null> | null = null;

  const refresh = async (current: Tokens): Promise<Tokens | null> => {
    const response = await fetchImpl(
      new Request(`${base}/api/auth/token`, {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({
          grant_type: 'refresh_token',
          refresh_token: current.refreshToken,
        }),
      }),
    );
    if (!response.ok) {
      await options.store.clear(options.serverUrl);
      options.onSessionExpired?.();
      return null;
    }
    const body = (await response.json()) as TokenPairBody;
    const next = tokensFromBody(body, Date.now());
    await options.store.save(options.serverUrl, next);
    return next;
  };

  const refreshOnce = (current: Tokens): Promise<Tokens | null> => {
    refreshing ??= refresh(current).finally(() => {
      refreshing = null;
    });
    return refreshing;
  };

  const send = async <T>(
    path: string,
    init: RequestInit,
    schema: z.ZodType<T>,
    retried = false,
  ): Promise<T> => {
    const stored = await options.store.load(options.serverUrl);
    if (stored === null) throw new ApiClientError(401, 'no_session', 'Not signed in');
    const request = new Request(`${base}${path}`, {
      ...init,
      headers: {
        ...(init.headers as Record<string, string> | undefined),
        authorization: `Bearer ${stored.accessToken}`,
      },
    });
    const response = await fetchImpl(request);
    if (response.status === 401 && !retried) {
      const refreshed = await refreshOnce(stored);
      if (refreshed === null) throw await readError(response);
      return send(path, init, schema, true);
    }
    if (!response.ok) throw await readError(response);
    const payload: unknown = await response.json();
    const parsed = schema.safeParse(payload);
    if (!parsed.success) {
      throw new ApiClientError(502, 'bad_response', 'The server sent an unexpected response');
    }
    return parsed.data;
  };

  return {
    get: (path, schema) => send(path, { method: 'GET' }, schema),
    post: (path, body, schema) =>
      send(
        path,
        { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify(body) },
        schema,
      ),
    hasSession: async () => (await options.store.load(options.serverUrl)) !== null,
  };
}
```

```ts
import * as Crypto from 'expo-crypto';

export const REDIRECT_URI = 'saldo://auth/callback';

export interface PkceChallenge {
  verifier: string;
  challenge: string;
  state: string;
}

const VERIFIER_BYTES = 64;

function base64UrlFromBytes(bytes: Uint8Array): string {
  let binary = '';
  for (const byte of bytes) binary += String.fromCharCode(byte);
  return globalThis.btoa(binary).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}

/** §9.3 step 2. `expo-crypto` is the only source of randomness — never `Math.random`. */
export async function createPkceChallenge(): Promise<PkceChallenge> {
  const verifier = base64UrlFromBytes(Crypto.getRandomBytes(VERIFIER_BYTES));
  const challenge = await Crypto.digestStringAsync(
    Crypto.CryptoDigestAlgorithm.SHA256,
    verifier,
    { encoding: Crypto.CryptoEncoding.BASE64 },
  ).then((digest) => digest.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, ''));
  const state = base64UrlFromBytes(Crypto.getRandomBytes(16));
  return { verifier, challenge, state };
}

/**
 * What the user typed, turned into an origin. A bare hostname gets `https://`, because that is the
 * only scheme a real deployment can use (§9.2) — `http` survives only when it is spelled out, for
 * `http://localhost` during development.
 */
export function normaliseServerUrl(input: string): string | null {
  const trimmed = input.trim();
  if (trimmed.length === 0) return null;
  const withScheme = /^https?:\/\//.test(trimmed) ? trimmed : `https://${trimmed}`;
  if (!URL.canParse(withScheme)) return null;
  const url = new URL(withScheme);
  if (url.hostname.length === 0 || url.hostname.includes(' ')) return null;
  if (url.pathname !== '/' && url.pathname !== '') return null;
  return `${url.protocol}//${url.host}`;
}

export function authorizeUrl(
  serverUrl: string,
  params: { redirectUri: string; codeChallenge: string; state: string; mode: 'login' | 'register' },
): string {
  const url = new URL('/auth/mobile', serverUrl);
  url.searchParams.set('redirect_uri', params.redirectUri);
  url.searchParams.set('code_challenge', params.codeChallenge);
  url.searchParams.set('state', params.state);
  url.searchParams.set('mode', params.mode);
  return url.toString();
}

export function callbackParams(redirect: string): { code: string; state: string } | null {
  if (!URL.canParse(redirect)) return null;
  const params = new URL(redirect).searchParams;
  const code = params.get('code');
  const state = params.get('state');
  if (code === null || state === null) return null;
  return { code, state };
}
```

```ts
import * as Application from 'expo-application';
import * as WebBrowser from 'expo-web-browser';
import { z } from 'zod';
import { ApiClientError, tokensFromBody } from '../net/apiClient';
import { authorizeUrl, callbackParams, createPkceChallenge, REDIRECT_URI } from './pkce';
import type { TokenStore, Tokens } from './tokenStore';

export const healthSchema = z.object({
  app: z.literal('saldo'),
  apiVersion: z.number(),
  schemaVersion: z.number(),
  version: z.string(),
  registrationAllowed: z.boolean(),
});

export type ServerHealth = z.infer<typeof healthSchema>;

const tokenBodySchema = z.object({
  access_token: z.string(),
  refresh_token: z.string(),
  expires_in: z.number(),
  user: z.object({ id: z.string(), displayName: z.string() }),
});

/** §9.3 step 1. Unauthenticated, so it runs before any session exists. */
export async function checkServer(serverUrl: string): Promise<ServerHealth> {
  const response = await fetch(`${serverUrl}/api/health`);
  if (!response.ok) {
    throw new ApiClientError(response.status, 'unreachable', 'The server did not answer');
  }
  const parsed = healthSchema.safeParse(await response.json());
  if (!parsed.success) {
    throw new ApiClientError(502, 'not_saldo', 'That URL does not look like a Saldo server');
  }
  return parsed.data;
}

function deviceName(): string {
  return Application.applicationName ?? 'Saldo';
}

/**
 * §9.3 steps 3–5: open the server's passkey page in a browser session, wait for it to come back to
 * `saldo://auth/callback`, check `state`, then exchange the code with the verifier that never left
 * the device.
 */
export async function signIn(options: {
  serverUrl: string;
  store: TokenStore;
  mode: 'login' | 'register';
}): Promise<Tokens> {
  const { verifier, challenge, state } = await createPkceChallenge();
  const result = await WebBrowser.openAuthSessionAsync(
    authorizeUrl(options.serverUrl, {
      redirectUri: REDIRECT_URI,
      codeChallenge: challenge,
      state,
      mode: options.mode,
    }),
    REDIRECT_URI,
  );
  if (result.type !== 'success') {
    throw new ApiClientError(499, 'cancelled', 'Sign-in was cancelled');
  }
  const params = callbackParams(result.url);
  if (params === null) throw new ApiClientError(400, 'bad_callback', 'The server sent no code');
  // A mismatched state means the callback did not come from the request we started.
  if (params.state !== state) {
    throw new ApiClientError(400, 'state_mismatch', 'Sign-in could not be verified');
  }

  const response = await fetch(`${options.serverUrl}/api/auth/token`, {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify({
      grant_type: 'authorization_code',
      code: params.code,
      code_verifier: verifier,
      device_name: deviceName(),
    }),
  });
  if (!response.ok) {
    throw new ApiClientError(response.status, 'exchange_failed', 'Could not complete sign-in');
  }
  const body = tokenBodySchema.parse(await response.json());
  const tokens = tokensFromBody(body, Date.now());
  await options.store.save(options.serverUrl, tokens);
  return tokens;
}

/** §9.3 step 7. Revokes server-side, then forgets the pair locally whatever the server said. */
export async function signOut(serverUrl: string, store: TokenStore): Promise<void> {
  const stored = await store.load(serverUrl);
  if (stored !== null) {
    await fetch(`${serverUrl}/api/auth/logout`, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ refresh_token: stored.refreshToken }),
    }).catch(() => undefined);
  }
  await store.clear(serverUrl);
}
```

```ts
import {
  type EntityName,
  entitySchemas,
  type PullChange,
  shouldApplyRemote,
  type SyncChangeEnvelope,
} from '@saldo/core';
import { and, eq, sql } from 'drizzle-orm';
import type { Clock } from '../db/clock';
import type { KvStore } from '../db/kv';
import type { RepositoryDatabase } from '../db/repositories/support';
import { PENDING, SYNC_ERROR, SYNCED } from '../db/repositories/support';
import { isSyncedEntity, SYNCED_ENTITY_NAMES, SYNCED_TABLES, type SyncedEntityName } from './entities';

interface SyncRow {
  id: string;
  updatedAt: string;
  deletedAt: string | null;
  syncState: number;
}

/**
 * Everything written locally and not yet acknowledged, as wire envelopes. This does not go through
 * the repositories: they hide tombstones, and a tombstone is exactly what the other device needs.
 */
export function pendingChanges(db: RepositoryDatabase, limit: number): SyncChangeEnvelope[] {
  const changes: SyncChangeEnvelope[] = [];
  for (const entity of SYNCED_ENTITY_NAMES) {
    if (changes.length >= limit) break;
    const table = SYNCED_TABLES[entity];
    const rows = db
      .select()
      .from(table)
      .where(eq(table.syncState, PENDING))
      .limit(limit - changes.length)
      .all() as (SyncRow & Record<string, unknown>)[];
    for (const row of rows) {
      const { syncState: _ignored, ...data } = row;
      changes.push({
        entity,
        id: row.id,
        updatedAt: row.updatedAt,
        deletedAt: row.deletedAt,
        data,
      });
    }
  }
  return changes;
}

export function pendingCount(db: RepositoryDatabase): number {
  let total = 0;
  for (const entity of SYNCED_ENTITY_NAMES) {
    const table = SYNCED_TABLES[entity];
    const [row] = db
      .select({ count: sql<number>`count(*)` })
      .from(table)
      .where(eq(table.syncState, PENDING))
      .all();
    total += row?.count ?? 0;
  }
  return total;
}

export function errorCount(db: RepositoryDatabase): number {
  let total = 0;
  for (const entity of SYNCED_ENTITY_NAMES) {
    const table = SYNCED_TABLES[entity];
    const [row] = db
      .select({ count: sql<number>`count(*)` })
      .from(table)
      .where(eq(table.syncState, SYNC_ERROR))
      .all();
    total += row?.count ?? 0;
  }
  return total;
}

/**
 * §8.3: clear the pending flag **only if** the row still carries the timestamp that was pushed. A
 * write that happened while the request was in flight must stay pending, or it would never be sent.
 */
export function markPushed(
  db: RepositoryDatabase,
  entity: SyncedEntityName,
  id: string,
  pushedUpdatedAt: string,
): void {
  const table = SYNCED_TABLES[entity];
  db.update(table)
    .set({ syncState: SYNCED })
    .where(and(eq(table.id, id), eq(table.updatedAt, pushedUpdatedAt)))
    .run();
}

export function markInvalid(
  db: RepositoryDatabase,
  entity: SyncedEntityName,
  id: string,
): void {
  const table = SYNCED_TABLES[entity];
  db.update(table).set({ syncState: SYNC_ERROR }).where(eq(table.id, id)).run();
}

export interface ApplyPullInput {
  db: RepositoryDatabase;
  kv: KvStore;
  clock: Clock;
  changes: readonly PullChange[];
  nextSince: number;
}

export interface ApplyPullOutcome {
  applied: number;
  skipped: number;
  errors: number;
}

/**
 * §8.3: applies a page and stores the cursor **in the same transaction as the rows**, so a crash
 * mid-page cannot leave the cursor ahead of the data it stands for.
 */
export function applyPull(input: ApplyPullInput): ApplyPullOutcome {
  const { db, kv, clock, changes, nextSince } = input;
  const outcome: ApplyPullOutcome = { applied: 0, skipped: 0, errors: 0 };
  db.transaction((tx) => {
    for (const change of changes) {
      // Every timestamp seen moves the local clock forward, whether or not the row is applied.
      clock.receive(change.updatedAt);
      if (!isSyncedEntity(change.entity as EntityName)) {
        outcome.skipped += 1;
        continue;
      }
      const entity = change.entity as SyncedEntityName;
      const parsed = entitySchemas[entity].safeParse(change.data);
      if (!parsed.success) {
        outcome.errors += 1;
        continue;
      }
      const table = SYNCED_TABLES[entity];
      const [local] = tx
        .select({ updatedAt: table.updatedAt })
        .from(table)
        .where(eq(table.id, change.id))
        .all();
      if (!shouldApplyRemote(change.updatedAt, local?.updatedAt ?? null)) {
        outcome.skipped += 1;
        continue;
      }
      const values = { ...parsed.data, syncState: SYNCED };
      tx.insert(table)
        .values(values)
        .onConflictDoUpdate({ target: table.id, set: values })
        .run();
      outcome.applied += 1;
    }
    kv.set('syncCursor', String(nextSince));
  });
  return outcome;
}
```

```ts
import {
  compareSchemaVersion,
  MAX_CHANGES_PER_PULL,
  MAX_CHANGES_PER_PUSH,
  pullResponseSchema,
  pushResponseSchema,
  SYNC_SCHEMA_VERSION,
} from '@saldo/core';
import type { Clock } from '../db/clock';
import type { KvStore } from '../db/kv';
import type { RepositoryDatabase } from '../db/repositories/support';
import { ApiClientError, type ApiClient } from '../net/apiClient';
import { isSyncedEntity } from './entities';
import { applyPull, markInvalid, markPushed, pendingChanges } from './localStore';

export interface SyncOutcome {
  pushed: number;
  stale: number;
  invalid: number;
  pulled: number;
  errors: number;
}

export interface SyncDeps {
  db: RepositoryDatabase;
  kv: KvStore;
  clock: Clock;
  api: ApiClient;
  deviceId: string;
  /** Runs after a successful cycle: pulled recurrences may need new occurrences (§8.5). */
  materialise?: () => void;
}

/**
 * One cycle (§8.5): push everything pending in batches, then pull until the server says there is
 * nothing left. Push first, so a row this device just wrote wins its own conflict rather than
 * being overwritten by the copy the server still has.
 */
export async function runSyncCycle(deps: SyncDeps): Promise<SyncOutcome> {
  const outcome: SyncOutcome = { pushed: 0, stale: 0, invalid: 0, pulled: 0, errors: 0 };

  for (;;) {
    const batch = pendingChanges(deps.db, MAX_CHANGES_PER_PUSH);
    if (batch.length === 0) break;
    const response = await deps.api.post(
      '/api/sync/push',
      { schemaVersion: SYNC_SCHEMA_VERSION, deviceId: deps.deviceId, changes: batch },
      pushResponseSchema,
    );
    assertSameSchema(response.schemaVersion);
    for (const result of response.results) {
      if (!isSyncedEntity(result.entity)) continue;
      const pushedChange = batch.find(
        (change) => change.id === result.id && change.entity === result.entity,
      );
      if (pushedChange === undefined) continue;
      if (result.status === 'invalid') {
        markInvalid(deps.db, result.entity, result.id);
        outcome.invalid += 1;
        continue;
      }
      // `stale` is not a failure: the server has a newer row and the pull below will bring it.
      markPushed(deps.db, result.entity, result.id, pushedChange.updatedAt);
      if (result.status === 'stale') outcome.stale += 1;
      else outcome.pushed += 1;
    }
    // A batch whose rows all came back unacknowledged would loop forever; nothing acknowledged
    // means nothing changed, so stop and let the next cycle retry.
    if (response.results.length === 0) break;
  }

  let since = Number.parseInt(deps.kv.get('syncCursor') ?? '0', 10);
  if (!Number.isFinite(since) || since < 0) since = 0;
  for (;;) {
    const page = await deps.api.get(
      `/api/sync/pull?since=${since}&limit=${MAX_CHANGES_PER_PULL}`,
      pullResponseSchema,
    );
    assertSameSchema(page.schemaVersion);
    if (page.changes.length > 0) {
      const applied = applyPull({
        db: deps.db,
        kv: deps.kv,
        clock: deps.clock,
        changes: page.changes,
        nextSince: page.nextSince,
      });
      outcome.pulled += applied.applied;
      outcome.errors += applied.errors;
    }
    since = page.nextSince;
    if (!page.hasMore) break;
  }

  deps.materialise?.();
  return outcome;
}

function assertSameSchema(peer: number): void {
  const verdict = compareSchemaVersion(peer);
  if (verdict === 'ok') return;
  // §8.1: stop rather than exchange rows one side cannot represent.
  throw new ApiClientError(
    409,
    verdict === 'peer-too-old' ? 'schema_too_old' : 'schema_too_new',
    verdict === 'peer-too-old' ? 'The server is older than this app' : 'This app is older than the server',
  );
}
```

```ts
import { ApiClientError } from '../net/apiClient';
import { runSyncCycle, type SyncDeps, type SyncOutcome } from './client';

/** §8.5. */
export const BACKOFF_MS = [5_000, 15_000, 60_000, 300_000] as const;
export const FOREGROUND_INTERVAL_MS = 60_000;
export const WRITE_DEBOUNCE_MS = 2_000;

export type SyncStatus =
  | { kind: 'idle'; lastSyncAt: number | null }
  | { kind: 'syncing' }
  | { kind: 'error'; code: string; message: string; retryAt: number }
  | { kind: 'session-expired' };

export interface Scheduler {
  /** Runs a cycle unless one is already running, in which case it joins it. */
  syncNow(): Promise<SyncOutcome | null>;
  /** Coalesces bursts of local writes into one cycle (§8.5). */
  requestSync(): void;
  status(): SyncStatus;
  subscribe(listener: (status: SyncStatus) => void): () => void;
  stop(): void;
}

export interface SchedulerOptions {
  deps: () => SyncDeps | null;
  now?: () => number;
  setTimer?: (fn: () => void, ms: number) => ReturnType<typeof setTimeout>;
  clearTimer?: (handle: ReturnType<typeof setTimeout>) => void;
}

/**
 * Serialises sync cycles. Never two at once (§8.5): two concurrent cycles would push the same rows
 * twice and race each other's cursor writes. Failures back off through `BACKOFF_MS`; a 401 that
 * survives the client's own refresh attempt parks the app in "session expired", where local use
 * carries on as normal.
 */
export function createScheduler(options: SchedulerOptions): Scheduler {
  const now = options.now ?? Date.now;
  const setTimer = options.setTimer ?? setTimeout;
  const clearTimer = options.clearTimer ?? clearTimeout;

  let inFlight: Promise<SyncOutcome | null> | null = null;
  let failures = 0;
  let debounce: ReturnType<typeof setTimeout> | null = null;
  let status: SyncStatus = { kind: 'idle', lastSyncAt: null };
  const listeners = new Set<(next: SyncStatus) => void>();

  const publish = (next: SyncStatus): void => {
    status = next;
    for (const listener of listeners) listener(next);
  };

  const cycle = async (): Promise<SyncOutcome | null> => {
    const deps = options.deps();
    if (deps === null) return null;
    publish({ kind: 'syncing' });
    try {
      const outcome = await runSyncCycle(deps);
      failures = 0;
      publish({ kind: 'idle', lastSyncAt: now() });
      return outcome;
    } catch (error) {
      const code = error instanceof ApiClientError ? error.code : 'network_error';
      const message = error instanceof Error ? error.message : 'Sync failed';
      if (code === 'no_session' || code === 'invalid_token' || code === 'invalid_grant') {
        publish({ kind: 'session-expired' });
        return null;
      }
      const delay = BACKOFF_MS[Math.min(failures, BACKOFF_MS.length - 1)] ?? 300_000;
      failures += 1;
      publish({ kind: 'error', code, message, retryAt: now() + delay });
      return null;
    }
  };

  return {
    syncNow() {
      inFlight ??= cycle().finally(() => {
        inFlight = null;
      });
      return inFlight;
    },
    requestSync() {
      if (debounce !== null) clearTimer(debounce);
      debounce = setTimer(() => {
        debounce = null;
        void this.syncNow();
      }, WRITE_DEBOUNCE_MS);
    },
    status: () => status,
    subscribe(listener) {
      listeners.add(listener);
      return () => listeners.delete(listener);
    },
    stop() {
      if (debounce !== null) clearTimer(debounce);
      debounce = null;
      listeners.clear();
    },
  };
}
```

```tsx
import { useDatabase } from '../db/DatabaseProvider';
import { createApiClient, type ApiClient } from '../net/apiClient';
import { checkServer, signIn, signOut, type ServerHealth } from './session';
import { createSecureTokenStore, type Tokens } from './tokenStore';

export interface ServerValue {
  /** Null when the app is local-only (§6.29 step 0). */
  serverUrl: string | null;
  session: Tokens | null;
  api: ApiClient | null;
  sessionExpired: boolean;
  check(url: string): Promise<ServerHealth>;
  connect(url: string, mode: 'login' | 'register'): Promise<Tokens>;
  disconnect(): Promise<void>;
  reload(): Promise<void>;
}

const ServerContext = createContext<ServerValue | null>(null);

export function ServerProvider({ children }: { children: ReactNode }) {
  const { kv } = useDatabase();
  const store = useMemo(createSecureTokenStore, []);
  const [serverUrl, setServerUrl] = useState<string | null>(() => kv.get('serverUrl'));
  const [session, setSession] = useState<Tokens | null>(null);
  const [sessionExpired, setSessionExpired] = useState(false);

  const reload = useCallback(async () => {
    const url = kv.get('serverUrl');
    setServerUrl(url);
    setSession(url === null ? null : await store.load(url));
  }, [kv, store]);

  const api = useMemo(() => {
    if (serverUrl === null) return null;
    return createApiClient({
      serverUrl,
      store,
      onSessionExpired: () => {
        setSessionExpired(true);
        setSession(null);
      },
    });
  }, [serverUrl, store]);

  const value = useMemo<ServerValue>(
    () => ({
      serverUrl,
      session,
      api,
      sessionExpired,
      check: (url) => checkServer(url),
      connect: async (url, mode) => {
        const tokens = await signIn({ serverUrl: url, store, mode });
        kv.set('serverUrl', url);
        setServerUrl(url);
        setSession(tokens);
        setSessionExpired(false);
        return tokens;
      },
      disconnect: async () => {
        if (serverUrl !== null) await signOut(serverUrl, store);
        // The server URL is forgotten too: §6.30's "Esci" leaves the app local-only, with the data.
        kv.remove('serverUrl');
        kv.remove('syncCursor');
        setServerUrl(null);
        setSession(null);
        setSessionExpired(false);
      },
      reload,
    }),
    [serverUrl, session, api, sessionExpired, store, kv, reload],
  );

  return <ServerContext.Provider value={value}>{children}</ServerContext.Provider>;
}

export function useServer(): ServerValue {
  const value = useContext(ServerContext);
  if (value === null) throw new Error('useServer must be used inside a ServerProvider');
  return value;
}
```

```tsx
import { createContext, type ReactNode, useContext, useEffect, useMemo, useState } from 'react';
import { AppState } from 'react-native';
import { useServer } from '../auth/ServerProvider';
import { db } from '../db/client';
import { useDatabase } from '../db/DatabaseProvider';
import { createClock } from '../db/clock';
import { runMaterialiser } from '../db/recurrenceService';
import { usePeriod } from '../features/period/PeriodProvider';
import { createScheduler, FOREGROUND_INTERVAL_MS, type Scheduler, type SyncStatus } from './scheduler';

export interface SyncValue {
  status: SyncStatus;
  scheduler: Scheduler | null;
}

const SyncContext = createContext<SyncValue>({
  status: { kind: 'idle', lastSyncAt: null },
  scheduler: null,
});

/**
 * Wires the scheduler to the app's lifecycle (§8.5): a cycle on mount, one on every foreground,
 * and one a minute while the app is in front. Mounted below `PeriodProvider` because the
 * materialiser needs `cycleStartDay`.
 */
export function SyncProvider({ children }: { children: ReactNode }) {
  const { kv } = useDatabase();
  const { api, session } = useServer();
  const { today, cycleStartDay } = usePeriod();
  const [status, setStatus] = useState<SyncStatus>({ kind: 'idle', lastSyncAt: null });

  const scheduler = useMemo(() => {
    if (api === null) return null;
    return createScheduler({
      deps: () => {
        const repos = kv;
        if (repos === null) return null;
        return {
          db,
          kv,
          clock: createClock(kv),
          api,
          deviceId: kv.deviceId(),
          materialise: () => {
            runMaterialiser(db, createRepositoriesForSync(), today, cycleStartDay);
          },
        };
      },
    });
  }, [api, kv, today, cycleStartDay]);

  useEffect(() => {
    if (scheduler === null) return;
    const unsubscribe = scheduler.subscribe(setStatus);
    void scheduler.syncNow();
    const interval = setInterval(() => {
      if (AppState.currentState === 'active') void scheduler.syncNow();
    }, FOREGROUND_INTERVAL_MS);
    const appState = AppState.addEventListener('change', (next) => {
      if (next === 'active') void scheduler.syncNow();
    });
    return () => {
      unsubscribe();
      clearInterval(interval);
      appState.remove();
      scheduler.stop();
    };
  }, [scheduler, session?.userId]);

  return (
    <SyncContext.Provider value={{ status, scheduler }}>{children}</SyncContext.Provider>
  );
}

export function useSync(): SyncValue {
  return useContext(SyncContext);
}
```
