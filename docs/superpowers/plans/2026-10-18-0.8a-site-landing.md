# 0.8a — Marketing site: the landing page — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/site`, a static Astro app with one English landing page, as the spec and the chosen mockup describe it.

**Architecture:** Astro with `output: 'static'`. The page is `.astro` components that read one content object for each locale (`src/content/en.ts`). The phone screens are components drawn from the `@saldo/ui` tokens; their app strings come from the `@saldo/i18n` catalog through `appText`. The client gets three small scripts only: the theme (inline in `<head>`, plus the toggle), the carousel and the copy buttons. Vercel serves the build from its own project with the root directory `apps/site`.

**Tech Stack:** Astro 7 (static), TypeScript 6 for `astro check` (D51), Vitest 5, Playwright 1.63, Biome 2.5 with full HTML support, `@fontsource/geist-sans` and `@fontsource/geist-mono`, the workspace packages `@saldo/ui`, `@saldo/i18n` and `@saldo/core`.

**Sources of truth:**

- Spec: `docs/superpowers/specs/2026-10-18-marketing-site.html` (D41–D51). It wins over this plan on behaviour.
- Design: `docs/superpowers/mockups/2026-10-18-marketing-site-product.html`. Open it at 1440 and 390, in both themes, before you start.
- Ground truth for the phone screens: `docs/screenshots/*.png` (layout and numbers only; the data there is Italian).

**How this plan was checked.** Every file below was built in a copy of the workspace before the plan was written: `astro check` (0 errors), `vitest` (13 tests), `astro build`, the Playwright suite (10 tests, 1440 and 390) and `biome check` were green. | Tokens | Two new tokens in `@saldo/ui`: `fontSize.siteDisplay` (72) and `palettes.*.deviceIsland` (`#000000`). Two new icons: `sun`, `moon` (Lucide, for the theme toggle). | D48 |

| Lint | Biome with `html.experimentalFullSupportEnabled`. `noDescendingSpecificity` is off for `apps/site/src/styles/**` only (see Task 5). | D49 |
| TypeScript | `apps/site` pins TypeScript 6 because `@astrojs/check` 0.9.10 accepts 5 or 6 only. | D51 |
| Telemetry | Every Astro script runs with `ASTRO_TELEMETRY_DISABLED=1`. The site says «Nothing reported», and its tools report nothing either. | spec §07 |

### Why the site copy is not in `@saldo/i18n`

The parity test of `@saldo/i18n` (`packages/i18n/src/locales.test.ts`) needs every key in all seven catalogs. Marketing copy there would need six translations before launch. The phone app and the web app import those catalogs, so they would also carry the marketing copy. The site starts in English only (D43), and a second language is one more object with the same type (`SiteContent`). The type checker stops an incomplete object, so the site needs no parity test of its own until a second locale exists.

The phone screens are different: they must say what the app says. They read the app catalog, never a copy of it.

### Test policy (AGENTS.md «Tests»)

- **Unit tests:** the carousel rules (`src/lib/carousel.test.ts`, pure functions: stops, projection, rubber band, spring) and the key check (`src/lib/appText.test.ts`, the sync between the site and `en.ts`).
- **End-to-end:** Playwright in `apps/site/e2e/`, at 1440 and 390: no console errors, no horizontal overflow, only the two calls to action, ten named screens, buttons and keys and a mouse flick stop on a card, the theme toggle survives a reload.
- **No tests** for the copy, the sample data, the tokens, the components or the links.

```ts
/**
 * D45: the public origin of the build. `SITE_URL` when it is set; on Vercel, the production host
 * that Vercel names; anywhere else, the dev server. No domain is written in the code.
 */
export function siteUrl(env: Readonly<Record<string, string | undefined>>): string {
  const explicit = env.SITE_URL?.trim();
  if (explicit) return explicit;
  const vercel = env.VERCEL_PROJECT_PRODUCTION_URL?.trim();
  if (vercel) return `https://${vercel}`;
  return 'http://localhost:4321';
}
```

```ts
/**
 * The rules of the screens carousel (spec 0.8a §05), as pure functions. The script
 * `src/scripts/carousel.ts` reads the DOM and calls these; the tests call them directly.
 */

/** A stop closer than this to the end becomes the end, so «previous» from the end moves a whole card. */
export const END_MERGE_PX = 32;
/** A mouse press becomes a drag after this much horizontal movement. */
export const DRAG_START_PX = 5;
/** The release speed comes from the pointer samples of this last window. */
export const SAMPLE_WINDOW_MS = 100;
export const MAX_SPEED = 6000;
/** Apple's deceleration rate for paging: a flick carries about two cards, not the whole strip. */
export const PAGING_RATE = 0.99;
export const RUBBER_BAND = 0.55;
export const SPRING_RESPONSE_S = 0.42;
export const SETTLE_DISTANCE = 0.5;
export const SETTLE_SPEED = 12;

/** The resting positions: each card's left edge minus the scroll padding, clamped to 0…max. */
export function snapStops(offsets: readonly number[], padStart: number, max: number): number[] {
  const stops: number[] = [];
  for (const offset of offsets) {
    const clamped = Math.max(0, Math.min(max, offset - padStart));
    const stop = Math.round(clamped > max - END_MERGE_PX ? max : clamped);
    if (!stops.includes(stop)) stops.push(stop);
  }
  return stops.sort((a, b) => a - b);
}

export function nearestStop(stops: readonly number[], x: number): number {
  let best = stops[0] ?? 0;
  for (const stop of stops) if (Math.abs(stop - x) < Math.abs(best - x)) best = stop;
  return best;
}

/** The next stop in `direction` from `x`, or null at that end. */
export function adjacentStop(
  stops: readonly number[],
  x: number,
  direction: 1 | -1,
): number | null {
  if (direction > 0) return stops.find((stop) => stop > x + 2) ?? null;
  for (let index = stops.length - 1; index >= 0; index -= 1) {
    const stop = stops[index];
    if (stop !== undefined && stop < x - 2) return stop;
  }
  return null;
}

/** How far a release at `velocity` (px/s) carries: Apple's projection, at the paging rate. */
export function project(velocity: number): number {
  return (velocity / 1000) * (PAGING_RATE / (1 - PAGING_RATE));
}

/** Where a release comes to rest: the stop nearest the projected position. */
export function restingStop(stops: readonly number[], x: number, velocity: number): number {
  return nearestStop(stops, x + project(velocity));
}

/** Past an end, the track follows less and less: the further it goes, the harder it pulls. */
export function rubberBand(overshoot: number, dimension: number): number {
  if (overshoot === 0) return 0;
  const distance = Math.abs(overshoot);
  return (
    Math.sign(overshoot) *
    ((distance * dimension * RUBBER_BAND) / (dimension + RUBBER_BAND * distance))
  );
}

export interface PointerSample {
  /** clientX, px */
  x: number;
  /** event.timeStamp, ms */
  t: number;
}

/**
 * The scroll velocity at release, px/s: the pointer moving left scrolls right. From the samples of
 * the last `SAMPLE_WINDOW_MS`, clamped to ±`MAX_SPEED`.
 */
export function releaseVelocity(samples: readonly PointerSample[]): number {
  const last = samples[samples.length - 1];
  if (last === undefined) return 0;
  const first = samples.find((sample) => last.t - sample.t <= SAMPLE_WINDOW_MS) ?? last;
  const elapsed = Math.max(16, last.t - first.t);
  const velocity = (-(last.x - first.x) / elapsed) * 1000;
  return Math.max(-MAX_SPEED, Math.min(MAX_SPEED, velocity));
}

/** A critically damped spring from `from` to `to` with start velocity `velocity`, at `t` seconds. */
export function springAt(
  from: number,
  to: number,
  velocity: number,
  t: number,
): { x: number; v: number } {
  const omega = (2 * Math.PI) / SPRING_RESPONSE_S;
  const offset = from - to;
  const c = velocity + omega * offset;
  const decay = Math.exp(-omega * t);
  return { x: to + (offset + c * t) * decay, v: (c - omega * (offset + c * t)) * decay };
}

export function isSettled(x: number, to: number, v: number): boolean {
  return Math.abs(x - to) < SETTLE_DISTANCE && Math.abs(v) < SETTLE_SPEED;
}
```

```ts
import { budgetProgress, cycleLength, diffDays, elapsedDays } from '@saldo/core';
import type { CategoryKey } from '../content/en';
import type { SiteContent } from '../content/index';

/**
 * Figures that more than one screen shows, calculated from the sample data so they cannot disagree
 * (spec 0.8a §12). The over-pace rule is `@saldo/core`'s own `budgetProgress`.
 */
type Sample = SiteContent['sample'];

const sum = (values: readonly number[]) => values.reduce((total, value) => total + value, 0);

export function incomeTotal(sample: Sample): number {
  return sum(sample.income.map((entry) => entry.amount));
}

export function expensesTotal(sample: Sample): number {
  return sum(Object.values(sample.spent));
}

export function leftToSpend(sample: Sample): number {
  return incomeTotal(sample) - expensesTotal(sample);
}

/** Day of the period and its length: «day 13 of 30». */
export function periodDay(sample: Sample): {
  elapsed: number;
  length: number;
  pace: number;
  daysLeft: number;
} {
  const elapsed = elapsedDays(sample.period, sample.period.today);
  const length = cycleLength(sample.period);
  return { elapsed, length, pace: elapsed / length, daysLeft: length - elapsed };
}

export interface BudgetState {
  category: CategoryKey;
  spent: number;
  limit: number;
  ratio: number;
  overPace: boolean;
  overLimit: boolean;
}

export function budgetStates(sample: Sample): BudgetState[] {
  const { pace } = periodDay(sample);
  const spending = new Map<string, number>(Object.entries(sample.spent));
  return sample.budgets.map((budget) => {
    const progress = budgetProgress(
      { categoryIds: [budget.category], amount: budget.limit, alertThreshold: null },
      spending,
      [{ id: budget.category, parentId: null }],
      pace,
    );
    return { category: budget.category, ...progress };
  });
}

export function spendableTotal(sample: Sample): number {
  return sum(sample.accounts.spending.map((account) => account.balance));
}

export function netWorth(sample: Sample): number {
  return spendableTotal(sample) + sum(sample.accounts.savings.map((account) => account.balance));
}

export function cardDue(sample: Sample): number {
  return sample.card.accrued + sample.card.statement;
}

export interface GoalState {
  ratio: number;
  /** elapsed / length from the start to the deadline; null without a deadline. */
  pace: number | null;
  /** Saved minus where the pace says the goal should be, in cents. */
  gap: number;
}

export function goalState(goal: Sample['goals'][number], today: string): GoalState {
  const ratio = goal.saved / goal.target;
  if (goal.deadline === null) return { ratio, pace: null, gap: 0 };
  const pace = diffDays(goal.start, today) / diffDays(goal.start, goal.deadline);
  return { ratio, pace, gap: Math.round(goal.saved - goal.target * pace) };
}

/** Recurring cost per month: weekly entries count 52/12 times. */
export function recurringPerMonth(sample: Sample): {
  expenses: number;
  income: number;
  share: number;
} {
  let expenses = 0;
  let income = 0;
  for (const entry of sample.recurring) {
    const monthly =
      entry.cadence === 'weekly' ? Math.round((entry.amount * 52) / 12) : entry.amount;
    if (monthly < 0) expenses += monthly;
    else income += monthly;
  }
  return { expenses, income, share: income > 0 ? Math.round((-expenses / income) * 100) : 0 };
}

export function recapFigures(sample: Sample) {
  const recap = sample.recap;
  const rows = Object.entries(recap.spent) as [CategoryKey, number][];
  const expenses = sum(rows.map(([, amount]) => amount));
  const shown = rows.slice(0, 3);
  const rest = rows.slice(3);
  return {
    expenses,
    net: recap.income - expenses,
    shown,
    rest: { count: rest.length, amount: sum(rest.map(([, amount]) => amount)) },
  };
}
```

```ts
/** Spec 0.8a §07: the copy buttons of the terminal blocks. Without JavaScript they do nothing. */
for (const button of document.querySelectorAll<HTMLButtonElement>('button[data-copy]')) {
  const label = button.getAttribute('aria-label') ?? '';
  let timer = 0;
  button.addEventListener('click', async () => {
    try {
      await navigator.clipboard.writeText(button.dataset.copy ?? '');
    } catch {
      // No clipboard permission: the state still changes, so the press is not lost.
    }
    button.classList.add('done');
    button.setAttribute('aria-label', button.dataset.copied ?? label);
    window.clearTimeout(timer);
    timer = window.setTimeout(() => {
      button.classList.remove('done');
      button.setAttribute('aria-label', label);
    }, 1600);
  });
}
```

```ts
import { nextTheme, readChoice, THEME_KEY, type ThemeChoice } from '../lib/theme';

/**
 * Spec 0.8a §08: the toggle. The inline script in `Base.astro` already applied the stored choice
 * before the first paint; this only handles presses.
 */
function current(): ThemeChoice {
  try {
    return readChoice(localStorage.getItem(THEME_KEY));
  } catch {
    return 'system';
  }
}

function apply(choice: ThemeChoice): void {
  const root = document.documentElement;
  if (choice === 'system') root.removeAttribute('data-theme');
  else root.setAttribute('data-theme', choice);
  try {
    if (choice === 'system') localStorage.removeItem(THEME_KEY);
    else localStorage.setItem(THEME_KEY, choice);
  } catch {
    // Private mode: the choice lasts for this page only.
  }
  for (const button of document.querySelectorAll<HTMLButtonElement>('[data-theme-toggle]')) {
    button.setAttribute('aria-label', button.getAttribute(`data-label-${choice}`) ?? choice);
  }
}

for (const button of document.querySelectorAll<HTMLButtonElement>('[data-theme-toggle]')) {
  button.setAttribute('aria-label', button.getAttribute(`data-label-${current()}`) ?? '');
  button.addEventListener('click', () => apply(nextTheme(current())));
}
```

```ts
 * Spec 0.8a §05. The browser scrolls; this script adds mouse drag with momentum, the buttons, the
 * keys and the progress. Touch and trackpads keep the browser's own scrolling, and no vertical
 * movement is ever handled, so the page always scrolls.
 */
const reduced = () => window.matchMedia('(prefers-reduced-motion: reduce)').matches;

interface Parts {
  root: HTMLElement;
  scroller: HTMLElement;
  track: HTMLElement;
  prev: HTMLButtonElement;
  next: HTMLButtonElement;
  count: HTMLElement;
  bar: HTMLElement;
  name: HTMLElement;
}

function find(root: HTMLElement): Parts | null {
  const section = root.closest('section');
  const scroller = root.querySelector<HTMLElement>('[data-carousel-scroller]');
  const track = root.querySelector<HTMLElement>('[data-carousel-track]');
  const prev = section?.querySelector<HTMLButtonElement>('[data-carousel-prev]');
  const next = section?.querySelector<HTMLButtonElement>('[data-carousel-next]');
  const count = section?.querySelector<HTMLElement>('[data-carousel-count]');
  const bar = section?.querySelector<HTMLElement>('[data-carousel-bar]');
  const name = section?.querySelector<HTMLElement>('[data-carousel-name]');
  if (!scroller || !track || !prev || !next || !count || !bar || !name) return null;
  return { root, scroller, track, prev, next, count, bar, name };
}

function init({ root, scroller, track, prev, next, count, bar, name }: Parts): void {
  const items = Array.from(track.children).filter(
    (item): item is HTMLElement => item instanceof HTMLElement,
  );
  const total = String(items.length).padStart(2, '0');

  const max = () => scroller.scrollWidth - scroller.clientWidth;
  const padStart = () =>
    Number.parseFloat(getComputedStyle(scroller).scrollPaddingInlineStart) || 0;
  const stops = () =>
    snapStops(
      items.map((item) => item.offsetLeft),
      padStart(),
      max(),
    );

  let frame = 0;
  function update(): void {
    frame = 0;
    const x = scroller.scrollLeft;
    const end = max();
    prev.disabled = x <= 1;
    next.disabled = x >= end - 1;
    root.classList.toggle('fl', x > 1);
    root.classList.toggle('fr', x < end - 1);
    let index = 0;
    items.forEach((item, at) => {
      const here = Math.abs(item.offsetLeft - padStart() - x);
      const best = Math.abs((items[index]?.offsetLeft ?? 0) - padStart() - x);
      if (here < best) index = at;
    });
    if (x >= end - 1) index = items.length - 1;
    count.innerHTML = `<b>${String(index + 1).padStart(2, '0')}</b> / ${total}`;
    name.textContent = items[index]?.dataset.name ?? '';
    bar.style.transform = `scaleX(${Math.min(1, (x + scroller.clientWidth) / scroller.scrollWidth).toFixed(4)})`;
  }
  const schedule = () => {
    if (frame === 0) frame = requestAnimationFrame(update);
  };

  let spring = 0;
  function stop(): void {
    cancelAnimationFrame(spring);
    spring = 0;
    scroller.classList.remove('anim');
  }
  /** From the live position, carrying the release velocity (px/s). */
  function settleTo(target: number, velocity = 0): void {
    stop();
    const from = scroller.scrollLeft;
    if (reduced() || Math.abs(target - from) < 1) {
      scroller.scrollLeft = target;
      schedule();
      return;
    }
    scroller.classList.add('anim');
    const start = performance.now();
    const step = (now: number) => {
      const state = springAt(from, target, velocity, (now - start) / 1000);
      scroller.scrollLeft = state.x;
      if (isSettled(state.x, target, state.v)) {
        scroller.scrollLeft = target;
        stop();
        schedule();
        return;
      }
      spring = requestAnimationFrame(step);
    };
    spring = requestAnimationFrame(step);
  }
  const go = (direction: 1 | -1) => {
    const target = adjacentStop(stops(), scroller.scrollLeft, direction);
    if (target !== null) settleTo(target);
  };

  prev.addEventListener('click', () => go(-1));
  next.addEventListener('click', () => go(1));
  scroller.addEventListener('keydown', (event) => {
    if (event.key === 'ArrowRight') go(1);
    else if (event.key === 'ArrowLeft') go(-1);
    else if (event.key === 'Home') settleTo(0);
    else if (event.key === 'End') settleTo(max());
    else return;
    event.preventDefault();
  });
  scroller.addEventListener('scroll', schedule, { passive: true });
  scroller.addEventListener('wheel', stop, { passive: true });
  scroller.addEventListener('touchstart', stop, { passive: true });
  window.addEventListener('resize', schedule, { passive: true });
  track.addEventListener('dragstart', (event) => event.preventDefault());

  interface Drag {
    id: number;
    x0: number;
    s0: number;
    active: boolean;
    over: number;
    samples: PointerSample[];
  }
  let drag: Drag | null = null;
  let suppressClick = false;
  track.addEventListener(
    'click',
    (event) => {
      if (!suppressClick) return;
      event.preventDefault();
      event.stopPropagation();
      suppressClick = false;
    },
    true,
  );
  scroller.addEventListener('pointerdown', (event) => {
    if (event.pointerType !== 'mouse' || event.button !== 0) return;
    stop();
    drag = {
      id: event.pointerId,
      x0: event.clientX,
      s0: scroller.scrollLeft,
      active: false,
      over: 0,
      samples: [{ x: event.clientX, t: event.timeStamp }],
    };
  });
  scroller.addEventListener('pointermove', (event) => {
    if (drag === null || event.pointerId !== drag.id) return;
    const dx = event.clientX - drag.x0;
    if (!drag.active) {
      if (Math.abs(dx) < DRAG_START_PX) return;
      drag.active = true;
      scroller.setPointerCapture(event.pointerId);
      scroller.classList.add('drag');
    }
    const wanted = drag.s0 - dx;
    const x = Math.max(0, Math.min(max(), wanted));
    scroller.scrollLeft = x;
    drag.over = wanted - x;
    track.style.transform =
      drag.over === 0 || reduced()
        ? ''
        : `translateX(${(-rubberBand(drag.over, scroller.clientWidth)).toFixed(1)}px)`;
    drag.samples.push({ x: event.clientX, t: event.timeStamp });
    while (
      drag.samples.length > 2 &&
      event.timeStamp - (drag.samples[0]?.t ?? 0) > SAMPLE_WINDOW_MS
    )
      drag.samples.shift();
  });
  const end = (event: PointerEvent) => {
    if (drag === null || event.pointerId !== drag.id) return;
    const finished = drag;
    drag = null;
    if (!finished.active) return;
    suppressClick = true;
    window.setTimeout(() => {
      suppressClick = false;
    }, 80);
    scroller.classList.remove('drag');
    if (finished.over !== 0) {
      const from = track.style.transform;
      track.style.transform = '';
      if (!reduced() && from !== '') {
        track.animate([{ transform: from }, { transform: 'translateX(0)' }], {
          duration: 420,
          easing: 'cubic-bezier(0.32, 0.72, 0, 1)',
        });
      }
      settleTo(finished.over < 0 ? 0 : max());
      return;
    }
    const velocity = releaseVelocity(finished.samples);
    settleTo(restingStop(stops(), scroller.scrollLeft, velocity), velocity);
  };
  scroller.addEventListener('pointerup', end);
  scroller.addEventListener('pointercancel', end);
  scroller.addEventListener('lostpointercapture', end);
  update();
}

for (const root of document.querySelectorAll<HTMLElement>('[data-carousel]')) {
  const parts = find(root);
  if (parts !== null) init(parts);
}
```

```js
import { spawn } from 'node:child_process';
import { fileURLToPath } from 'node:url';
import { chromium } from '@playwright/test';

const root = fileURLToPath(new URL('..', import.meta.url));
const preview = spawn('pnpm', ['exec', 'astro', 'preview', '--port', '4399', '--ignore-lock'], {
  cwd: root,
  stdio: 'pipe',
});
// Astro moves to the next free port when 4399 is busy, so read the address that it prints.
// `--ignore-lock` keeps the server in the foreground when an agent runs this script.
const origin = await new Promise((resolve, reject) => {
  preview.stdout.on('data', (chunk) => {
    const match = /http:\/\/localhost:\d+/.exec(String(chunk));
    if (match) resolve(match[0]);
  });
  preview.on('exit', (code) => reject(new Error(`astro preview exited with ${code}`)));
});
try {
  const browser = await chromium.launch();
  const page = await browser.newPage({
    viewport: { width: 1200, height: 630 },
    colorScheme: 'dark',
  });
  await page.goto(`${origin}/og/`, { waitUntil: 'networkidle' });
```

```ts
import { expect, type Page, test } from '@playwright/test';

const REPO = 'https://github.com/saliougaye/saldo';
const GUIDE = 'https://github.com/saliougaye/saldo/blob/main/docs/self-hosting.md';

/** Where the scroller rests, and whether that is one of its stops (spec 0.8a §05). */
async function carousel(page: Page) {
  return page.locator('[data-carousel-scroller]').evaluate((scroller: HTMLElement) => {
    const pad = Number.parseFloat(getComputedStyle(scroller).scrollPaddingInlineStart) || 0;
    const max = scroller.scrollWidth - scroller.clientWidth;
    const stops = Array.from(scroller.querySelectorAll<HTMLElement>('.car-it')).map((item) => {
      const stop = Math.max(0, Math.min(max, item.offsetLeft - pad));
      return Math.round(stop > max - 32 ? max : stop);
    });
    const x = scroller.scrollLeft;
    return { x, max, onStop: stops.some((stop) => Math.abs(stop - x) <= 1) };
  });
}

async function settle(page: Page) {
  await page.waitForFunction(
    () => !document.querySelector('[data-carousel-scroller]')?.classList.contains('anim'),
  );
}

test.describe('landing page', () => {
  let errors: string[] = [];

  test.beforeEach(async ({ page }) => {
    errors = [];
    page.on('pageerror', (error) => errors.push(error.message));
    page.on('console', (message) => {
      if (message.type() === 'error') errors.push(message.text());
    });
    await page.goto('/');
  });

  test.afterEach(() => {
    expect(errors).toEqual([]);
  });

  test('has no horizontal overflow and only the two calls to action', async ({ page }) => {
    const overflow = await page.evaluate(
      () => document.documentElement.scrollWidth - window.innerWidth,
    );
    expect(overflow).toBeLessThanOrEqual(0);
    const hrefs = await page
      .locator('a.btn-primary, a.btn-ghost')
      .evaluateAll((links) => links.map((link) => link.getAttribute('href')));
    expect(new Set(hrefs)).toEqual(new Set([REPO, GUIDE]));
  });

  test('shows ten screens and names each one', async ({ page }) => {
    const labels = await page
      .locator('[data-carousel-track] .ph[role="img"]')
      .evaluateAll((screens) => screens.map((screen) => screen.getAttribute('aria-label') ?? ''));
    expect(labels).toHaveLength(10);
    for (const label of labels) expect(label).toMatch(/^[A-Z][\w ]+: /);
  });

  test('buttons and keys stop on a card, and each button is disabled at its end', async ({
    page,
  }) => {
    const next = page.locator('[data-carousel-next]');
    const prev = page.locator('[data-carousel-prev]');
    await expect(prev).toBeDisabled();
    while (!(await next.isDisabled())) {
      await next.click();
      await settle(page);
      expect((await carousel(page)).onStop).toBe(true);
    }
    await expect(page.locator('[data-carousel-count]')).toHaveText('10 / 10');
    await page.locator('[data-carousel-scroller]').focus();
    await page.keyboard.press('Home');
    await settle(page);
    expect((await carousel(page)).x).toBe(0);
    await page.keyboard.press('ArrowRight');
    await settle(page);
    const after = await carousel(page);
    expect(after.onStop).toBe(true);
    expect(after.x).toBeGreaterThan(0);
  });

  test('a mouse flick lands on a card and does not scroll the page', async ({ page }) => {
    const scroller = page.locator('[data-carousel-scroller]');
    await scroller.scrollIntoViewIfNeeded();
    const box = await scroller.boundingBox();
    if (box === null) throw new Error('the carousel has no box');
    const pageY = await page.evaluate(() => window.scrollY);
    const y = box.y + 200;
    await page.mouse.move(box.x + box.width * 0.6, y);
    await page.mouse.down();
    for (let step = 1; step <= 6; step += 1) {
      await page.mouse.move(box.x + box.width * 0.6 - step * 60, y);
    }
    await page.mouse.up();
    await settle(page);
    const state = await carousel(page);
    expect(state.onStop).toBe(true);
    expect(state.x).toBeGreaterThan(0);
    expect(await page.evaluate(() => window.scrollY)).toBe(pageY);
  });

  test('the theme toggle sets the theme before the next paint, after a reload too', async ({
    page,
  }) => {
    const toggle = page.locator('[data-theme-toggle]');
    await toggle.click();
    await expect(page.locator('html')).toHaveAttribute('data-theme', 'light');
    await page.reload();
    await expect(page.locator('html')).toHaveAttribute('data-theme', 'light');
    await toggle.click();
    await expect(page.locator('html')).toHaveAttribute('data-theme', 'dark');
    await toggle.click();
    await expect(page.locator('html')).not.toHaveAttribute('data-theme', /.*/);
  });
});
```
