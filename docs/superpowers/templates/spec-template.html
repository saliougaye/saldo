Saldo 0.4 · MCP · Explainer

The MCP feature of Saldo

Your AI assistant can read and change your Saldo data. The data stays on your server. Saldo does not keep an AI key and does not call an AI model.

Language Simplified Technical English (ASD-STE100) Source Spec §17.4 Date 2026-10-05
01

What it is

MCP is the Model Context Protocol. It is a standard. An AI client uses it to find and use the tools of a server.

Saldo is an MCP server. Your AI client is the MCP client. The AI model runs in the client, not in Saldo.

The client sends a tool call to Saldo. Saldo sends back the result. Saldo never starts the conversation.

Example

You ask Claude: “How much did I spend on food this month?” Claude calls spending_by_category. The totals are the same as the totals on the Statistics page, to the cent.

0

AI keys in Saldo

The model runs in your client. You pay your AI company, not Saldo.

1

Address to give

You give the client one URL: https://your-host/mcp. There is no key to copy.

2

Permission levels

Read and Write. You select them on the consent page.

02

The parts

The feature has five parts. Each part has one job.

The business rules stay in @saldo/core. The route only loads the data, calls core, and sends the result.

A write tool uses the same write functions as the web forms. Thus, an AI client cannot write data that a form cannot write.

PartJobWhere
A · OAuth serverRegisters clients. Gives, refreshes and revokes tokens./api/auth/oauth2/*
B · ScreensYou approve a client. You see and revoke clients. The admin turns MCP on or off./oauth/consent /profile/connectors /admin/mcp
C · MCP endpointChecks the token. Lists the tools for the scope. Runs one tool.apps/web/app/mcp
D · Write functionsApplies the rules of the web forms. Checks the row version.src/server/write/*
E · CatalogueTells the model what each tool does. Calculates the read results.packages/core/src/assistant/
03

Connect a client

Do this procedure one time for each client. You need a passkey for your Saldo account. The server must use https://.

Claude Code

  1. In Saldo, go to Profile › Connectors.
  2. Copy the endpoint address.
  3. In a terminal, type the command below.
  4. Send a request, for example “List my accounts”.
  5. The browser opens. Sign in with your passkey.
  6. Select the permissions. Click Authorize.
claude mcp add --transport http saldo https://your-host/mcp

Claude (app or web)

  1. Go to Settings › Connectors › Add custom connector.
  2. Paste the endpoint address. Then do steps 5 and 6 above.
Other clients

A client with HTTP and OAuth finds all other data at /.well-known/oauth-protected-resource. For a terminal with no browser, use npx mcp-remote.

04

The sign-in flow

The client does most steps automatically. You do only two steps: you sign in, and you click Authorize.

The flow is OAuth 2.1 with PKCE. The client registers itself. A registration alone gives no access. A token exists only after your consent.

The consent page shows the client name. The client selects this name itself. Thus, the page shows a warning for a new client.

Caution

Click Authorize only if you started the request a short time before. If you did not start it, click Deny.

Saldo keeps your consent. The same client does not ask again for the same or fewer permissions. If you clear “Add and change”, the button changes to Authorize reading only.

05

Permissions

A token has one or two scopes. The scope controls the tools that the client can see.

With only read, the client does not see the write tools in the tool list.

If a client calls a write tool with a read-only token, Saldo sends HTTP 403 and the error insufficient_scope.

Note

A third scope, offline_access, is hidden. The consent page does not show it. It is necessary for the refresh token.

06

The tools

Each tool has a name, a description for the model, and an input and output schema.

Amounts. Saldo keeps money as integers in minor units. A tool sends three fields. The model reads amount. For calculations, the model uses minor.

Dates. All dates are YYYY-MM-DD. “Today” is the date in your time zone.

Periods. Use "current", "previous", a date in the period, or from and to. Your cycle day sets the start of a period.

Links. get_preferences gives the links of the web app. After a change, the model can give you a link to the row.

07

One request

Each request is independent. Saldo does not keep a session. It checks the token, does the work, and forgets the request.

Saldo builds a new MCP server for each request. It registers only the tools that the scope of the token permits.

A tool always sends structuredContent and the same JSON as text. A refused change is a tool error with a clear message. It is never a crash or an HTTP 500.

08

Safe changes

An AI client reads a row. Some minutes later, it changes the row. In this time, your phone can change the same row.

Saldo must not lose the change from the phone. Thus, each change sends back the updatedAt that the client read.

If the row changed after the read, Saldo refuses the change. The message is “changed after you read it”. Saldo writes nothing. The client must read the row again.

Partial updates. An update sends the id, the updatedAt and only the changed fields. Saldo keeps all other fields.

Web forms too. The web forms use the same check. A form does not overwrite a newer change from the phone. It tells you to reload the page.

09

Tokens

Tokens are opaque strings. Saldo keeps only a SHA-256 hash of each token and checks the token on each call.

An access token is valid for 1 hour. The client uses the refresh token to get a new one. Each refresh gives a new refresh token. If the client does not use it for 180 days, the authorization ends.

There is no JWT. Thus, a revocation is immediate. There is no wait for expiry.

Security

Saldo does not accept a token in the URL. Saldo does not write tokens to the logs. If you sign out of the web app, your MCP clients continue to work. To stop a client, use Revoke access.

10

Admin switch

An admin can turn MCP off for all users of the instance. Go to Admin › MCP.

Before “off”, the page asks for confirmation. It shows how many connectors will stop.

Environment variable. MCP_ENABLED=true|false has priority over the switch. When it is set, the page shows a lock and the switch is disabled.

Numbers. The page shows: users with connectors, authorized connectors, and connectors used in the last 7 days. It shows totals only, not client names or user details.

Words

The meaning of the special words in this document.

WordMeaning
MCPModel Context Protocol. A standard for AI clients to use the tools of a server.
ClientThe program that contains the AI model, for example Claude Code.
ConnectorOne authorized client in Saldo. Claude uses the same word.
ToolOne operation that the client can call, for example list_accounts.
ScopeA permission level: read or write.
ConsentYour approval of one client, with its scopes.
Access tokenA secret string. It gives access for 1 hour.
Refresh tokenA secret string. The client uses it to get a new access token.
PKCEA check. It makes sure that the client that starts the flow is the client that gets the token.
Minor unitsThe smallest unit of a currency. €123.45 is 12345.
updatedAtThe time of the last change to a row. The version check uses it.
